# คู่มือผู้ใช้ Bedside English

**กลุ่มเป้าหมาย:** แพทย์ผู้สำเร็จการศึกษาจากต่างประเทศ (IMGs), แพทย์ประจำบ้าน (Resident Physicians), นักศึกษาแพทย์ และบุคลากรทางการแพทย์ที่เตรียมความพร้อมด้านภาษาอังกฤษทางการแพทย์, OSCE, OET Speaking, การสัมภาษณ์ฝึกงานแพทย์ในสหรัฐฯ, การนำเสนอเคสบนวอร์ด และการสื่อสารทางคลินิก

Bedside English เป็นแอปพลิเคชันสำหรับระบบปฏิบัติการ Android ขับเคลื่อนด้วย AI สำหรับการสนทนา (Google Gemini, OpenAI Realtime, Anthropic Claude) และเทคโนโลยีเสียงแบบเรียลไทม์ แอปนี้ออกแบบมาเพื่อฝึกฝนทักษะการสื่อสารทางคลินิก เหตุผลทางการแพทย์ การออกเสียง และความชัดเจนในการสื่อสาร คู่มือนี้ระบุรายละเอียดคุณสมบัติและการใช้งานทั้งหมดของแอปพลิเคชันเวอร์ชันล่าสุดอย่างครบถ้วน

## 1. การตั้งค่าและการกำหนดค่า API Key

Bedside English รองรับเบื้องหลังการทำงานจาก Google Gemini, OpenAI และ Anthropic Claude อย่างยืดหยุ่น

### 💡 การตั้งค่าที่แนะนำ (โหมดใช้คีย์เดียว Google Gemini)

**การลงทะเบียนคีย์ Google Gemini API เพียงคีย์เดียว สามารถเปิดใช้งานฟังก์ชันทั้งหมดของแอปพลิเคชัน ตั้งแต่การสนทนาด้วยเสียงเรียลไทม์ไปจนถึงการวิเคราะห์ผลหลังเซสชัน ในวิธีที่รวดเร็วและคุ้มค่าที่สุด**

| บริการ                 | วัตถุประสงค์หลัก                                            | ความจำเป็น                               | ลิงก์                                                  |
| :--------------------- | :---------------------------------------------------------- | :--------------------------------------- | :----------------------------------------------------- |
| **Google (Gemini)**    | สนทนาด้วยเสียงเรียลไทม์ (Gemini Live) + วิเคราะห์ผลเชิงลึก  | **จำเป็น (คีย์เดียวครอบคลุมทุกฟีเจอร์)** | [aistudio.google.com](https://aistudio.google.com)     |
| **OpenAI**             | เสียงเรียลไทม์ (OpenAI Realtime) + ผลป้อนกลับ + Premium TTS | ตัวเลือกเสริม                            | [platform.openai.com](https://platform.openai.com)     |
| **Anthropic (Claude)** | วิเคราะห์ผลป้อนกลับหลังเซสชัน (เลือกเบื้องหลังได้)          | ตัวเลือกเสริม (Gemini เป็นค่าเริ่มต้น)   | [console.anthropic.com](https://console.anthropic.com) |

### การป้อนคีย์ API และความปลอดภัย

คีย์ API จะถูกป้อนโดยตรงภายในแอป:

- ตั้งค่าระหว่าง **ขั้นตอนเริ่มต้นใช้งานครั้งแรก (Onboarding Wizard)** หรือผ่านเมนู **ไอคอนเฟืองการตั้งค่า (⚙️) → การตั้งค่า → API Keys** ในแถบด้านบน
- คีย์ API ที่ป้อนจะถูก **จัดเก็บอย่างปลอดภัย** บนอุปกรณ์ด้วยระบบเข้ารหัส (`EncryptedSharedPreferences`) และจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ภายนอกใดๆ
- ช่องป้อนคีย์แต่ละช่องจะมีรูปไอคอนดวงตาทางด้านขวาเพื่อเปิดปิดการมองเห็นคีย์

### 🎈 โหมดสาธิต (ทดลองใช้งานฟรีอย่างสมบูรณ์)

หากคุณต้องการทดลองใช้งานแอปโดยไม่ต้องลงทะเบียนคีย์ API หรือให้สิทธิ์ไมโครโฟน ให้เลือกโหมด **Demo** ในหน้าเริ่มต้นใช้งานหรือใน **การตั้งค่า**
บทสนทนาตัวอย่างและข้อมูลผลป้อนกลับที่เตรียมไว้จะถูกโหลดขึ้นมา ทำให้คุณสามารถสำรวจ UI ระบบติดตามข้อผิดพลาด และฟีเจอร์การทบทวนทั้งหมดได้ **ฟรี** โดยไม่เสียโทเคน หลังจากจบเซสชันตัวอย่าง ระบบจะแสดงคำแนะนำให้คุณป้อนคีย์ API หรือดำเนินการฝึกเคสตัวอย่างถัดไปได้ตลอดเวลา

## 2. การติดตั้งแอปและการตั้งค่าสิทธิ์การใช้งาน

Bedside English ทำงานบนสมาร์ทโฟนและแท็บเล็ตระบบ Android 8.0 (API Level 26) ขึ้นไป

### การติดตั้งแอป

- เปิดไฟล์ติดตั้ง (`.apk`) ที่ได้รับบนอุปกรณ์ Android ของคุณและปฏิบัติตามคำแนะนำบนหน้าจอเพื่อติดตั้ง

### สิทธิ์ไมโครโฟนและโหมดเปลี่ยนเป็นพิมพ์

- เมื่อเริ่มต้นใช้งานโหมดฝึกซ้อมด้วยเสียงจริงเป็นครั้งแรก ระบบ Android จะขอสิทธิ์เข้าถึงไมโครโฟน แตะ **[อนุญาต]** เพื่อให้ระบบจำเสียงทำงานได้อย่างถูกต้อง
- หากอยู่ในสถานที่ที่ไม่สะดวกในการพูดหรือปฏิเสธสิทธิ์ แอปจะไม่เด้งดับ แอปจะเปลี่ยนเป็นโหมด **เปลี่ยนเป็นพิมพ์ (Type instead)** โดยอัตโนมัติ ช่วยให้คุณฝึกสนทนาผ่านการพิมพ์แป้นพิมพ์แทนได้

### สิทธิ์การแจ้งเตือนและการตรวจสอบเสียงล่วงหน้า (Audio Preflight)

- ระบบจะขอสิทธิ์การแจ้งเตือนเพื่อส่งการแจ้งเตือนเมื่อการวิเคราะห์ผลป้อนกลับเบื้องหลังเสร็จสิ้น
- ก่อนเริ่มเซสชันเสียงจริงครั้งแรก หน้าต่าง **การตรวจสอบเสียงล่วงหน้า (Audio Preflight)** จะแสดงขึ้นเพื่อแนะนำการใช้หูฟังและทดสอบระดับเสียงไมโครโฟน เพื่อป้องกันเสียงสะท้อน (Howling)

## 3. การเริ่มต้นใช้งานครั้งแรกและการปรับแต่งตามภาษาแม่ (L1)

เมื่อเปิดแอปพลิเคชันเป็นครั้งแรก ระบบจะแสดงขั้นตอนการตั้งค่า 4 ขั้นตอนเพื่อสร้างสภาพแวดล้อมการเรียนรู้ที่เหมาะกับคุณ:

1. **หน้าต้อนรับ**: แนะนำฟีเจอร์หลักและมีปุ่ม **ลองโหมดสาธิต** เพื่อทดลองโดยไม่ต้องใช้คีย์ API
2. **ตัวเลือกภาษาของแอป (UI Language Picker)**: เลือกภาษาที่คุณต้องการ (รองรับ 8 ภาษา: อังกฤษ, เกาหลี, สเปน, จีน, อาหรับ, ฮินดี, โปรตุเกส, ตากาล็อก)
3. **การตั้งค่าคีย์ API**: ลงทะเบียนคีย์ Google Gemini API หรือคีย์อื่นๆ
4. **ภาษาแม่และความเป็นส่วนตัว (Native Language & Privacy)**: เลือกภาษาแม่ของคุณ (เช่น **เกาหลี**, จีน, สเปน, อาหรับ, ฮินดี, ตากาล็อก, โปรตุเกส) เพื่อเปิดใช้งานการวิเคราะห์ไวยากรณ์และการออกเสียงที่วิเคราะห์จากรูปแบบข้อผิดพลาดเฉพาะของภาษาแม่นั้นๆ

### 🌐 ตัวอย่างการปรับแต่งตามภาษาแม่ (เช่น ผู้เรียน L1 ที่ใช้ภาษาเกาหลี)

- **การแก้ไขไวยากรณ์และรูปประโยค**:
  - การละเลยคำหน้านาม (Article: _a/an/the_)
  - การลืมเติม _-s_ สำหรับพหูพจน์ (_two patient_ → _two patients_)
  - ข้อผิดพลาดเรื่อง Tense (ใช้ Present Tense ขณะซักประวัติอดีต)
  - การใช้คำบุพบท (Preposition) ผิดพลาด (_in hospital_, การละบุพบทใน _explain to patient_)
  - การแปลตรงตัว (Literal direct translations) / Konglish (_skin scale_, การแปลตรงตัวที่ผิดธรรมชาติของ _side effect_)
- **การแก้ไขการออกเสียงและความชัดเจน**:
  - การแยกเสียง _r / l_ (_liver_ vs _river_)
  - การแยกเสียง _f / p_ (_fever_ vs _peter_)
  - การออกเสียง _th_ (_think_ vs _tink_)
  - การตัดเสียงพยัญชนะท้ายและการเติมเสียงสระ 으/이 โดยไม่จำเป็น (_cardiac_ → _cardi-ack-eu_)
  - การลงเน้นเสียง (Stress) คำศัพท์ทางการแพทย์ผิดตำแหน่ง (_angina_, _arrhythmia_)

### 💡 คำแนะนำการใช้งานแบบโต้ตอบครั้งแรก

หลังจากเสร็จสิ้นการตั้งค่าและเข้าสู่หน้าแรกเป็นครั้งแรก ระบบบทเรียนโต้ตอบจะนำทางคุณไปยังตำแหน่งและหน้าที่ของปุ่มสำคัญต่างๆ อัตโนมัติ (หน้าแรก, ศูนย์การฝึกฝน, ห้องปฏิบัติการออกเสียง, การทบทวน SRS, ประวัติ, ช่วยเหลือ, โค้ชเสียง 1:1)

## 4. โครงสร้างภาพรวมของ UI (เมนูด้านล่าง 5 แท็บ และความช่วยเหลือ)

### แถบเมนูด้านล่าง (5 แท็บ)

เมนูหลักประกอบด้วย 5 แท็บด้านล่าง:

```
┌───────────┬──────────────┬───────────────────────┬───────────────┬─────────────┐
│  🏠 Home  │  ▶ Practice  │  🎙️ Pronunciation Lab │  ⚠️ SRS Reviews│  🕘 History │
└───────────┴──────────────┴───────────────────────┴───────────────┴─────────────┘
```

1. **Home (หน้าแรก)**: ความต่อเนื่องของการฝึก (`🔥`), ภารกิจทางคลินิก 5 นาที, กราฟแนวโน้มพัฒนาการ, Mistake Genome, แผนที่การเรียนรู้ และ **โค้ชเสียง 1:1 ที่พร้อมใช้งานเสมอ**
2. **Practice (ศูนย์การฝึกฝน)**: ศูนย์รวมโหมดการฝึกพูดเรียลไทม์ทั้งหมด: การตรวจรักษาผู้ป่วย, การสอบและการประเมินผล, ภาษาอังกฤษเพื่อการเอาตัวรอด, การอธิบายบทเรียน, การสัมภาษณ์, ห้องสนทนาเสรี และสถานการณ์กำหนดเอง
3. **Pronunciation Lab (ห้องปฏิบัติการออกเสียง)**: แท็บการฝึกเฉพาะทางเพื่อความชัดเจนในการออกเสียงและการแก้ไขคำผิด
4. **SRS Reviews (การทบทวนจุดอ่อน)**: แบบทดสอบทบทวนด้วยเสียงโดยใช้ระบบอัลกอริทึมเว้นระยะทบทวนสำหรับประโยคที่บันทึกไว้
5. **History (ประวัติเซสชัน)**: เรียกดูคะแนนและผลป้อนกลับในอดีต ติดตามค่าใช้จ่ายโทเคน ส่งออกข้อมูลไปยัง Anki/Word และเริ่ม **การนำเสนอเคสแก่แพทย์อาวุโส (Present Case)**

### แถบแอปด้านบน

- **โลโก้ Bedside English**: ชื่อหลักของแอป
- **วิกิช่วยเหลือ (ไอคอน `?`)**: แตะไอคอน `?` เพื่อเปิดคู่มือผู้ใช้นี้ในรูปแบบการแสดงผลเต็มหน้าจอ พร้อมแถบสารบัญและการค้นหาคำด้วยคีย์เวิร์ด
- **เฟืองการตั้งค่า (⚙️ Preferences)**: คีย์ API, เครื่องมือเสียง AI, ความเร็วในการพูด, การป้องกันเสียงสะท้อน, ภาษา และการจัดการข้อมูล

## 5. การใช้งานแดชบอร์ดหลัก (Mastering the Dashboard (Home))

แดชบอร์ดหลักแสดงพัฒนาการด้านการสื่อสารภาษาอังกฤษทางการแพทย์ของคุณอย่างมีมิติ:

- **Streak Tracker**: แสดงจำนวนวันที่ฝึกฝนติดต่อกันด้วยไอคอนรูปไฟ (`🔥`) เพื่อสร้างนิสัยการฝึกซ้อมประจำวัน
- **การ์ดตัววัดหลัก**:
  - **Sessions done**: จำนวนเซสชันที่เสร็จสมบูรณ์และผ่านการวิเคราะห์แล้วทั้งหมด
  - **Errors tracked**: จำนวนข้อแก้ไขที่ยืนยันบันทึกเข้าสู่ฐานข้อมูลจุดอ่อนส่วนตัว
  - **Mastered**: ข้อผิดพลาดที่ได้รับการแก้ไขและผ่านการทดสอบทบทวนซ้ำจนเชี่ยวชาญแล้ว
  - **Due now**: จำนวนการ์ดทบทวน SRS ที่ถึงกำหนดต้องฝึกพูดในวันนี้
  - **Stubborn**: ข้อผิดพลาดที่ตอบผิดติดต่อกัน 4 ครั้งขึ้นไป ซึ่งต้องการการฝึกฝนเน้นเป็นพิเศษ
- **ภารกิจทางคลินิก 5 นาทีประจำวัน**: แนะนำคอร์สฝึกฝน 5 นาทีที่เหมาะสมที่สุดให้อัตโนมัติ โดยเน้นรายการทบทวนที่ถึงกำหนด การทดสอบที่จำเป็น หรือทักษะด้านที่อ่อนที่สุด
- **ความครอบคลุมคำศัพท์ชาวบ้าน OET (Layman Vocabulary)**:
  - ติดตามประสิทธิภาพในการเลือกใช้คำศัพท์ที่เข้าใจง่ายสำหรับผู้ป่วย (เช่น _fainting_) แทนคำศัพท์ทางการแพทย์ที่ซับซ้อน (เช่น _syncope_)
  - คำศัพท์ที่ใช้แล้วจะแสดงในส่วน **ปลดล็อกแล้วล่าสุด** ขณะที่คำศัพท์ที่ยังไม่ได้ใช้จะอยู่ในลำดับ **เป้าหมายถัดไป (ล็อกอยู่)**
- **แผง Mistake Genome**: วิเคราะห์หมวดหมู่ข้อผิดพลาดที่เกิดขึ้นบ่อยที่สุดของคุณ (คำหน้านาม, พหูพจน์, Tense, บุพบท, ระดับภาษา, การแปลตรงตัว) และแสดงจุดอ่อน 5 อันดับแรกเป็นกราฟแท่ง
- **กราฟแนวโน้มและผลกระทบจากภาษาแม่**:
  - แสดงกราฟแนวโน้มคะแนน 5 ด้าน (ไวยากรณ์, ความถูกต้อง, เหตุผลทางคลินิก, ความเป็นมืออาชีพ, ความคล่องแคล่ว) จาก 20 เซสชันล่าสุด
  - แสดงรูปแบบข้อผิดพลาดทางไวยากรณ์ที่เกิดขึ้นซ้ำๆ ให้เห็นอย่างชัดเจน
- **แผนที่การเรียนรู้ส่วนบุคคล**: วิเคราะห์ตัววัดที่อ่อนและประวัติข้อผิดพลาดเพื่อนำเสนอการ์ดทักษะเน้นหนัก 4 ลำดับแรก
- **ปุ่มโค้ชเสียง 1:1 ที่พร้อมใช้งานเสมอ (`🎙️ RecordVoiceOver`)**:
  - อยู่บริเวณมุมขวาล่างของแดชบอร์ด แตะเพื่อเปิดบทสนทนาฝึกพูด 1:1 กับโค้ช AI ได้ทันทีตามโปรไฟล์จุดอ่อนส่วนตัวโดยไม่ต้องเริ่มเคสเต็ม

## 6. ศูนย์การฝึกฝนและการปลดล็อกฟีเจอร์ตามลำดับ

### การปลดล็อกฟีเจอร์ตามลำดับ

เพื่อป้องกันไม่ให้ผู้ใช้ใหม่รู้สึกสับสน ในครั้งแรกแอปจะแสดงหน้าจอเริ่มต้นที่เรียบง่าย ประกอบด้วยโหมดหลัก (**หน้าแรก**, **การตรวจรักษาผู้ป่วย**, **ภาษาอังกฤษเพื่อการเอาตัวรอด**, **ประวัติ**)

- **การทำเซสชันฝึกซ้อมแรกเสร็จสมบูรณ์** จะ **ปลดล็อก** โหมดขั้นสูง (การสอบ, การอธิบายบทเรียน, การสัมภาษณ์, ห้องสนทนาเสรี, กำหนดเอง) โดยอัตโนมัติพร้อมข้อความแสดงความยินดี
- คุณสามารถแตะปุ่มขยายเพื่อเปิดดูโหมดทั้งหมดได้ทันทีจากหน้าการฝึกฝน

### หมวดหมู่โหมดหลักในศูนย์การฝึกฝน

1. **การตรวจรักษาผู้ป่วย**: การซักประวัติ, การติดตามผล, โหมดพื้นฐานสำหรับผู้เริ่มต้น, การซ้อมทักษะเฉพาะจุด, การฝึกฝนข้อผิดพลาดของฉัน
2. **การสอบและการประเมินผล**: การประเมินระดับพื้นฐาน 10 นาที, จำลองการสอบ OSCE, OET, การสัมภาษณ์แพทย์ประจำบ้าน และการนำเสนอเคสบนวอร์ด
3. **ภาษาอังกฤษเพื่อการเอาตัวรอดและห้องปฏิบัติการฟัง**: สถานการณ์ไม่คาดคิดในโรงพยาบาล, การคุยเล่นโต้ตอบเร็ว, โปรไฟล์สำเนียงเจ้าของภาษา 15 แบบ, การซ้อมฟังรายละเอียดย่อย
4. **การอธิบายบทเรียน (Teach-back)**: การฝึกฝนเทคนิค Feynman จากสรุป YouTube หรือข้อความ
5. **การสัมภาษณ์แพทย์ประจำบ้าน**: การสัมภาษณ์จำลองด้านพฤติกรรม ทางคลินิก และสำหรับ IMG โดยเฉพาะ
6. **ห้องสนทนาภาษาอังกฤษเสรี**: การอภิปรายประเด็นทางการแพทย์ สรุปข่าว และการแก้ปัญหาความขัดแย้งในที่ทำงาน
7. **สถานการณ์แบบกำหนดเอง**: สร้างคำสั่ง AI และเกณฑ์การประเมินผลด้วยตนเอง

## 7. การซักประวัติผู้ป่วยและระบบติดตามความครอบคลุมทางการแพทย์แบบเรียลไทม์

จำลองการซักประวัติและการให้คำแนะนำผู้ป่วยข้างเตียง ซึ่งเป็นหัวใจสำคัญของการสื่อสารทางคลินิก

### 7-1. โหมดย่อยการใช้งาน

- **โหมดพื้นฐาน (Foundations Mode)**: ลดภาระเรื่องเหตุผลทางคลินิกสำหรับผู้เริ่มต้น เน้นเฉพาะ **ไวยากรณ์, คำศัพท์คลินิก, การสร้างความสัมพันธ์ (Rapport) และความคล่องแคล่ว**
- **การซ้อมทักษะเฉพาะจุด (Skill Drills)**: แบบฝึกหัดทักษะย่อยเฉพาะทาง (เทคนิคการแสดงความเห็นอกเห็นใจ NURSE, การอธิบายด้วยภาษาง่าย, การส่งเวรเวรดึก, **การล่ามแปลภาษาแม่ → อังกฤษแบบต่อเนื่อง**)
- **การฝึกฝนข้อผิดพลาดของฉัน (Practice My Mistakes)**: สร้างแบบทดสอบบทสนทนาด้วยเสียงทันทีจากข้อผิดพลาดที่ค้างอยู่ในฐานข้อมูลของคุณ
- **ภารกิจประจำวัน (Daily Mission)**: แบบทดสอบท้าทาย 5 นาทีประจำวันที่ปรับเปลี่ยนตามช่องว่างทักษะปัจจุบันของคุณ

### 7-2. ระบบติดตามความครอบคลุมทางการแพทย์แบบเรียลไทม์

แผงแสดงผลแบบพับเก็บได้ที่ช่วยทำเครื่องหมายหัวข้อการซักประวัติขณะที่คุณพูด:

- ติดตามรายการซักประวัติอัตโนมัติตามบริบทบทสนทนา AI
- ตรวจสอบระยะเวลา/จุดเริ่มต้น, ลักษณะอาการปวด, การร้าว, ปัจจัยกระตุ้น/บรรเทา, อาการร่วม, ICE (ความคิด, ความกังวล, ความคาดหวัง), ประวัติอดีต, ยา, การแพ้ยา, แอลกอฮอล์/บุหรี่, ประวัติครอบครัว ฯลฯ
- ประโยคคำถามปฏิเสธ เช่น _"คุณไม่ได้สูบบุหรี่ใช่ไหม?"_ สามารถตรวจจับและทำเครื่องหมายติดตามได้อย่างถูกต้อง

### 7-3. ตัวช่วยแนะนำประโยคถัดไปตามบริบท (`💡 Help me continue`)

หากคุณติดขัดหรือนึกคำถามไม่ออกระหว่างเซสชัน ให้แตะปุ่ม **💡 Help me continue** ด้านล่างหน้าจอ

- ระบบจะวิเคราะห์คำตอบล่าสุดของผู้ป่วยเพื่อแนะนำเป้าหมายคำถามถัดไปที่เหมาะสม พร้อม **ประโยคตัวอย่างภาษาอังกฤษที่พร้อมใช้งาน**
- ตัวติดตามขั้นตอนการสัมภาษณ์ด้านบนจะแสดงความก้าวหน้าด้วยสัญลักษณ์:
  - `✓`: ตรวจพบหลักฐานครบถ้วน
  - `•`: ตรวจพบการกล่าวถึงบางส่วน
  - `?`: ข้ามมาถึงขั้นตอนหลังโดยยังไม่ได้ยืนยันขั้นตอนก่อนหน้า

## 8. โหมดสอบและการประเมินผล (วัดระดับ 10 นาทีตามมาตรฐาน CEFR)

วัดระดับความสามารถในการสื่อสารภายใต้สภาวะการสอบจับเวลาที่สมจริง:

### การทดสอบประเมินภาษาอังกฤษทางการแพทย์ระดับพื้นฐาน 10 นาที

- เริ่มต้นด้วยการแนะนำตัวของผู้สอบ จากนั้นทำแบบทดสอบสั้น 4 ข้อ (อธิบายการวินิจฉัยโรค, ตอบคำถามติดตามผล, นำเสนอส่งเวร SBAR 45 วินาที, ตอบคำถามสัมภาษณ์แพทย์ประจำบ้าน)
- จัดระดับผลการประเมินตามมาตรฐาน **CEFR** อัตโนมัติ:
  - **คะแนน >= 8.5**: **C1** (คล่องแคล่ว สื่อสารทางคลินิกได้อย่างปลอดภัยระดับแพทย์อาวุโส)
  - **คะแนน >= 7.2**: **B2+** (มีความสามารถเหมาะสมสำหรับการฝึกงานและการทำงานในโรงพยาบาล)
  - **คะแนน >= 6.0**: **B1-B2** (ความสามารถการสื่อสารพื้นฐาน แนะนำให้ศึกษาเพิ่มเติมอย่างเป็นระบบ)
  - **คะแนน < 6.0**: **A2-B1** (จำเป็นต้องรับการฝึกฝนการสื่อสารทางคลินิกระดับพื้นฐาน)

### สถานการณ์จำลองการสอบ

- **OSCE**: การซักประวัติผู้ป่วยอาการเจ็บหน้าอก Mr. Hayes (วัด ICE, การตรวจหาอาการอันตราย Red Flags, ความเห็นอกเห็นใจ)
- **OET Speaking**: บทบาทสมมติติวผู้ป่วยโรคความดันโลหิตสูง
- **Residency**: การสัมภาษณ์จำลองกับผู้อำนวยการหลักสูตรอายุรศาสตร์ สหรัฐฯ
- **การนำเสนอเคสบนวอร์ด**: การนำเสนอเคสโรคปอดบวมติดเชื้อจากชุมชน 5 นาทีและการตอบคำถามปากเปล่า

### สัญลักษณ์ความน่าเชื่อถือของคะแนน (Score Reliability Badge)

แสดงระดับความเชื่อมั่นในการให้คะแนนของ AI เป็น **สูง (High)**, **ปานกลาง (Medium)** หรือ **ต่ำ (Low)**:

- **สูง**: จำนวนคำของผู้เรียน >= 180 คำ & อัตราหลักฐาน Checklist >= 75%
- **ปานกลาง**: จำนวนคำของผู้เรียน >= 80 คำ & อัตราหลักฐาน Checklist >= 50%
- **ต่ำ**: จำนวนคำ < 80 คำ (ติดธงบทสนทนาสั้นเกินไป) หรืออัตราหลักฐาน < 50%

## 9. ห้องปฏิบัติการการออกเสียงและความชัดเจน (Pron Lab)

ตั้งอยู่ในแท็บด้านล่างลำดับที่ 3 (`🎙️ Pron Lab`) เป็นศูนย์ฝึกฝนเน้นย้ำความชัดเจนในการสื่อสารออกเสียงโดยเฉพาะ

### 💡 การฝึกที่เน้นความชัดเจนในการสื่อสาร (Intelligibility-Centered)

เป้าหมายไม่ใช่การเลียนแบบสำเนียงเจ้าของภาษา แต่คือ **"เพื่อนร่วมงานและผู้ป่วยชาวต่างชาติสามารถฟังเข้าใจสิ่งที่เราพูดได้อย่างชัดเจนโดยไม่เข้าใจผิดหรือไม่?"**

- การวิเคราะห์เสียงจะเน้นแนะนำเฉพาะจุดออกเสียงที่อาจก่อให้เกิดความเข้าใจผิดแก่ผู้ฟังเท่านั้น

### หมวดหมู่ข้อผิดพลาดและปุ่มตัวกรอง (Filter Chips)

ข้อผิดพลาดการออกเสียงที่ตรวจพบจะถูกจัดกลุ่มตามหมวดหมู่ไว้ในปุ่มตัวกรอง:

- `r · l`: _liver / river_, _clinical / critical_
- `f · p`: _fever / peter_, _palpation / falcation_
- `th`: _think / tink_, _throat / troat_
- `final`: การละเสียงพยัญชนะท้าย (_chest / ches_)
- `cluster`: การควบกล้ำและการเติมเสียงสระโดยไม่จำเป็น (_cardiac_ → _cardi-ack-eu_)
- `stress`: การเน้นเสียงคำศัพท์ทางการแพทย์ผิดตำแหน่ง (_angina_, _arrhythmia_)
- `vowel`: สับสนเสียงสระสั้นและสระยาว (_ship / sheep_, _fit / feet_)

### กฎการเลื่อนสถานะสังเกตการณ์ (Observed State)

เมื่อการ์ดการออกเสียงถูกบันทึกครั้งแรก การ์ดจะอยู่ในสถานะ **สังเกตการณ์ (Observed)** ก่อน ยังไม่ถูกเพิ่มเป็นบ้านการบ้านการทบทวนทันที โดยการ์ดจะถูกเลื่อนเป็นรายการทบทวน SRS ก็ต่อเมื่อพบรูปแบบข้อผิดพลาดเดียวกันซ้ำในเซสชันอื่น เพื่อป้องกันไม่ให้ความผิดพลาดของระบบจำเสียงเพียงครั้งเดียวกลายเป็นภาระการบ้านที่มากเกินไป

## 10. ภาษาอังกฤษเพื่อการเอาตัวรอดและห้องปฏิบัติการฟัง

เตรียมความพร้อมแพทย์ IMG สำหรับการปฏิสัมพันธ์นอกห้องตรวจภายในโรงพยาบาลจริง

- **โหมดสุ่ม / ประหลาดใจ**: ฝึกรับมือสถานการณ์ไม่คาดคิดทันที (คำถามตามทางเดิน, การโทรกลับจากห้องยา, การคุยเล่นกับพยาบาล) โดยซ่อนบริบทไว้จนกว่า AI จะเริ่มพูด
- **การคุยเล่นโต้ตอบเร็ว**: ฝึกตอบโต้การเปลี่ยนหัวข้อสนทนาอย่างรวดเร็ว
- **โปรไฟล์สำเนียงเจ้าของภาษา 15 แบบ**: ฝึกปรับตัวเข้ากับสำเนียงและจังหวะการพูดที่หลากหลายจากทั่วโลก
- **การควบคุมความเร็วเสียงเรียลไทม์ (0.5× ถึง 2.5×)**: แถบปรับความเร็วเสียงที่ไม่เปลี่ยนระดับเสียงพูด ช่วยในการฝึกฟังคนพูดเร็ว
- **โหมดฟังอย่างเดียว (Ear-only)**: ซ่อนคำบรรยายบทสนทนา AI เพื่อให้คุณพึ่งพาการฟังเพียงอย่างเดียว โดยมีปุ่ม **[แสดงบรรทัดล่าสุด]** ให้กดดูได้เมื่อจำเป็น
- **การส่งเสริมการใช้ประโยคขอความช่วยเหลือ**: การใช้ประโยคซักถามซ้ำ เช่น _"Sorry?", "Could you say that again?"_ จะได้รับ **คะแนนโบนัส** แทนการถูกหักคะแนน
- **ห้องปฏิบัติการฟัง (Listening Lab)**: แบบฝึกหัดทดสอบความถูกต้องในการจับใจความรายละเอียด (ตัวเลข, ขนาดยา, ชื่อผู้ป่วย, เวลา, ทิศทาง, ราคา) พร้อมคะแนนความแม่นยำรายข้อ

## 11. การอธิบายบทเรียนคืน (Lecture Teach-back / เทคนิค Feynman)

ใช้เทคนิค Feynman—การอธิบายแนวคิดออกมาดังๆ เสมือนกำลังสอนผู้อื่น—เพื่อตกผลึกความรู้ทางการแพทย์

1. **เตรียมเนื้อหาบทเรียน**: วางสรุปเนื้อหา หรือใส่ URL วิดีโอการเรียนการสอนทางการแพทย์จาก YouTube แล้วแตะ **`🎬 Fetch YT transcript`**
2. **การย่อความด้วย AI**: สำหรับเนื้อหาที่ยาว ให้แตะ **`✨ Condense`** เพื่อย่อเนื้อหาเป็นโครงร่าง 500 คำ
3. **เลือกบุคลิกผู้ฟัง**:
   - **ศาสตราจารย์สอบปากเปล่า**: ถามคำถามท้าทายเชิงคลินิกประเภท "ทำไม" และ "ถ้าหากว่า"
   - **เพื่อนร่วมชั้นที่กำลังสับสน**: ต้องการคำอธิบายภาษาพูดที่เข้าใจง่ายโดยไม่ใช้คำศัพท์ยากๆ
   - **ติวเตอร์ใจดี**: ให้กำลังใจและช่วยเกลาประโยค
4. **เริ่มสอน**: แตะ **Start** แล้วอธิบายผ่านไมโครโฟน โดย AI ผู้ฟังจะถามคำถามซักถามกลับเป็นระยะ

## 12. การจำลองสัมภาษณ์การฝึกงานแพทย์ (Residency Mock Interviews)

จำลองการสัมภาษณ์สมัครงานโรงพยาบาลต่างประเทศและการสมัคร Residency สหรัฐฯ ที่สมจริง:

- **ด้านพฤติกรรม (Behavioral)**: ใช้โครงสร้าง STAR (Situation, Task, Action, Result) ในการเล่าประสบการณ์
- **ด้านคลินิก (Clinical)**: การนำเสนอเคสปากเปล่า จริยธรรมทางการแพทย์ และตรรกะการรับมือภาวะฉุกเฉิน
- **เฉพาะสำหรับ IMG**: เน้นคำถามที่พบบ่อยสำหรับแพทย์จบต่างประเทศ (การขอวีซ่า, การอธิบายช่องว่างใน CV, จุดเด่นเฉพาะของ IMG)
- AI ผู้ดำเนินรายการสัมภาษณ์จะถามคำถามเจาะลึกอย่างสุภาพ

## 13. ห้องสนทนาภาษาอังกฤษเสรีและสถานการณ์แบบกำหนดเอง

### ห้องสนทนาภาษาอังกฤษเสรี

- พูดคุยประเด็นทางการแพทย์ปัจจุบัน สรุปวารสารวิชาการ แก้ไขความขัดแย้งในที่ทำงาน หรือฝึกคุยเล่นช่วงพักกาแฟ
- ดึงซับไตเติลข่าวทางการแพทย์จาก YouTube มาพูดคุยโต้ตอบกับ AI ได้อย่างอิสระ

### สถานการณ์แบบกำหนดเอง

สร้างสถานการณ์ฝึกซ้อมตามความต้องการของคุณ:

- **ชื่อสถานการณ์**: ชื่ออ้างอิงสถานการณ์
- **บุคลิก / บริบท**: คำสั่งระบบกำหนดบทบาทและสถานการณ์ของ AI
- **แม่แบบการประเมิน**: เลือกเกณฑ์การประเมิน (เช่น SPIKES protocol สำหรับการแจ้งข่าวร้าย)
- **เกณฑ์ประเมินแบบกำหนดเอง**: กำหนดจุดประเมินสำคัญเฉพาะเพื่อให้ AI ช่วยตรวจสอบ

## 14. การวิเคราะห์รายงานผลป้อนกลับ (7 ส่วนหลัก)

เมื่อจบเซสชัน ระบบจะสร้างรายงานประเมินผลอย่างครอบคลุมใน 7 ส่วน:

1. **คะแนน (Scores)**: เปรียบเทียบคะแนน AI รายด้าน (0–10) กับการประเมินตนเองของคุณ หากมีความต่าง **2.0 คะแนนขึ้นไป** ระบบจะแสดงการ์ด **คำถามชวนคิด (Reflection Prompt)** สีเหลืองเพื่อช่วยทบทวนตนเอง
2. **ความคล่องแคล่ว (Fluency)**:
   - **WPM (จำนวนคำต่อนาที)**: วัดความเร็วในการพูดเปรียบเทียบกับเป้าหมายที่แนะนำ (100–130 WPM)
   - **คำฟุ่มเฟือย (Filler Words)**: วัดความถี่ของคำฟุ่มเฟือย (_um_, _uh_, _like_) เพื่อส่งเสริมการใช้จังหวะหยุดพูดอย่างมีประสิทธิภาพ
3. **Checklist**: ประเมินเป้าหมายทางคลินิก พร้อมอ้างอิงประโยคจริงจากบทสนทนาเป็น **หลักฐาน (Evidence)**
4. **เปรียบเทียบ SOAP Note**: เปรียบเทียบ SOAP Note ที่สร้างให้อัตโนมัติจากเซสชันของคุณกับ SOAP Note อ้างอิงตัวอย่าง
5. **รายการแก้ไข (Corrections)**: การ์ดข้อแก้ไขสำหรับการแปลตรงตัว, คำหน้านาม/พหูพจน์, ประโยคที่ไม่เป็นธรรมชาติ และการออกเสียง การแตะ **[ยอมรับ (Accept)]** จะบันทึกรายการเข้าสู่ระบบทบทวน SRS จุดอ่อนของคุณ
6. **การฝึกพูดตาม (Shadowing)**: เกลาประโยคที่อ่อนให้เป็นภาษาอังกฤษทางการแพทย์ระดับแพทย์อาวุโสสำหรับการฝึกฟังและพูดตาม
7. **สรุปและการ์ดแบ่งปัน (Summary & Share Cards)**: แสดงผลสรุปภาพรวมและมีระบบสร้าง **การ์ดแบ่งปัน (Share Card)** สำหรับส่งภาพสรุปผลงานให้เพื่อนร่วมชั้นเรียน

## 15. ครูผู้สอน AI สไตล์ โสเครติส และโค้ชเสียง 1:1 (Socratic AI Tutor & Always-On 1:1 Voice Coach)

### 15-1. ถอดบทเรียนกับครูผู้สอน AI สไตล์โสเครติส (`[Debrief with AI Tutor]`)

การแตะปุ่ม **[Debrief with AI Tutor]** ที่ด้านล่างของรายงานผลป้อนกลับจะเปิดห้องแชท 1:1 กับครูผู้สอน AI

- ระบบจะถามคำถามนำทางแทนการบอกคำตอบตรงๆ ช่วยให้คุณค้นพบและแก้ไขข้อผิดพลาดได้ด้วยตนเอง
- ประวัติการแชทจะถูกบันทึกไว้ในฐานข้อมูล เพื่อให้คุณกลับมาคุยต่อได้ตลอดเวลา

### 15-2. ปุ่มโค้ชเสียง 1:1 ที่พร้อมใช้งานเสมอ (หน้าแรก FAB)

การแตะ **ปุ่มลอยโค้ชเสียง (`🎙️ RecordVoiceOver`)** ที่มุมขวาล่างของหน้าแรกจะเปิดบทสนทนากับโค้ชเสียงได้ทันทีโดยไม่ต้องเริ่มเคสเต็ม

- โค้ช AI จะดำเนินบทสนทนาโต้ตอบ 1:1 ตามประวัติจุดอ่อน SRS สะสมของคุณ

## 16. ระบบติดตามข้อผิดพลาดแบบเว้นระยะทบทวน (Spaced Repetition Error Tracker & Mistake Genome)

รายการแก้ไขที่กด **[ยอมรับ]** จะถูกบริหารจัดการด้วยอัลกอริทึมเว้นระยะทบทวนในฐานข้อมูลข้อผิดพลาดของคุณอัตโนมัติ

- **การตรวจจับข้อผิดพลาดซ้ำ (Fuzzy Duplicate Detection)**: ป้องกันการบันทึกข้อผิดพลาดที่คล้ายกันซ้ำซ้อนโดยอัตโนมัติ
- **ข้อผิดพลาดฝังลึก (Leech / Stubborn Errors)**: รายการที่ทำผิดติดต่อกัน 4 ครั้งขึ้นไปในการทดสอบทบทวนจะถูกติดป้าย **ฝังลึก (Stubborn)** เพื่อการดูแลเป็นพิเศษ
- **ช่วงเวลาการเว้นระยะทบทวนตามหลักวิทยาศาสตร์**:
  - ตารางทบทวน: **1 วัน → 3 วัน → 7 วัน → 14 วัน → 30 วัน** การผ่านการทดสอบ 3 ครั้งติดต่อกันจะเลื่อนรายการเป็น **เชี่ยวชาญแล้ว (Mastered)**
  - การผ่านแบบทดสอบเสียงในโหมด **การฝึกฝนข้อผิดพลาดของฉัน** จะช่วยเลื่อนสถานะรายการสู่ความเชี่ยวชาญ
- **แผง Mistake Genome**:
  - แสดงหมวดหมู่ข้อผิดพลาดจุดอ่อน 5 อันดับแรก (คำหน้านาม, พหูพจน์, Tense, บุพบท, ระดับภาษา, การแปลตรงตัว) เป็นกราฟแท่งบนหน้าแรกพร้อมคำอธิบายภาษาพูด

## 17. การนำเสนอเคสแก่แพทย์อาวุโส (Attending Case Presentation Chaining)

ฝึกทักษะการรายงานเคสปากเปล่าแก่แพทย์นิเทศก์หลังจากจบเซสชันการตรวจรักษาผู้ป่วย:

1. ทำเซสชัน **การตรวจรักษาผู้ป่วย** ให้เสร็จสิ้น
2. ไปที่แท็บ **ประวัติ (History)** เลือกเซสชันนั้นแล้วแตะ **`📋 Present Case`**
3. แพทย์อาวุโส AI จะเริ่มทักทาย: _"คุณหมอ ช่วยรายงานเคสที่คุณหมอเพิ่งตรวจไปให้ฟังหน่อยครับ"_
4. นำเสนอเคสปากเปล่าตามรูปแบบ SBAR หรือ SOAP และตอบคำถามเพิ่มเติมเกี่ยวกับการวินิจฉัยแยกโรคและแผนการรักษา

## 18. การนำเข้าประวัติการสนทนาจากภายนอก (Import Transcript)

นำเข้าข้อความบทสนทนาจาก ChatGPT, Gemini หรือโน้ตทางคลินิกเข้ามาในแอปเพื่อรับรายงานผลประเมินฉบับเต็ม:

1. **การแชร์ผ่านระบบ Android**: ไฮไลต์ข้อความสนทนาในแอปภายนอก แล้วเลือก **[แชร์] → [Bedside English]** เพื่อเปิดหน้า **นำเข้าบทสนทนา** อัตโนมัติ
2. **การป้อนตรง / วางข้อความ**: เปิดหน้า `Import Transcript` โดยตรงจากการตั้งค่าหรือเมนูหลัก แล้ววางข้อความลงไป
3. **รายงานประเมินและ SRS อัตโนมัติ**: สร้างคะแนนรายด้าน, SOAP Note และการ์ดข้อแก้ไขที่สามารถกดบันทึกเข้า SRS ได้ทันที

## 19. การส่งออกการ์ด Anki และเอกสาร Word

- **การส่งออกการ์ด Anki (`.txt` คั่นด้วยแท็บ)**:
  - แปลงรายการข้อแก้ไขที่ยอมรับแล้วเป็นไฟล์นำเข้าแบบข้อความของ Anki (ไฟล์ → นำเข้า ใน Anki / AnkiDroid) โดยหมวดหมู่ของแต่ละข้อผิดพลาดจะติดไปเป็นแท็ก สามารถใช้ได้ทั้งบนหน้าจอผลป้อนกลับหลังจบเซสชัน และจากหน้า **My Mistakes** ซึ่งจะส่งออกรายการทบทวนทั้งหมดของคุณในครั้งเดียว
- **การส่งออกรายงาน Word (`.docx`)**:
  - สร้างรายงานทางการแพทย์ที่มีโครงสร้างสวยงาม ประกอบด้วยคะแนน, หลักฐาน Checklist, SOAP Note และประโยคแก้ไข โดยเปิดการบันทึกอัตโนมัติได้ในเมนูการตั้งค่า

## 20. วิกิช่วยเหลือในแอป (In-App Help Wiki)

การแตะ **ไอคอนช่วยเหลือ `?`** ในแถบแอปด้านบนจะเปิดหน้าต่างวิกิช่วยเหลือในรูปแบบเต็มหน้าจอ

- **การรองรับหลายภาษา**: โหลดคู่มือผู้ใช้ฉบับภาษาที่ตรงกับการตั้งค่าภาษาแอปโดยอัตโนมัติ
- **แถบสารบัญ (TOC Sidebar)**: ช่วยให้กดข้ามไปยังหัวข้อต่างๆ ในคู่มือได้อย่างรวดเร็ว
- **การค้นหาข้อความเต็ม**: ใส่คีย์เวิร์ดในช่องค้นหาเพื่อไฮไลต์คำที่ตรงกันและกดเลื่อนดูด้วยปุ่มก่อนหน้า/ถัดไป
- **ลิงก์ภายนอก**: การแตะลิงก์เว็บในคู่มือจะเปิดเบราว์เซอร์หลักของอุปกรณ์ขึ้นมา

## 21. การตั้งค่าภาษา แอปพลิเคชัน การติดตามค่าใช้จ่าย API และการตั้งค่าอื่นๆ (UI Language Settings, API Cost Tracking & Preferences)

เข้าใช้งาน **เฟืองการตั้งค่า (⚙️)** ในแถบด้านบนเพื่อปรับแต่งแอปให้เหมาะกับอุปกรณ์และงบประมาณของคุณ:

- **เสียงและผลป้อนกลับ**:
  - เลือกโมเดล AI สำหรับเสียงและผลป้อนกลับ (Demo, Gemini, OpenAI, Claude)
  - **การป้องกันเสียงสะข้อง**: ปิดไมโครโฟนอัตโนมัติขณะ AI กำลังพูด เพื่อป้องกันเสียงวนสะท้อน (จำเป็นเมื่อไม่ได้ใช้หูฟัง)
  - **ความเร็วการพูดของ AI**: ปรับความเร็วได้เป็นระดับ (ช้า, ปกติ, เร็ว, ท้าทาย)
- **การวิเคราะห์ค่าใช้จ่าย API**: แสดงสถิติการใช้โทเคนและประมาณการค่าใช้จ่ายเป็นดอลลาร์ต่อเซสชันอย่างโปร่งใสพร้อมกราฟ
- **ระบบเสียง**: แถบวัดระดับเสียงไมโครโฟนแบบเรียลไทม์และระบบทดสอบเสียงลำโพง
- **คีย์ API**: ระบบจัดการคีย์จัดเก็บแบบเข้ารหัสในเครื่อง
- **การส่งออกและการเรียนรู้**: ตัวเลือกบันทึก Docx อัตโนมัติ, การบังคับใส่ SOAP Note, ภาษาแม่ และภาษาของแอป
- **ข้อมูล**: เปิดปิดการวิเคราะห์การออกเสียง ตั้งค่าเอนจินเสียง TTS
- **ความเป็นส่วนตัว**: เปิดปิดการส่งสถิติการใช้งานแบบไม่ระบุตัวตน

## 22. คำถามที่พบบ่อย (FAQ) และเกณฑ์การให้คะแนน

### คำถามที่พบบ่อย (FAQ)

**Q: ไมโครโฟนไม่จับเสียงพูดและ AI ไม่ตอบสนอง**

- ตรวจสอบที่ **การตั้งค่า Android → แอป → Bedside English → สิทธิ์การใช้งาน → ไมโครโฟน** แล้วตั้งเป็น [อนุญาต] หากสิทธิ์ถูกปฏิเสธ แอปจะเปลี่ยนเป็นโหมด **เปลี่ยนเป็นพิมพ์** ให้คุณฝึกต่อด้วยแป้นพิมพ์ได้

**Q: โหมดฝึกฝนขั้นสูง (การสอบ, การอธิบายบทเรียน, การสัมภาษณ์, ห้องสนทนาเสรี, กำหนดเอง) หายไป**

- ทำเซสชันฝึกซ้อมแรกให้เสร็จสิ้น แล้วโหมดขั้นสูงทั้งหมดจะปลดล็อกให้อัตโนมัติพร้อมข้อความแสดงความยินดี หรือแตะปุ่มขยายเพื่อเปิดดูทั้งหมดได้จากหน้าการฝึกฝน

**Q: ผลการวิเคราะห์การออกเสียงไม่เข้าไปอยู่ในฐานข้อมูลทบทวน SRS ทันที**

- เพื่อป้องกันไม่ให้ความผิดพลาดครั้งเดียวของระบบจำเสียงกลายเป็นภาระแก่ผู้เรียน รายการออกเสียงที่ยอมรับจะเข้าสู่สถานะ **สังเกตการณ์ (Observed)** ก่อน โดยจะเลื่อนเป็นการ์ดทบทวน SRS ก็ต่อเมื่อพบรูปแบบข้อผิดพลาดเดิมซ้ำในเซสชันถัดไป

**Q: สามารถนำเข้าบทสนทนาจากภายนอก (เช่น ChatGPT) มาให้แอปประเมินได้หรือไม่?**

- ได้ โดยใช้ฟีเจอร์แชร์ของ Android แชร์ข้อความมายัง Bedside English หรือวางข้อความลงในหน้า `Import Transcript` เพื่อรับผลประเมินเต็มรูปแบบ, SOAP Note และการ์ดแก้ไข
