# Bedside English ব্যবহারকারী গাইড

**টার্গেট অডিয়েন্স:** ইন্টারন্যাশনাল মেডিকেল গ্র্যাজুয়েট (IMGs), রেসিডেন্ট চিকিৎসক, মেডিকেল শিক্ষার্থী এবং স্বাস্থ্যসেবা পেশাজীবী যারা ক্লিনিক্যাল ইংলিশ, OSCE, OET Speaking, ইউএস রেসিডেন্সি ইন্টারভিউ, ওয়ার্ড রাউন্ড প্রেজেন্টেশন এবং ক্লিনিক্যাল যোগাযোগের প্রস্তুতি নিচ্ছেন।

Bedside English হলো একটি অ্যান্ড্রয়েড-এক্সক্লুসিভ অ্যাপ যা কনভারসেশনাল এআই (Google Gemini, OpenAI Realtime, Anthropic Claude) এবং রিয়েল-টাইম ভয়েস টেকনোলজি দ্বারা পরিচালিত। এটি ক্লিনিক্যাল যোগাযোগ দক্ষতা, মেডিকেল লজিক, উচ্চারণ এবং বাক্যের স্পষ্টতা বহু-মাত্রিকভাবে উন্নত করার জন্য ডিজাইন করা হয়েছে। এই গাইডে ব্যবহারকারীদের জন্য তৈরি সর্বশেষ অ্যাপ সংস্করণের সমস্ত বৈশিষ্ট্য এবং ব্যবহারের বিবরণ দেওয়া হয়েছে।

## 1. API কী সেটআপ এবং কনফিগারেশন

Bedside English নমনীয়ভাবে Google Gemini, OpenAI এবং Anthropic Claude ব্যাকএন্ড সাপোর্ট করে।

### 💡 সুপারিশকৃত সেটআপ (Google Gemini একক কী মোড)

**একটি মাত্র Google Gemini API কী রেজিস্টার করলে রিয়েল-টাইম ভয়েস সেশন থেকে শুরু করে সেশন-পরবর্তী ফিডব্যাক বিশ্লেষণ পর্যন্ত অ্যাপের প্রতিটি সুবিধা সবচেয়ে দ্রুত ও সাশ্রয়ী উপায়ে ব্যবহার করা যায়।**

| সার্ভিস                | প্রধান উদ্দেশ্য                                                    | প্রয়োজনীয়তা                              | লিংক                                                   |
| :--------------------- | :----------------------------------------------------------------- | :----------------------------------------- | :----------------------------------------------------- |
| **Google (Gemini)**    | রিয়েল-টাইম ভয়েস কনভারসেশন (Gemini Live) + গভীর ফিডব্যাক বিশ্লেষণ | **প্রয়োজনীয় (একক কী সব ফিচার কভার করে)** | [aistudio.google.com](https://aistudio.google.com)     |
| **OpenAI**             | রিয়েল-টাইম ভয়েস (OpenAI Realtime) + ফিডব্যাক + প্রিমিয়াম টিটিএস | ঐচ্ছিক                                     | [platform.openai.com](https://platform.openai.com)     |
| **Anthropic (Claude)** | সেশন ফিডব্যাক বিশ্লেষণ (নির্বাচনযোগ্য ব্যাকএন্ড)                   | ঐচ্ছিক (Gemini ডিফল্ট)                     | [console.anthropic.com](https://console.anthropic.com) |

### API কী ইনপুট এবং নিরাপত্তা

API কী সরাসরি অ্যাপের ভেতরে ইনপুট দেওয়া হয়:

- **প্রথমবার ব্যবহারের অনবোর্ডিং উইজার্ড (First-Run Onboarding Wizard)** এর মাধ্যমে অথবা উপরের বারের **সেটিংস গিয়ার (⚙️) → Preferences → API Keys** মেনু থেকে কনফিগার করুন।
- ইনপুট দেওয়া API কীগুলো ডিভাইসের এনক্রিপ্টেড স্টোরেজে (`EncryptedSharedPreferences`) **নিরাপদে সংরক্ষিত থাকে** এবং কখনোই বাইরের সার্ভারে পাঠানো হয় না।
- প্রতিটি কী ফিল্ডের ডান পাশে একটি চোখ আইকন থাকে যা দিয়ে কী দৃশ্যমানতা টগল করা যায়।

### 🎈 ডেমো মোড (সম্পূর্ণ বিনামূল্যে ট্রায়াল)

আপনি যদি API কী রেজিস্টার না করে বা মাইক্রোফোনের অনুমতি না দিয়ে অ্যাপটি অভিজ্ঞতা করতে চান, তবে অনবোর্ডিং স্ক্রিনে বা **Preferences** এর অধীনে **Demo** মোড বেছে নিন।
প্রস্তুতকৃত (scripted) নমুনা কথোপকথন এবং ফিডব্যাক ডেটা লোড হবে, যা আপনাকে কোনো টোকেন খরচ না করেই **বিনামূল্যে** পুরো UI, এরর ট্র্যাকার এবং রিভিউ বৈশিষ্ট্যগুলো অন্বেষণ করতে দেবে। একটি ডেমো সেশন সম্পন্ন করার পর, একটি প্রম্পট আপনাকে একটি API কী ইনপুট দিতে বা যেকোনো সময় পরবর্তী ডেমো রোগীর অনুশীলনে চালিয়ে যেতে দেয়।

## 2. অ্যাপ ইনস্টলেশন এবং পারমিশন সেটআপ

Bedside English অ্যান্ড্রয়েড ৮.০ (API লেভেল ২৬) বা তার উপরের সংস্করণে চলমান স্মার্টফোন এবং ট্যাবলেটে চলে।

### অ্যাপ ইনস্টলেশন

- আপনার অ্যান্ড্রয়েড ডিভাইসে প্রদান করা ইনস্টলেশন ফাইলটি (`.apk`) চালু করুন এবং ইনস্টল করতে স্ক্রিনের নির্দেশাবলী অনুসরণ করুন।

### মাইক্রোফোন পারমিশন এবং টাইপিং মোড (Type-instead Mode)

- প্রথমবার লাইভ ভয়েস প্র্যাকটিস মোড চালু করার সময়, অ্যান্ড্রয়েড OS মাইক্রোফোন অ্যাক্সেসের অনুমতি চায়। ভয়েস রিকগনিশন সঠিকভাবে কাজ করার জন্য **[Allow]** এ ট্যাপ করুন।
- আপনি যদি এমন কোনো পরিবেশে থাকেন যেখানে কথা বলা কঠিন অথবা অনুমতি অস্বীকার করা হয়, অ্যাপটি ক্র্যাশ করবে না। এটি স্বয়ংক্রিয়ভাবে **Type instead (টাইপ করুন)** মোডে চলে যায়, যা আপনাকে কিবোর্ড ব্যবহার করে কথোপকথন অনুশীলন করার অনুমতি দেয়।

### নোটিফিকেশন পারমিশন এবং অডিও প্রাক-পরীক্ষা (Audio Preflight)

- ব্যাকগ্রাউন্ড ফিডব্যাক বিশ্লেষণ সম্পন্ন হলে নোটিফিকেশন পাওয়ার জন্য নোটিফিকেশনের অনুমতি চাওয়া হয়।
- আপনার প্রথম লাইভ ভয়েস সেশন শুরু করার ঠিক আগে, হেডফোন ব্যবহারের নির্দেশনা দিতে এবং স্পিকারের ফিডব্যাক লুপ (howling) রোধ করতে মাইক্রোফোন ইনপুট লেভেল পরীক্ষা করার জন্য একটি **Audio Preflight** মডাল প্রদর্শিত হয়।

## 3. প্রথমবার অ্যাপ ব্যবহার এবং মাতৃভাষা (L1) কাস্টমাইজেশন

অ্যাপটি প্রথমবার চালু করার সময়, একটি কাস্টমাইজড শেখার পরিবেশ তৈরি করতে ৪-ধাপের সেটআপ উইজার্ড চলে:

1. **স্বাগতম স্ক্রিন (Welcome Screen)**: মূল বৈশিষ্ট্যগুলোর সাথে পরিচয় করিয়ে দেয় এবং API কী ছাড়া অন্বেষণ করতে একটি **Try Demo Mode** বোতাম প্রদান করে।
2. **UI ভাষা নির্বাচক (UI Language Picker)**: আপনার পছন্দের ইন্টারফেস ভাষা নির্বাচন করুন (৮টি সমর্থিত ভাষা: ইংরেজি, কোরিয়ান, স্প্যানিশ, চীনা, আরবি, হিন্দি, পর্তুগিজ, তাগালগ)।
3. **API কী সেটআপ (API Keys Setup)**: আপনার Google Gemini বা অন্যান্য এআই API কী রেজিস্টার করুন।
4. **মাতৃভাষা ও গোপনীয়তা (Native Language & Privacy)**: আপনার প্রথম ভাষা নির্বাচন করুন (যেমন, **কোরিয়ান**, চীনা, স্প্যানিশ, আরবি, হিন্দি, তাগালগ, পর্তুগিজ)। এটি আপনার মাতৃভাষার নির্দিষ্ট ব্যাঘাতের ধরণগুলোর (interference patterns) ওপর ভিত্তি করে সুনির্দিষ্ট ব্যাকরণ এবং উচ্চারণ বিশ্লেষণ সক্রিয় করে।

### 🌐 L1 মাতৃভাষা কাস্টমাইজেশন হাইলাইটস (যেমন কোরিয়ান L1 শিক্ষার্থী)

- **ব্যাকরণ ও বাক্য গঠন সংশোধন (Grammar & Phrasing Corrections)**:
  - আর্টিকেল বাদ দেওয়া (বিশেষ্যের আগে _a/an/the_ বাদ দেওয়া)
  - বহুবচন _-s_ বাদ দেওয়া (_two patient_ → _two patients_)
  - টেন্সের ভুল (অতীত মেডিকেল ইতিহাস আলোচনার সময় বর্তমান কাল ব্যবহার)
  - প্রিপজিশন ভুল ব্যবহার (_in hospital_, _explain to patient_ এ প্রিপজিশন বাদ পড়া)
  - আক্ষরিক সরাসরি অনুবাদ / কঙ্গলিশ (Konglish) (_skin scale_, _side effect_ এর বেমানান আক্ষরিক অনুবাদ)
- **উচ্চারণ ও স্পষ্টতা সংশোধন (Pronunciation & Intelligibility Corrections)**:
  - _r / l_ ন্যূনতম জোড়া পার্থক্য (_liver_ বনাম _river_)
  - _f / p_ পার্থক্য (_fever_ বনাম _peter_)
  - _th_ ডেন্টাল ফ্রিক্যাটিভ উচ্চারণ (_think_ বনাম _tink_)
  - শব্দের শেষ ব্যঞ্জনবর্ণ বাদ দেওয়া এবং অনাবশ্যক স্বরধ্বনি যুক্ত করা (_cardiac_ → _cardi-ack-eu_)
  - মেডিকেল শব্দের ভুল স্থানে জোর (Stress) দেওয়া (_angina_, _arrhythmia_)

### 💡 ইন্টারেক্টিভ প্রথম ব্যবহার নির্দেশিকা (Interactive First-Run Tour)

অনবোর্ডিং সম্পন্ন করে ড্যাশবোর্ডে প্রথমবার প্রবেশের পর, একটি ইন্টারেক্টিভ টিউটোরিয়াল আপনাকে প্রধান বোতামগুলোর (Dashboard, Practice Hub, Pron Lab, SRS Reviews, History, Help, 1:1 Voice Coach) অবস্থান এবং ফাংশনগুলো দিয়ে স্বয়ংক্রিয়ভাবে গাইড করে।

## 4. ইউজার ইন্টারফেস ওভারভিউ (নিচের ৫টি ট্যাব এবং সাহায্য)

### নিচের নেভিগেশন বার (৫টি ট্যাব)

প্রধান নেভিগেশন ৫টি নিচের ট্যাব নিয়ে গঠিত:

```
┌───────────┬──────────────┬───────────────────────┬───────────────┬─────────────┐
│  🏠 Home  │  ▶ Practice  │  🎙️ Pronunciation Lab │  ⚠️ SRS Reviews│  🕘 History │
└───────────┴──────────────┴───────────────────────┴───────────────┴─────────────┘
```

1. **Home (ড্যাশবোর্ড)**: প্র্যাকটিস স্ট্রিক (Practice streak `🔥`), ৫-মিনিটের ক্লিনিক্যাল মিশন, পারফর্ম্যান্স ট্রেন্ড চার্ট, মিস্টেক জিনোম (Mistake Genome), রোডম্যাপ এবং **সবসময় সচল ১:১ ভয়েস কোচ (Always-on 1:1 Voice Coach)**।
2. **Practice (প্র্যাকটিস হাব)**: সমস্ত রিয়েল-টাইম স্পিকিং মোডের কেন্দ্রীয় হাব: Patient Encounters, Exam & Diagnostic, Survival English, Teach-back, Interviews, Lounge এবং Custom Scenarios।
3. **Pronunciation Lab (Pron Lab / উচ্চারণ ল্যাব)**: স্পিচ স্পষ্টতা এবং উচ্চারণ সংশোধনের জন্য নিবেদিত প্রশিক্ষণ ট্যাব (ত্রুটি প্যাটার্ন ফিল্টারিং, পর্যবেক্ষণ স্থিতি পরিচালনা)।
4. **SRS Reviews (দুর্বলতা পর্যালোচনা)**: গৃহীত সংশোধন বাক্যগুলোর জন্য স্পেসড রিপিটেশন অ্যালগরিদমের ওপর ভিত্তি করে ভোকাল রিভিউ কুইজ।
5. **History (সেশন হিস্ট্রি)**: অতীতের সেশনগুলোর স্কোর এবং ফিডব্যাক দেখুন, টোকেন খরচ ট্র্যাক করুন, Anki/Word এ এক্সপোর্ট করুন এবং **অ্যাটেন্ডিং কেস প্রেজেন্টেশন (Present Case)** ট্রিগার করুন।

- **Bedside English লোগো**: মূল শিরোনাম।
- **হেল্প উইকি (`?` আইকন)**: `?` আইকনে ট্যাপ করলে সূচিপত্র নেভিগেশন এবং ফুল-টেক্সট কীওয়ার্ড অনুসন্ধান সহ এই ব্যবহারকারী গাইডটি ফুল-স্ক্রিন ভিউয়ারে খুলে যায়।
- **সেটিংস গিয়ার (⚙️ Preferences)**: API কী, ভয়েস ব্যাকএন্ড, কথা বলার গতি, ইকো প্রতিরোধ, ভাষা এবং ডেটা ব্যবস্থাপনা।

## 5. ড্যাশবোর্ড (Home) পুরোপুরি আয়ত্ত করা

প্রধান ড্যাশবোর্ড একাধিক মাত্রা জুড়ে ক্লিনিক্যাল ইংরেজি যোগাযোগের দক্ষতায় আপনার বৃদ্ধি দৃশ্যমানভাবে উপস্থাপন করে:

- **প্র্যাকটিস স্ট্রিক (Practice Streak)**: দৈনন্দিন অধ্যয়নের অভ্যাস গড়ে তুলতে একটি ফ্লেম আইকন (`🔥`) সহ টানা সক্রিয় প্র্যাকটিসের দিনগুলো প্রদর্শন করে।
- **কোর মেট্রিক কার্ডসমূহ (Core Metric Cards)**:
  - **Sessions done**: সম্পূর্ণ সম্পন্ন হওয়া এবং বিশ্লেষণ করা সেশনের মোট সংখ্যা।
  - **Errors tracked**: আপনার ব্যক্তিগত দুর্বলতা ডেটাবেসে নিবন্ধিত নিশ্চিতকৃত সংশোধনসমূহ।
  - **Mastered**: বারবার রিভিউ কুইজের মাধ্যমে সমাধানকৃত এবং গ্র্যাজুয়েট হওয়া ভুলসমূহ।
  - **Due now**: আজ ভোকাল রিভিউর জন্য নির্ধারিত SRS রিভিউ কার্ডের সংখ্যা।
  - **Stubborn**: "Leech" ত্রুটি যা টানা ৪+ বার ফসকে গেছে এবং ফোকাসড মনোযোগ প্রয়োজন।
- **আজকের ৫-মিনিটের ক্লিনিক্যাল মিশন (Today's 5-Minute Clinical Mission)**: স্বয়ংক্রিয়ভাবে একটি অপটিমাল ৫-মিনিটের প্র্যাকটিস কোর্স সুপারিশ করে যা ডিউ রিভিউ আইটেম, প্রয়োজনীয় ডায়াগনস্টিক বা আপনার সবচেয়ে দুর্বল স্কিল ডোমেইনকে টার্গেট করে।
- **OET লেইম্যান শব্দভাণ্ডার কভারেজ (OET Layman Vocabulary Coverage)**:
  - জটিল মেডিকেল পরিভাষার (যেমন, _syncope_) জন্য সাধারণ, রোগী-বান্ধব শব্দ (যেমন, _fainting_) প্রতিস্থাপনে আপনি কতটা কার্যকর তা ট্র্যাক করে।
  - ব্যবহৃত পদগুলো **Recently Unlocked (সম্প্রতি আনলকড)** এর অধীনে উপস্থিত হয়, আর অব্যবহৃত এক্সপ্রেশনগুলো **Next Goals (Locked) / পরবর্তী লক্ষ্য (লকড)** এর অধীনে সারিবদ্ধ থাকে।
- **মিস্টেক জিনোম প্যানেল (Mistake Genome Panel)**: আপনার সবচেয়ে ঘনঘন ত্রুটির বিভাগগুলো (আর্টিকেল, বহুবচন, টেন্স, প্রিপজিশন, রেজিস্টার, ডিরেক্ট ট্রান্সলেশন) বিশ্লেষণ করে এবং আপনার শীর্ষ ৫টি দুর্বল ক্ষেত্রকে বার চার্ট হিসাবে প্রদর্শন করে।
- **গ্রোথ ট্রেন্ডস এবং L1 ইন্টারফারেন্স চার্ট (Growth Trends & L1 Interference Chart)**:
  - আপনার গত ২০টি সেশনে ৫টি ডোমেইনে (Grammar, Accuracy, Reasoning, Professionalism, Fluency) স্কোর ট্রেন্ড গ্রাফ করে।
  - বারবার হওয়া ব্যাকরণগত ভুলের প্যাটার্নগুলো ভিজ্যুয়ালাইজ করে।
- **পার্সোনালাইজড রোডম্যাপ (Personalized Roadmap)**: ৪টি অগ্রাধিকারপ্রাপ্ত ফোকাস স্কিল কার্ড উপস্থাপন করতে দুর্বল মেট্রিক্স এবং ত্রুটির ইতিহাস বিশ্লেষণ করে।
- **সবসময় সচল ১:১ ভয়েস কোচ বোতাম (Always-On 1:1 Voice Coach Button - `🎙️ RecordVoiceOver`)**:
  - ড্যাশবোর্ডের নিচের ডানদিকে অবস্থিত। সম্পূর্ণ সেশন সিনারিও শুরু না করেই আপনার ব্যক্তিগত দুর্বলতা প্রোফাইলের ওপর ভিত্তি করে এআই টিউটরের সাথে তাত্ক্ষণিকভাবে একটি ১:১ ভোকাল স্পিকিং ডায়ালগ খুলতে ট্যাপ করুন।

## 6. প্র্যাকটিস হাব এবং ধাপে ধাপে ফিচার আনলক

### ধাপে ধাপে ফিচার আনলক (Progressive Feature Unlocking)

নতুন ব্যবহারকারীদের অভিভূত বোধ করা থেকে বিরত রাখতে, প্রথমবার ব্যবহারকারীরা কোর মোডগুলো (**Dashboard**, **Patient Encounters**, **Survival English**, **History**) প্রদর্শনকারী একটি শান্ত ইন্ট্রো স্ক্রিন দিয়ে শুরু করে।

- **আপনার প্রথম প্র্যাকটিস সেশন সম্পন্ন করা** স্বয়ংক্রিয়ভাবে একটি উদযাপন বার্তার সাথে অ্যাডভান্সড মোডগুলো (Exam, Teach-back, Interview, Lounge, Custom) **আনলক (unlock)** করে।
- আপনি Practice স্ক্রিন থেকে অবিলম্বে সমস্ত মোড প্রসারিত এবং প্রকাশ করতে ট্যাপ করতে পারেন।

### প্র্যাকটিস হাবের প্রধান মোড বিভাগসমূহ

1. **রোগীর সাক্ষাৎকার (Patient Encounters)**: হিস্ট্রি টেকিং, ফলো-আপ, ফাউন্ডেশনস (Foundations) বিগিনার মোড, স্কিল ড্রিলস (Skill Drills), আমার ভুলগুলো প্র্যাকটিস করুন (Practice My Mistakes)।
2. **পরীক্ষা ও ডায়াগনস্টিক (Exam & Diagnostic)**: ১০-মিনিটের বেসলাইন ডায়াগনস্টিক, OSCE, OET, রেসিডেন্সি এবং ওয়ার্ড রাউন্ড মক পরীক্ষা।
3. **সারভাইভাল ইংলিশ এবং লিসেনিং ল্যাব (Survival English & Listening Lab)**: হাসপাতালের অপ্রত্যাশিত পরিস্থিতি, দ্রুতগতির স্মল টক (rapid small talk), ১৫টি নেটিভ অ্যাকসেন্ট প্রোফাইল, লিসেনিং ল্যাব বিস্তারিত ড্রিলস।
4. **লেকচার টিচ-ব্যাক (Lecture Teach-back)**: ইউটিউব/টেক্সট সামারির ওপর ভিত্তি করে ফাইনম্যান টেকনিক প্রশিক্ষণ।
5. **রেসিডেন্সি ইন্টারভিউ (Residency Interviews)**: বিহেভিয়ারাল, ক্লিনিক্যাল এবং IMG-নির্দিষ্ট মক ইন্টারভিউ।
6. **মুক্ত ইংরেজি লাউঞ্জ (Free English Lounge)**: মেডিকেল বিতর্ক, খবরের সাবটাইটেল আলোচনা, কর্মক্ষেত্রের বিরোধ নিষ্পত্তি।
7. **কাস্টম সিনারিও (Custom Scenarios)**: কাস্টম এআই প্রম্পট এবং স্কোরিং রুব্রিক তৈরি করুন।

## 7. রোগীর সাক্ষাৎকার এবং লাইভ হিস্ট্রি কভারেজ ট্র্যাকার

বেডসাইড হিস্ট্রি টেকিং এবং রোগীর কাউন্সেলিং অনুকরণ করে — যা ক্লিনিক্যাল কমিউনিকেশনের মূল বিষয়।

### 7-1. অপারেশনাল সাব-মোডসমূহ

- **ফাউন্ডেশন মোড (Foundations Mode)**: প্রারম্ভিক শিক্ষার্থীদের জন্য ক্লিনিক্যাল রিজনিংয়ের বোঝা দূর করে, কঠোরভাবে **ব্যাকরণ, ক্লিনিক্যাল শব্দভাণ্ডার, রেপোর্ট তৈরি এবং সাবলীলতার (fluency)** ওপর ফোকাস করে।
- **স্কিল ড্রিলস (Skill Drills)**: টার্গেটেড মাইক্রো-কম্পিটেন্সি ব্যায়াম (NURSE এমপ্যাথি টেকনিক, সহজ-ভাষার ব্যাখ্যা, নাইট শিফট হ্যান্ডওভার, **নেটিভ ভাষা → ইংরেজি সিকোয়েনশিয়াল মেডিকেল ইন্টারপ্রেটিং**)।
- **আমার ভুলগুলো প্র্যাকটিস করুন (Practice My Mistakes)**: আপনার ডেটাবেসে থাকা পেন্ডিং ত্রুটিগুলো থেকে তাত্ক্ষণিকভাবে একটি ভোকাল ডায়ালগ কুইজ সংশ্লেষ করে।
- **দৈনিক মিশন (Daily Mission)**: একটি অ্যাডাপটিভ ৫-মিনিটের দৈনিক চ্যালেঞ্জ যা আপনার বর্তমান স্কিল গ্যাপগুলোকে লক্ষ্য করে।

### 7-2. লাইভ হিস্ট্রি কভারেজ ট্র্যাকার

একটি কলাপসিবল রিয়েল-টাইম প্যানেল যা আপনি কথা বলার সাথে সাথে হিস্ট্রি-টেকিং আইটেমগুলোকে চেক অফ করে:

- এআই কনভারসেশনের প্রেক্ষাপটের ওপর ভিত্তি করে স্বয়ংক্রিয়ভাবে আইটেমগুলো ট্র্যাক করে।
- অনসেট/ডিউরেশন, ব্যথার ক্যারেক্টার, রেডিয়েশন, অ্যাগ্রাভেটিং/রিলিভিং ফ্যাক্টর, অ্যাসোসিয়েটেড সিম্পটমস, ICE (Ideas, Concerns, Expectations), অতীতের ইতিহাস, মেডিকেশন, অ্যালার্জি, অ্যালকোহল/ধূমপান, পারিবারিক ইতিহাস ইত্যাদি মনিটর করে।
- নেগেটিভ কনফার্মেশন প্রশ্ন যেমন _"You don't smoke, do you?"_ সঠিকভাবে স্বীকৃত এবং ট্র্যাক করা হয়।

### 7-3. প্রসঙ্গ-সচেতন কন্টিনিউয়েশন হেল্প (`💡 Help me continue`)

যদি আপনি আটকে যান বা সেশনের মাঝামাঝি প্রশ্ন ফুরিয়ে যায়, স্ক্রিনের নিচে **💡 Help me continue** এ ট্যাপ করুন।

- একটি **ব্যবহারের জন্য প্রস্তুত ইংরেজি নমুনা বাক্য** সহ পরবর্তী লজিক্যাল কোশ্চেন অবজেক্টিভ সাজেস্ট করার জন্য রোগীর সর্বশেষ রেসপন্স বিশ্লেষণ করে।
- শীর্ষ ইন্টারভিউ ফেজ ট্র্যাকার স্ট্যাটাস সিম্বল ব্যবহার করে অগ্রগতি প্রদর্শন করে:
  - `✓`: পর্যাপ্ত প্রমাণ (evidence) শনাক্ত করা হয়েছে
  - `•`: আংশিক উল্লেখ শনাক্ত করা হয়েছে
  - `?`: পূর্ববর্তী ফেজ যাচাইকরণ ছাড়াই পরবর্তী ফেজে পৌঁছেছে

## 8. পরীক্ষা ও ডায়াগনস্টিক মোড (১০ মিনিটের বেসলাইন ও CEFR ম্যাপিং)

সময়সীমাযুক্ত, ইমারসিভ পরীক্ষার শর্তে কমিউনিকেশন প্রফিসিয়েন্সি পরিমাপ করে:

### ১০-মিনিটের বেসলাইন ক্লিনিক্যাল ইংলিশ ডায়াগনস্টিক

- একটি পরীক্ষকের (examiner) পরিচয়ের মাধ্যমে শুরু হয়, তারপরে ৪টি ছোট কাজ (একটি ডায়াগনোসিস ব্যাখ্যা করা, ফলো-আপ প্রশ্নগুলো হ্যান্ডেল করা, একটি ৪৫-সেকেন্ডের SBAR হ্যান্ডওভার ডেলিভার করা, একটি রেসিডেন্সি ইন্টারভিউ প্রশ্নের উত্তর দেওয়া) থাকে।
- স্বয়ংক্রিয়ভাবে আপনার পারফরম্যান্স আন্তর্জাতিক **CEFR গ্রেডে** ম্যাপ করে:
  - **স্কোর >= 8.5**: **C1** (অ্যাটেন্ডিং ফিজিশিয়ান লেভেলে সাবলীল, নিরাপদ ক্লিনিক্যাল কমিউনিকেশন)
  - **স্কোর >= 7.2**: **B2+** (ক্লিনিক্যাল ক্লার্কশিপ এবং হাসপাতাল প্র্যাকটিসের জন্য উপযুক্ত)
  - **স্কোর >= 6.0**: **B1-B2** (বেসিক কমিউনিকেশন ক্যাপাবিলিটি; স্ট্রাকচার্ড স্টাডি রিকমেন্ডেড)
  - **স্কোর < 6.0**: **A2-B1** (ফাউন্ডেশনাল ক্লিনিক্যাল কমিউনিকেশন ট্রেইনিং প্রয়োজন)

### মক এক্সাম সিনারিও

- **OSCE**: মিস্টার হেইস (Mr. Hayes) এর বুকে ব্যথার হিস্ট্রি টেকিং (ICE পরিমাপ, রেড ফ্ল্যাগ ডিটেকশন, এমপ্যাথি)।
- **OET Speaking**: হাইপারটেনশন রোগীর কাউন্সেলিং রোলপ্লে।
- **Residency**: ইউএস ইন্টারনাল মেডিসিন প্রোগ্রাম ডিরেক্টর মক ইন্টারভিউ।
- **Ward Round**: ৫-মিনিটের কমিউনিটি-অ্যাকোয়ার্ড নিউমোনিয়া কেস প্রেজেন্টেশন এবং ওরাল কোশ্চেন হ্যান্ডেলিং।

### স্কোর রিলায়েবিলিটি ব্যাজ (Score Reliability Badge)

এআই গ্রেডিং কনফিডেন্সকে **High (উচ্চ)**, **Medium (মধ্যম)** বা **Low (নিম্ন)** হিসেবে নির্দেশ করে:

- **High**: লার্নারের শব্দ সংখ্যা >= 180 শব্দ এবং চেকলিস্ট এভিডেন্স রেট >= 75%।
- **Medium**: লার্নারের শব্দ সংখ্যা >= 80 শব্দ এবং চেকলিস্ট এভিডেন্স রেট >= 50%।
- **Low**: শব্দ সংখ্যা < 80 শব্দ (শর্ট ট্রান্সক্রিপ্ট ফ্ল্যাগ) বা এভিডেন্স রেট < 50%।

## 9. উচ্চারণ ও স্পষ্টতা ল্যাব (Pron Lab)

৩য় ডেডিকেটেড বটম ট্যাবে (`🎙️ Pron Lab`) অবস্থিত, এটি আপনার স্পিচ ইন্টেলিজিবিলিটি বা বাক্যের স্পষ্টতার জন্য বিশেষায়িত ট্রেইনিং সেন্টার।

### 💡 ইন্টেলিজিবিলিটি-কেন্দ্রিক কোচিং

লক্ষ্য নেটিভ অ্যাকসেন্ট অনুকরণ নয়, বরং **"আন্তর্জাতিক সহকর্মী এবং রোগীরা কি ভুল বোঝাবুঝি ছাড়াই আমার কথা স্পষ্টভাবে বুঝতে পারছে?"**

- অডিও বিশ্লেষণ শুধুমাত্র সেইসব উচ্চারণ আইটেমগুলোতে পিনপয়েন্ট কোচিং প্রদান করে যা শ্রোতার ভুল বোঝাবুঝির কারণ হয়।

### এরর প্যাটার্ন ক্যাটাগরি ও ফিল্টার চিপস (Error Pattern Categories & Filter Chips)

আপনার সেশনগুলোতে সনাক্তকৃত উচ্চারণ ত্রুটিগুলো ক্যাটাগরি অনুযায়ী ফিল্টার চিপসে সংগঠিত হয়:

- `r · l`: _liver / river_, _clinical / critical_
- `f · p`: _fever / peter_, _palpation / falcation_
- `th`: _think / tink_, _throat / troat_
- `final`: শেষ ব্যঞ্জনবর্ণ বাদ পড়া (_chest / ches_)
- `cluster`: ব্যঞ্জনবর্ণ ক্লাস্টার প্রসেসিং এবং অনাবশ্যক স্বরধ্বনি যুক্ত করা (_cardiac_ → _cardi-ack-eu_)
- `stress`: মেডিকেল ওয়ার্ড স্ট্রেস মিসপ্লেসমেন্ট (_angina_, _arrhythmia_)
- `vowel`: শর্ট বনাম লং ভাওয়েল কনফিউশন (_ship / sheep_, _fit / feet_)

### অবজার্ভড স্টেট প্রমোশন রুল (Observed State Promotion Rule)

যখন একটি অ্যাকসেপ্টেড প্রোনাউন্সিয়েশন কার্ড প্রথম লগ করা হয়, তখন এটি অবিলম্বে একটি দৈনিক হোমওয়ার্ক কার্ড হওয়ার পরিবর্তে একটি **অবজার্ভড (Observed) বা পর্যবেক্ষণ** অবস্থায় প্রবেশ করে। এটি শুধুমাত্র তখনই একটি অ্যাকটিভ SRS রিভিউ এরর কার্ডে উন্নীত হয় যখন একই এরর প্যাটার্ন একটি পৃথক সেশনে পুনরাবৃত্তি হয়, এটি নিশ্চিত করে যে সিঙ্গেল-অকারেন্স স্পিচ-রিকগনিশন গ্লিচ অতিরিক্ত হোমওয়ার্ক তৈরি না করে।

## 10. সারভাইভাল ইংলিশ এবং লিসেনিং ল্যাব

পরীক্ষার রুমের বাইরে বাস্তব-বিশ্বের, নন-ক্লিনিক্যাল হাসপাতালের মিথস্ক্রিয়াগুলোর জন্য আইএমজিদের (IMGs) প্রস্তুত করে।

- **র‍্যান্ডম / সারপ্রাইজ মোড (Random / Surprise Mode)**: অপ্রত্যাশিত পরিস্থিতিগুলোর (হলওয়ে কার্বসাইড কোশ্চেনস, ফার্মেসি কলব্যাকস, নার্স স্মল টক) স্বতঃস্ফূর্ত হ্যান্ডেলিং, যেখানে এআই কথা না বলা পর্যন্ত সিনারিওর প্রেক্ষাপট লুকানো থাকে।
- **র‍্যাপিড-ফায়ার স্মল টক (Rapid-fire Small Talk)**: আকস্মিক টপিক পরিবর্তনের দ্রুত রেসপন্স।
- **১৫টি নেটিভ অ্যাকসেন্ট প্রোফাইল**: আন্তর্জাতিক নেটিভ অ্যাকসেন্ট এবং স্পিচ রিদমের সাথে মানিয়ে নেওয়ার প্র্যাকটিস।
- **রিয়েল-টাইম অডিও স্পিড কন্ট্রোল (0.5× থেকে 2.5×)**: দ্রুত নেটিভ স্পিকারদের সাথে অ্যাডজাস্ট করার জন্য পিচ-প্রিজার্ভিং প্লেব্যাক স্পিড স্লাইডার।
- **কান-শুধুমাত্র লিসেনিং মোড (Ear-only Listening Mode)**: এআই কনভারসেশন সাবটাইটেলগুলো লুকিয়ে রাখে যাতে আপনি শুধুমাত্র শোনার ওপর নির্ভর করেন, প্রয়োজন হলে **[Reveal last line]** উপলব্ধ থাকে।
- **রিপেয়ার এক্সপ্রেশন এনকারেজমেন্ট (Repair Expression Encouragement)**: _"Sorry?", "Could you say that again?"_ এর মতো রিপেয়ার কৌশলগুলো ব্যবহার করলে পয়েন্ট কাটার পরিবর্তে **বোনাস পয়েন্ট** দেওয়া হয়।
- **লিসেনিং ল্যাব (Listening Lab)**: আইটেমাইজড অ্যাকুরেসি স্কোরিং সহ সঠিক ডিটেইল কম্প্রিহেনশন (সংখ্যা, ড্রাগ ডোজেস, রোগীর নাম, সময়, নির্দেশাবলী, দাম) পরীক্ষা করার ব্যায়াম।

## 11. লেকচার টিচ-ব্যাক (ফাইনম্যান টেকনিক)

ফাইনম্যান টেকনিক ব্যবহার করে—মেডিকেল নলেজ শক্ত করার জন্য অন্য কাউকে শেখানোর মতো করে কনসেপ্টগুলো জোরে জোরে ব্যাখ্যা করা।

1. **লেকচার ম্যাটেরিয়াল প্রস্তুত করুন**: সামারি নোটস পেস্ট করুন বা একটি ইউটিউব মেডিকেল লেকচার URL এন্টার করুন এবং **`🎬 Fetch YT transcript`** ট্যাপ করুন।
2. **এআই কনডেনসেশন (AI Condensation)**: দীর্ঘ উপকরণগুলোর জন্য, টেক্সটকে একটি স্ট্রাকচার্ড ৫০০-শব্দের আউটলাইনে কম্প্রেস করতে **`✨ Condense`** ট্যাপ করুন।
3. **অডিয়েন্স পারসোনা নির্বাচন করুন**:
   - **Oral Exam Professor (ওরাল এক্সাম প্রফেসর)**: তীক্ষ্ণ, চ্যালেঞ্জিং ক্লিনিক্যাল "Why" এবং "What-if" ফলো-আপ প্রশ্ন জিজ্ঞাসা করে।
   - **Confused Classmate (কনফিউজড ক্লাসমেট)**: ভারী জার্গন ছাড়াই প্লেইন-ল্যাঙ্গুয়েজ ব্যাখ্যার অনুরোধ করে।
   - **Friendly Tutor (ফ্রেন্ডলি টিউটর)**: সাপোর্টিভ এনকারেজমেন্ট এবং ফ্রেজিং গাইডেন্স প্রদান করে।
4. **টিচ (Teach)**: **Start** ট্যাপ করুন এবং মাইক্রোফোনের মাধ্যমে ব্যাখ্যা করুন যখন এআই লিসেনার ক্লারিফাইং কোশ্চেন দিয়ে রেসপন্স করে।

## 12. রেসিডেন্সি মক ইন্টারভিউ

ওভারসিজ হাসপাতাল এমপ্লয়মেন্ট এবং ইউএস রেসিডেন্সি ম্যাচের জন্য বাস্তবসম্মত ইন্টারভিউ সিমুলেট করে:

- **বিহেভিয়ারাল (Behavioral)**: STAR মেথড (Situation, Task, Action, Result) এক্সপেরিয়েন্স ডেসক্রিপশন।
- **ক্লিনিক্যাল (Clinical)**: ওরাল কেস প্রেজেন্টেশন, মেডিকেল এথিক্স এবং ইমার্জেন্সি ম্যানেজমেন্ট লজিক।
- **IMG-Specific (আইএমজি-নির্দিষ্ট)**: কমন আইএমজি প্রশ্নগুলোর ওপর ফোকাস করে (ভিসা স্পনসরশিপ, সিভি গ্যাপ ইয়ার এক্সপ্লানেশন, একজন আইএমজি হিসেবে ইউনিক স্ট্রেংথস)।
- একজন এআই প্রোগ্রাম ডিরেক্টর বিনয়ী কিন্তু প্রোবিং ফলো-আপ প্রশ্নগুলোর নেতৃত্ব দেয়।

## 13. মুক্ত ইংরেজি লাউঞ্জ এবং কাস্টম সিনারিও

### ফ্রি ইংলিশ লাউঞ্জ (Free English Lounge)

- বর্তমান মেডিকেল টপিকগুলো আলোচনা করুন, জার্নাল আর্টিকেলগুলো সামারাইজ করুন, কর্মক্ষেত্রের/নার্স কনফ্লিক্টগুলো সমাধান করুন বা কফি-ব্রেক স্মল টক প্র্যাকটিস করুন।
- এআই-এর সাথে স্বাধীনভাবে বিতর্ক করতে ইউটিউব মেডিকেল নিউজ সাবটাইটেলগুলো ফেচ করুন।

### কাস্টম সিনারিও (Custom Scenarios)

আপনার প্রয়োজন অনুসারে কাস্টম প্র্যাকটিস সিনারিও তৈরি করুন:

- **Scenario Name (সিনারিও নাম)**: কাস্টম আইডেন্টিফায়ার।
- **Persona / Context (পারসোনা / প্রেক্ষাপট)**: এআই-এর রোল এবং সিচুয়েশন ডিফাইন করার সিস্টেম প্রম্পট।
- **Eval Template (মূল্যায়ন টেমপ্লেট)**: মূল্যায়ন রুব্রিক সিলেক্ট করুন (যেমন খারাপ খবর দেওয়ার জন্য SPIKES প্রোটোকল)।
- **Custom Eval Criteria (কাস্টম মূল্যায়ন মানদণ্ড)**: এআই-এর চেক করার জন্য স্পেসিফিক কি অ্যাসেসমেন্ট পয়েন্টগুলো সেট করুন।

## 14. ফিডব্যাক রিপোর্টের বিশ্লেষণ (৭টি প্রধান অংশ)

একটি সেশন সম্পন্ন করার পরে, একটি ৭-সেকশনের রিপোর্ট মাল্টি-ডাইমেনশনাল ফিডব্যাক প্রদান করে:

1. **Scores (স্কোরসমূহ)**: আপনার সেলফ-অ্যাসেসমেন্টের সাথে এআই ডোমেইন স্কোর (০-১০) পাশাপাশি কম্পেয়ার করে। **২.০+ পয়েন্টের** গ্যাপ একটি হলুদ **Reflection Prompt** কার্ড ট্রিগার করে যা সেলফ-রিফ্লেকশন গাইড করে।
2. **Fluency (সাবলীলতা)**:
   - **WPM (Words Per Minute)**: রেকমেন্ডেড টার্গেট (১০০-১৩০ WPM) এর বিপরীতে কথা বলার গতি পরিমাপ করে।
   - **Filler Words (ফিলার ওয়ার্ডস)**: ফিলার ওয়ার্ড ডেনসিটি পরিমাপ করে (`um`, `uh`, `like`), পজগুলোর (pauses) কার্যকরী ব্যবহারকে উৎসাহিত করে।
3. **Checklist (চেকলিস্ট)**: ক্লিনিক্যাল অবজেক্টিভগুলো মূল্যায়ন করে, সঠিক ট্রান্সক্রিপ্ট সেন্টেন্সগুলোকে **Evidence (প্রমাণ)** হিসেবে উদ্ধৃত করে।
4. **SOAP Note Comparison**: আপনার সেশন থেকে একটি স্বয়ংক্রিয়ভাবে জেনারেট হওয়া SOAP নোটকে একটি মডেল রেফারেন্স SOAP নোটের সাথে কম্পেয়ার করে।
5. **Corrections (সংশোধনসমূহ)**: ডিরেক্ট ট্রান্সলেশন, আর্টিকেলস/প্লুরালস, আনন্যাচারাল এক্সপ্রেশনস এবং প্রোনাউন্সিয়েশনের জন্য কার্ড-বেসড কারেকশন। **[Accept]** ট্যাপ করলে আইটেমটি আপনার পার্সোনাল SRS এরর ট্র্যাকারে রেজিস্টার হয়।
6. **Shadowing (শ্যাডোয়িং)**: উইক সেন্টেন্সগুলোকে লিসেন-অ্যান্ড-রিপিট অডিও ট্রেইনিংয়ের জন্য অ্যাটেন্ডিং-লেভেল ক্লিনিক্যাল ইংলিশে রিরাইট করে।
7. **Summary & Share Cards (সারসংক্ষেপ ও শেয়ার কার্ড)**: ওভারঅল ফিডব্যাক প্রদর্শন করে এবং স্টাডি পিয়ারদের সাথে পারফরম্যান্স সামারি শেয়ার করার জন্য একটি **Share Card** ইমেজ জেনারেটর প্রদান করে।

## 15. সক্রেটিক এআই টিউটর এবং সবসময় সচল ১:১ ভয়েস কোচ

### 15-1. সক্রেটিক এআই টিউটর ১:১ ডিব্রিফ (`[Debrief with AI Tutor]`)

ফিডব্যাক রিপোর্টের নিচে **[Debrief with AI Tutor]** ট্যাপ করলে একজন সক্রেটিক এআই মেন্টরের সাথে একটি ১:১ চ্যাটরুম খোলে।

- সরাসরি উত্তর দেওয়ার বদলে গাইডিং প্রশ্ন জিজ্ঞাসা করে, যা আপনাকে নিজে নিজে ভুল আবিষ্কার করতে এবং সংশোধন করতে সাহায্য করে।
- ডিব্রিফ চ্যাট হিস্ট্রি ডেটাবেসে প্রিজার্ভ করা হয় যাতে আপনি ফিরে আসতে পারেন এবং যেকোনো সময় চালিয়ে যেতে পারেন।

### 15-2. সবসময় সচল ১:১ স্পিকিং ভয়েস কোচ (Home FAB)

ড্যাশবোর্ডের নিচের ডানদিকে **Voice Coach Floating Button (`🎙️ RecordVoiceOver`)** ট্যাপ করলে প্রথমে একটি সম্পূর্ণ সিনারিও সম্পন্ন না করেই তাত্ক্ষণিকভাবে একটি স্পিকিং কোচ ডায়ালগ খোলে।

- এআই কোচ আপনার অ্যাকুমুলেটেড SRS উইক পয়েন্টগুলোর ওপর ভিত্তি করে কাস্টমাইজড ১:১ ভয়েস কনভারসেশনে লিড দেয়।

## 16. স্পেসড রিপিটেশন এরর ট্র্যাকার ও মিস্টেক জিনোম

**[Accept]** এর মাধ্যমে গৃহীত সংশোধনগুলো স্বয়ংক্রিয়ভাবে আপনার এরর ডেটাবেসে স্পেসড রিপিটেশন অ্যালগরিদম দ্বারা পরিচালিত হয়।

- **Fuzzy Duplicate Detection (ফাজি ডুপ্লিকেট ডিটেকশন)**: স্বয়ংক্রিয়ভাবে একই রকম ভুলের ডুপ্লিকেট লগিং প্রতিরোধ করে।
- **Leech / Stubborn Errors (একগুঁয়ে ত্রুটিসমূহ)**: রিভিউ কুইজে টানা ৪+ বার মিস হওয়া আইটেমগুলোকে ফোকাসড ম্যানেজমেন্টের জন্য **Stubborn / Leech** হিসেবে ট্যাগ করা হয়।
- **Scientific Spaced Repetition Intervals (বৈজ্ঞানিক স্পেসড রিপিটেশন ব্যবধান)**:
  - রিভিউ শিডিউল: **১ দিন → ৩ দিন → ৭ দিন → ১৪ দিন → ৩০ দিন**। টানা ৩টি রিভিউ পাস করলে আইটেমটি **Mastered (মাস্টার্ড)** এ গ্র্যাজুয়েট হয়।
  - **Practice My Mistakes**-এ ভোকাল কুইজ ক্লিয়ার করলে আইটেমগুলো Mastery-এর দিকে এগিয়ে যায়।
- **Mistake Genome Panel (মিস্টেক জিনোম প্যানেল)**:
  - প্লেইন-ল্যাঙ্গুয়েজ টুলটিপস সহ ড্যাশবোর্ড বার চার্ট হিসেবে আপনার শীর্ষ ৫টি দুর্বল এরর ক্যাটাগরি (Articles, Plurals, Tense, Prepositions, Register, Direct Translations) প্রদর্শন করে।

## 17. অ্যাটেন্ডিং কেস প্রেজেন্টেশন চেইনিং

পেশেন্ট এনকাউন্টারের পরে একজন সুপারভাইজারের কাছে কেস প্রেজেন্ট করার মাধ্যমে ওরাল হ্যান্ডঅফ স্কিলস ট্রেইন করুন:

1. একটি **Patient Encounter** সেশন কমপ্লিট করুন।
2. **History** ট্যাবে যান, সেশন সিলেক্ট করুন এবং **`📋 Present Case`** ট্যাপ করুন।
3. এআই অ্যাটেন্ডিং খোলে এর সাথে: _"Doctor, please present the case you just saw."_
4. SBAR বা SOAP ফরম্যাট ব্যবহার করে একটি ওরাল কেস প্রেজেন্টেশন ডেলিভার করুন এবং ডিফারেনশিয়াল ডায়াগনোসিস এবং ট্রিটমেন্ট প্ল্যানের ফলো-আপ প্রশ্নগুলোর উত্তর দিন।

## 18. বাহ্যিক কনভারসেশন হিস্ট্রি ইম্পোর্ট করা (Import Transcript)

ফুল ফিডব্যাক পেতে ChatGPT, Gemini বা ক্লিনিক্যাল নোটস থেকে অ্যাপটিতে কনভারসেশন টেক্সট ইম্পোর্ট করুন:

1. **Android Share Integration (অ্যান্ড্রয়েড শেয়ার ইন্টিগ্রেশন)**: এক্সটার্নাল অ্যাপগুলোতে কনভারসেশন টেক্সট হাইলাইট করুন এবং স্বয়ংক্রিয়ভাবে **Import Transcript** স্ক্রিন খুলতে **[Share] → [Bedside English]** সিলেক্ট করুন।
2. **Direct Entry / Paste (সরাসরি এন্ট্রি / পেস্ট)**: Preferences বা মেইন মেনু থেকে সরাসরি `Import Transcript` স্ক্রিন খুলুন এবং টেক্সট পেস্ট করুন।
3. **Automated Feedback & SRS (অটোমেটেড ফিডব্যাক এবং SRS)**: ডোমেইন স্কোর, SOAP নোটস এবং কারেকশন কার্ড তৈরি করে যা SRS অ্যাকসেপ্টেন্সের জন্য অ্যাভেইলেবল।

## 19. Anki ডেক এবং Word ডকুমেন্ট এক্সপোর্ট

- **Anki Card Export (ট্যাব-বিভাজিত `.txt`)**:
  - অ্যাকসেপ্টেড কারেকশনগুলোকে একটি Anki প্লেইন-টেক্সট ইম্পোর্ট ফাইলে কনভার্ট করে (Anki / AnkiDroid-এ File → Import)। প্রতিটি ভুলের ক্যাটাগরি একটি ট্যাগ হিসেবে ক্যারি করা হয়। এটি পোস্ট-সেশন ফিডব্যাক স্ক্রিন এবং **My Mistakes** উভয় জায়গাতেই অ্যাভেইলেবল, যা আপনার পুরো রিভিউ লিস্ট একবারে এক্সপোর্ট করে।
- **Word Report (`.docx`) Export**:
  - স্কোর, চেকলিস্ট এভিডেন্স, SOAP নোটস এবং সেন্টেন্স কারেকশনস সম্বলিত স্ট্রাকচার্ড মেডিকেল রিপোর্ট তৈরি করে। Preferences অপশন অটো-সেভিং এনাবল করে।

## 20. অ্যাপের ভেতরের হেল্প উইকি

উপরের অ্যাপ বারে **`?` Help আইকন** ট্যাপ করলে বিল্ট-ইন হেল্প উইকি ভিউয়ার ফুল-স্ক্রিন মোডে খোলে।

- **Multilingual Integration (মাল্টিলিঙ্গুয়াল ইন্টিগ্রেশন)**: অ্যাপের UI ল্যাঙ্গুয়েজ সেটিংয়ের সাথে ম্যাচ করে স্বয়ংক্রিয়ভাবে ইউজার গাইড ফাইল লোড করে।
- **Table of Contents (TOC) Sidebar (সূচিপত্র সাইডবার)**: সমস্ত গাইড সেকশন জুড়ে র‍্যাপিড জাম্প নেভিগেশন এনাবল করে।
- **Full-Text Search (ফুল-টেক্সট সার্চ)**: ম্যাচগুলো হাইলাইট করতে সার্চ বারে কীওয়ার্ড এন্টার করুন এবং প্রিভিয়াস/নেক্সট বোতামগুলোর মাধ্যমে নেভিগেট করুন।
- **External Hyperlinks (এক্সটার্নাল হাইপারলিংকস)**: গাইডের ভেতরের ওয়েব লিংকগুলোতে ট্যাপ করলে আপনার ডিফল্ট সিস্টেম ব্রাউজার খোলে।

## 21. UI ভাষার সেটিংস, API খরচ ট্র্যাকিং ও পছন্দসমূহ

আপনার ডিভাইস এবং বাজেটের সাথে অ্যাপটিকে মানানসই করতে উপরের বারের **সেটিংস গিয়ার (⚙️)** অ্যাক্সেস করুন:

- **Voice & Feedback (ভয়েস এবং ফিডব্যাক)**:
  - ভয়েস এবং ফিডব্যাক এআই মডেল (Demo, Gemini, OpenAI, Claude) সিলেক্ট করুন।
  - **Echo Prevention (ইকো প্রিভেনশন)**: অডিও ফিডব্যাক লুপগুলো প্রিভেন্ট করতে এআই কথা বলার সময় মাইক্রোফোনটি স্বয়ংক্রিয়ভাবে মিউট করে (হেডফোন ব্যবহার না করার সময় অপরিহার্য)।
  - **AI Speaking Pace (এআই স্পিকিং পেস)**: স্টেপওয়াইজ স্পিড কন্ট্রোল (Slow, Normal, Fast, Challenge)।
- **API Cost Analytics (API কস্ট অ্যানালিটিক্স)**: ট্রান্সপারেন্টভাবে টোকেন ইউজেস এবং চার্ট ভিজ্যুয়ালাইজেশনের সাথে সেশন প্রতি আনুমানিক ডলার খরচ ট্র্যাক করে।
- **Audio (অডিও)**: রিয়েল-টাইম মাইক্রোফোন লেভেল ইন্ডিকেটর এবং স্পিকার টেস্ট টোন।
- **API Keys (API কীসমূহ)**: লোকাল এনক্রিপ্টেড স্টোরেজ কী ম্যানেজার।
- **Export & Learning (এক্সপোর্ট এবং লার্নিং)**: Docx অটো-সেভ অপশনস, ম্যান্ডেটরি SOAP নোট এন্ট্রি, নেটিভ ল্যাঙ্গুয়েজ এবং UI ল্যাঙ্গুয়েজ সেটিংস।
- **Data (ডেটা)**: প্রোনাউন্সিয়েশন অ্যানালাইসিস টগল করুন, ইঞ্জিনগুলো কনফিগার করুন এবং TTS শ্যাডোয়িং ইঞ্জিন সিলেক্ট করুন।
- **Privacy (গোপনীয়তা)**: অ্যানোনিমাস ইউজেস টেলিমেট্রি টগল করুন।

## 22. সচরাচর জিজ্ঞাসিত প্রশ্নাবলী (FAQ) ও স্কোরিং রুব্রিক

### সচরাচর জিজ্ঞাসিত প্রশ্নাবলী (FAQ)

**Q: মাইক্রোফোন অডিও পিক আপ করছে না এবং এআই রেসপন্স করছে না।**

- অ্যান্ড্রয়েড **Settings → Apps → Bedside English → Permissions → Microphone** চেক করুন এবং এটিকে [Allow] তে সেট করুন। যদি অনুমতি অস্বীকার করা হয়, অ্যাপটি **Type instead (টাইপ করুন)** মোডে স্যুইচ করে যাতে আপনি কিবোর্ডের মাধ্যমে প্র্যাকটিস চালিয়ে যেতে পারেন।

**Q: অ্যাডভান্সড প্র্যাকটিস মোডগুলো (Exam, Teach-back, Interview, Lounge, Custom) মিসিং।**

- আপনার প্রথম প্র্যাকটিস সেশন সম্পন্ন করুন এবং সমস্ত অ্যাডভান্সড মোড স্বয়ংক্রিয়ভাবে একটি উদযাপন বার্তার সাথে আনলক হবে। আপনি Practice স্ক্রিন থেকে সমস্ত মোড প্রসারিত এবং প্রকাশ করতে পারেন।

**Q: প্রোনাউন্সিয়েশন অ্যানালাইসিস রেজাল্টগুলো অবিলম্বে আমার SRS রিভিউ ডেটাবেসে যায় না।**

- সিঙ্গেল-অকারেন্স স্পিচ-রিকগনিশন ত্রুটিগুলোকে লার্নারদের ওপর বোঝা চাপানো থেকে বিরত রাখতে, অ্যাকসেপ্টেড প্রোনাউন্সিয়েশন আইটেমগুলো প্রথমে একটি **অবজার্ভড (Observed)** স্টেটে প্রবেশ করে। তারা শুধুমাত্র অ্যাকটিভ SRS রিভিউ কার্ডে প্রমোটেড হয় যখন একই এরর প্যাটার্ন ভবিষ্যৎ সেশনে পুনরাবৃত্তি হয়।

**Q: আমি কি গ্রেডিংয়ের জন্য এক্সটার্নাল কনভারসেশন ট্রান্সক্রিপ্ট (যেমন, ChatGPT) ইম্পোর্ট করতে পারি?**

- হ্যাঁ। Bedside English এ টেক্সট শেয়ার করতে অ্যান্ড্রয়েডের শেয়ার ফিচার ব্যবহার করুন বা ফুল ফিডব্যাক, SOAP নোটস এবং কারেকশন কার্ড পেতে `Import Transcript` স্ক্রিনে টেক্সট পেস্ট করুন।
