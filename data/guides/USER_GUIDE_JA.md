# Bedside English ユーザーガイド

**対象読者:** 海外の医学部卒業生（IMG）、研修医、医学生、および臨床英語、OSCE、OET Speaking、米国レジデンシー面接、回診でのプレゼンテーション、臨床コミュニケーションの準備をしている医療従事者。

Bedside Englishは、対話型AI（Google Gemini、OpenAI Realtime、Anthropic Claude）とリアルタイム音声技術を搭載したAndroid専用アプリです。臨床コミュニケーションスキル、医学的推論、発音、音声の明瞭度を多角的にトレーニングするように設計されています。このガイドでは、ユーザー向けに調整された最新のアプリバージョンのすべての機能と使用方法について詳しく説明します。

## 1. APIキーの設定と構成

Bedside Englishは、Google Gemini、OpenAI、Anthropic Claudeのバックエンドに柔軟に対応しています。

### 💡 推奨設定（Google Gemini シングルキーモード）

**単一のGoogle Gemini APIキーを登録することで、リアルタイムの音声会話からセッション後のフィードバック分析まで、アプリのすべての機能を最速かつ最も費用対効果の高い方法で有効にできます。**

| サービス               | 主な目的                                                            | 必須 / オプション                          | リンク                                                 |
| :--------------------- | :------------------------------------------------------------------ | :----------------------------------------- | :----------------------------------------------------- |
| **Google (Gemini)**    | リアルタイム音声会話 (Gemini Live) + 深いフィードバック分析         | **必須（単一キーですべての機能をカバー）** | [aistudio.google.com](https://aistudio.google.com)     |
| **OpenAI**             | リアルタイム音声 (OpenAI Realtime) + フィードバック + プレミアムTTS | オプション                                 | [platform.openai.com](https://platform.openai.com)     |
| **Anthropic (Claude)** | セッションフィードバック分析（選択可能なバックエンド）              | オプション（デフォルトはGemini）           | [console.anthropic.com](https://console.anthropic.com) |

### APIキーの入力とセキュリティ

APIキーはアプリ内で直接入力します：

- **初回起動時のオンボーディングウィザード**中、またはトップバーの**設定歯車 (⚙️) → Preferences → API Keys**メニューから構成します。
- 入力されたAPIキーはデバイスの暗号化ストレージ（`EncryptedSharedPreferences`）に**安全に保存**され、外部サーバーに送信されることは決してありません。
- 各キーフィールドの右側には、キーの表示/非表示を切り替える目のアイコンがあります。

### 🎈 デモモード（完全無料トライアル）

APIキーを登録したりマイクの権限を付与したりせずにアプリを体験したい場合は、オンボーディング画面または**Preferences**の下にある**Demo**モードを選択してください。
スクリプト化された模擬会話とフィードバックデータが読み込まれ、トークンを消費することなく、完全なUI、エラートラッカー、およびレビュー機能を**無料**で探索できます。デモセッションを完了すると、いつでもAPIキーを入力するか、次のデモ患者での練習を続けることができるプロンプトが表示されます。

## 2. アプリのインストールと権限の設定

Bedside Englishは、Android 8.0（APIレベル26）以降を実行しているスマートフォンおよびタブレットで動作します。

### アプリのインストール

- 提供されたインストールファイル（`.apk`）をAndroidデバイスで起動し、画面の指示に従ってインストールします。

### マイク権限と「代わりにタイプする」モード

- ライブ音声練習モードを初めて起動する際、Android OSはマイクへのアクセス権限を要求します。音声認識を適切に機能させるには、**[許可]**をタップします。
- 話すのが難しい環境にいる場合や権限が拒否された場合でも、アプリはクラッシュしません。自動的に**Type instead（代わりにタイプする）**モードに切り替わり、キーボード入力で会話の練習を続けることができます。

### 通知権限とオーディオの事前確認（Audio Preflight）

- バックグラウンドでのフィードバック分析が完了したときに通知を受け取ることができるように、通知権限が要求されます。
- 最初のライブ音声セッションを開始する直前に、**Audio Preflight（オーディオの事前確認）**チェックモーダルが表示され、ヘッドフォンの使用を案内し、マイクの入力レベルをテストして、スピーカーのフィードバックループ（ハウリング）を防ぎます。

## 3. 初回起動時のオンボーディングとL1学習者のカスタマイズ

アプリを初めて起動すると、カスタマイズされた学習環境を構築するための4ステップのセットアップウィザードが実行されます：

1. **ようこそ画面**: 主要な機能を紹介し、APIキーなしで探索するための**Try Demo Mode（デモモードを試す）**ボタンを提供します。
2. **UI言語ピッカー**: 優先するインターフェース言語（英語、韓国語、スペイン語、中国語、アラビア語、ヒンディー語、ポルトガル語、タガログ語の8つのサポート言語）を選択します。
3. **APIキーの設定**: Google Geminiまたはその他のAI APIキーを登録します。
4. **母語とプライバシー**: 第一言語（例：**Korean**、中国語、スペイン語、アラビア語、ヒンディー語、タガログ語、ポルトガル語）を選択します。これにより、母語特有の干渉パターンに合わせた高精度の文法と発音の分析が有効になります。

### 🌐 L1母語のカスタマイズのハイライト（例：韓国語L1学習者）

- **文法と表現の修正**:
  - 冠詞の欠落（名詞の前の _a/an/the_ の省略）
  - 複数形の _-s_ の欠落（_two patient_ → _two patients_）
  - 時制のエラー（過去の病歴について議論する際の現在時制の使用）
  - 前置詞の誤用（_in hospital_、_explain to patient_ における前置詞の省略）
  - 文字通りの直訳 / コングリッシュ（_skin scale_、_side effect_ の不自然な直訳）
- **発音と明瞭度の修正**:
  - _r / l_ の最小対の区別（_liver_ vs _river_）
  - _f / p_ の区別（_fever_ vs _peter_）
  - _th_ の歯摩擦音の発音（_think_ vs _tink_）
  - 省略された最後の子音と不要な母音の挿入（_cardiac_ → _cardi-ack-eu_）
  - 医療単語のアクセントの誤配置（_angina_、_arrhythmia_）

### 💡 インタラクティブな初回実行ツアー

オンボーディングを完了してダッシュボードに初めて入ると、インタラクティブなチュートリアルが自動的に主要なボタン（ダッシュボード、Practice Hub、Pron Lab、SRSレビュー、履歴、ヘルプ、1対1ボイスコーチ）の場所と機能を案内します。

## 4. UIレイアウトの概要（下部ナビゲーションの5つのタブとヘルプ）

### 下部ナビゲーションバー（5つのタブ）

メインナビゲーションは5つの下部タブで構成されています：

```
┌───────────┬──────────────┬───────────────────────┬───────────────┬─────────────┐
│  🏠 Home  │  ▶ Practice  │  🎙️ Pronunciation Lab │  ⚠️ SRS Reviews│  🕘 History │
└───────────┴──────────────┴───────────────────────┴───────────────┴─────────────┘
```

1. **Home（ダッシュボード）**: 練習の継続日数（`🔥`）、5分間の臨床ミッション、パフォーマンストレンドチャート、Mistake Genome、ロードマップ、および**常時オンの1対1ボイスコーチ**。
2. **Practice（Practice Hub）**: すべてのリアルタイムスピーキングモードの中央ハブ：患者との遭遇、試験・診断、サバイバルイングリッシュ、ティーチバック、面接、ラウンジ、カスタムシナリオ。
3. **Pronunciation Lab（Pron Lab）**: 音声の明瞭度と発音矯正のための専用トレーニングタブ（エラーパターンのフィルタリング、観察ステータス管理）。
4. **SRS Reviews（弱点レビュー）**: 受け入れた修正文に対する、間隔反復アルゴリズムに基づいた音声レビュークイズ。
5. **History（セッション履歴）**: 過去のセッションのスコアとフィードバックの表示、トークンコストの追跡、Anki/Wordへのエクスポート、および**主治医への症例プレゼンテーション（Present Case）**のトリガー。

### 上部アプリバー

- **Bedside English ロゴ**: メインタイトル。
- **Help Wiki（`?` アイコン）**: `?` アイコンをタップすると、このユーザーガイドがフルスクリーンビューアで開きます。目次ナビゲーションと全文キーワード検索が可能です。
- **設定歯車（⚙️ Preferences）**: APIキー、音声バックエンド、話すペース、エコー防止、言語、データ管理。

## 5. ダッシュボード（Home）の習熟

メインダッシュボードは、多角的な次元での臨床英語コミュニケーションスキルの成長を視覚的に提示します：

- **Practice Streak（練習の継続日数）**: 毎日の学習習慣を構築するために、連続したアクティブな練習日数を炎のアイコン（`🔥`）で表示します。
- **コアメトリックカード**:
  - **Sessions done**: 完全に完了し、分析されたセッションの総数。
  - **Errors tracked**: 個人の弱点データベースに登録された確認済みの修正。
  - **Mastered**: 繰り返しのレビュークイズを通じて解決し、卒業した間違い。
  - **Due now**: 今日音声でレビューする予定のSRSレビューカードの数。
  - **Stubborn**: 4回連続で失敗し、集中的な注意が必要な「リーチ（Leech）」エラー。
- **Today's 5-Minute Clinical Mission（今日の5分間臨床ミッション）**: 期限の来たレビュー項目、必要な診断、または最も弱いスキル領域を対象とした最適な5分間の練習コースを自動的に推奨します。
- **OET 専門外の語彙カバレッジ**:
  - 複雑な医学的専門用語（例：_syncope_）の代わりに、平易で患者に優しい用語（例：_fainting_）をどれだけ効果的に置き換えられているかを追跡します。
  - 使用された用語は**Recently Unlocked（最近ロック解除されたもの）**の下に表示され、未使用の表現は**Next Goals (Locked)（次の目標（ロック中））**の下にキューイングされます。
- **Mistake Genome パネル**: 最も頻繁なエラーカテゴリ（冠詞、複数形、時制、前置詞、使用域（レジスター）、直訳）を分析し、上位5つの弱点領域を棒グラフで表示します。
- **成長トレンドとL1干渉チャート**:
  - 過去20セッションにわたる5つの領域（文法、正確性、推論、プロフェッショナリズム、流暢さ）のスコアトレンドをグラフ化します。
  - 繰り返し発生する文法的な間違いのパターンを視覚化します。
- **パーソナライズされたロードマップ**: 弱い指標とエラーの履歴を分析し、優先順位付けされた4つのフォーカススキルカードを提示します。
- **Always-On 1:1 Voice Coach Button（常時オンの1対1ボイスコーチボタン） (`🎙️ RecordVoiceOver`)**:
  - ダッシュボードの右下に配置されています。タップすると、完全なセッションシナリオを開始することなく、個人の弱点プロファイルに基づいたAIチューターとの1対1の音声スピーキング対話が即座に開きます。

## 6. Practice Hubと段階的な機能のロック解除

### 段階的な機能のロック解除

新規ユーザーが圧倒されるのを防ぐため、初回ユーザーはコアモード（**Dashboard**、**Patient Encounters**、**Survival English**、**History**）を表示する落ち着いたイントロ画面から始まります。

- **最初の練習セッションを完了する**と、お祝いのメッセージとともに高度なモード（Exam、Teach-back、Interview、Lounge、Custom）が自動的に**ロック解除**されます。
- また、Practice画面からタップして展開し、すべてのモードをすぐに表示することもできます。

### Practice Hubのメインモードカテゴリ

1. **Patient Encounters（患者との遭遇）**: 病歴聴取、フォローアップ、Foundations（基礎）初心者モード、Skill Drills（スキル・ドリル）、Practice My Mistakes（私の間違いを練習）。
2. **Exam & Diagnostic（試験・診断）**: 10分間のベースライン診断、OSCE、OET、レジデンシー、回診の模擬試験。
3. **Survival English & Listening Lab（サバイバルイングリッシュとリスニングラボ）**: 病院での予期せぬ状況、素早い雑談、15のネイティブアクセントプロファイル、リスニングラボの詳細ドリル。
4. **Lecture Teach-back（講義ティーチバック）**: YouTube/テキストの要約に基づいたファインマン・テクニックのトレーニング。
5. **Residency Interviews（レジデンシー面接）**: 行動、臨床、およびIMG固有の模擬面接。
6. **Free English Lounge（フリーイングリッシュラウンジ）**: 医療ディベート、ニュース字幕の議論、職場での対立解決。
7. **Custom Scenarios（カスタムシナリオ）**: カスタムAIプロンプトとスコアリングルブリックを作成。

## 7. 患者との遭遇とライブ病歴網羅トラッカー

臨床コミュニケーションの核心である、ベッドサイドでの病歴聴取と患者へのカウンセリングをシミュレートします。

### 7-1. オペレーショナルサブモード

- **Foundations（基礎）モード**: 初学者のために臨床的推論の負担を取り除き、**文法、臨床語彙、ラポール構築、流暢さ**に厳密に焦点を当てます。
- **Skill Drills（スキル・ドリル）**: ターゲットを絞ったマイクロコンピテンシーの演習（NURSE共感テクニック、平易な言葉での説明、夜勤の引き継ぎ、**母語 → 英語の逐次医療通訳**）。
- **Practice My Mistakes（私の間違いを練習）**: データベース内の保留中のエラーから即座に音声対話クイズを合成します。
- **Daily Mission（デイリーミッション）**: 現在のスキルギャップを対象とした、適応型の5分間のデイリーチャレンジ。

### 7-2. ライブ病歴網羅トラッカー

話している間に病歴聴取項目にチェックを入れる、折りたたみ可能なリアルタイムパネル：

- AIの会話コンテキストに基づいて項目を自動的に追跡します。
- 発症/持続時間、痛みの性質、放散痛、増悪/緩解因子、随伴症状、ICE（考え、懸念、期待）、既往歴、薬剤、アレルギー、飲酒/喫煙、家族歴などを監視します。
- _"You don't smoke, do you?"_（タバコは吸いませんよね？）のような否定的な確認の質問も正しく認識され、追跡されます。

### 7-3. コンテキストを認識した継続のヘルプ（`💡 Help me continue`）

セッションの途中で行き詰まったり、質問が思い浮かばなくなったりした場合は、画面下部の **💡 Help me continue（続けるのを手伝って）** をタップします。

- 患者の最新の反応を分析し、次に論理的な質問の目的を、**すぐに使える英語の例文**とともに提案します。
- 上部のInterview Phase Tracker（面接フェーズトラッカー）は、ステータスシンボルを使用して進捗状況を表示します：
  - `✓`: 十分な証拠が検出されました
  - `•`: 部分的な言及が検出されました
  - `?`: 前のフェーズを確認せずに後のフェーズに到達しました

## 8. 試験・診断モード（10分間のベースラインとCEFRマッピング）

時間を区切った没入型の試験条件下で、コミュニケーション能力を測定します。

### 10分間のベースライン臨床英語診断

- 試験官の紹介から始まり、その後に4つの短いタスク（診断の説明、フォローアップの質問への対応、45秒間のSBAR引き継ぎの実施、レジデンシー面接の質問への回答）が続きます。
- あなたのパフォーマンスを国際的な**CEFRグレード**に自動的にマッピングします：
  - **スコア >= 8.5**: **C1**（主治医レベルでの流暢で安全な臨床コミュニケーション）
  - **スコア >= 7.2**: **B2+**（臨床実習および病院での診療に有能）
  - **スコア >= 6.0**: **B1-B2**（基本的なコミュニケーション能力；構造化された学習を推奨）
  - **スコア < 6.0**: **A2-B1**（基礎的な臨床コミュニケーショントレーニングが必要）

### 模擬試験シナリオ

- **OSCE**: Hayes氏の胸痛の病歴聴取（ICE、レッドフラッグの検出、共感の測定）。
- **OET Speaking**: 高血圧患者のカウンセリングロールプレイ。
- **Residency**: 米国内科プログラムディレクターの模擬面接。
- **Ward Round**: 5分間の市中肺炎の症例プレゼンテーションと口頭での質問対応。

### スコア信頼性バッジ

AIの採点の確実性を**High（高）**、**Medium（中）**、または**Low（低）**として示します：

- **High**: 学習者の単語数 >= 180単語、かつチェックリストの証拠率 >= 75%。
- **Medium**: 学習者の単語数 >= 80単語、かつチェックリストの証拠率 >= 50%。
- **Low**: 単語数 < 80単語（短いトランスクリプトのフラグ）、または証拠率 < 50%。

## 9. 発音と明瞭度ラボ（Pron Lab）

下部の3番目の専用タブ（`🎙️ Pron Lab`）にある、音声の明瞭度のための専門のトレーニングセンターです。

### 💡 明瞭度中心のコーチング

目標はネイティブのアクセントを模倣することではなく、**「海外の同僚や患者が私の話を誤解なく明確に理解できるか？」**です。

- 音声分析により、聞き手の誤解を招く発音項目についてのみ、ピンポイントのコーチングが提供されます。

### エラーパターンのカテゴリとフィルターチップ

セッション全体で検出された発音エラーは、カテゴリごとにフィルターチップに整理されます：

- `r · l`: _liver / river_、_clinical / critical_
- `f · p`: _fever / peter_、_palpation / falcation_
- `th`: _think / tink_、_throat / troat_
- `final`: 省略された最後の子音（_chest / ches_）
- `cluster`: 子音群の処理と不要な母音の挿入（_cardiac_ → _cardi-ack-eu_）
- `stress`: 医療単語のアクセントの誤配置（_angina_、_arrhythmia_）
- `vowel`: 短母音と長母音の混同（_ship / sheep_、_fit / feet_）

### 観察済み状態の昇格ルール

受け入れられた発音カードが最初にログに記録されると、すぐに毎日の宿題カードになるのではなく、**Observed（観察済み）**状態に入ります。同じエラーパターンが別のセッションで再発した場合にのみ、アクティブなSRSレビューエラーカードに昇格し、単発の音声認識の不具合が過剰な宿題を作成しないようにします。

## 10. サバイバルイングリッシュとリスニングラボ

IMG（海外の医学部卒業生）が診察室の外で遭遇する、現実世界の非臨床的な病院でのやり取りに備えます。

- **Random / Surprise Mode（ランダム/サプライズモード）**: AIが話すまでシナリオのコンテキストが隠された状態で、予期せぬ状況（廊下での相談、薬局からの折り返しの電話、看護師との雑談）に自発的に対処します。
- **Rapid-fire Small Talk（素早い雑談）**: 突然の話題の変更に対する素早い対応。
- **15のネイティブアクセントプロファイル**: 国際的なネイティブのアクセントと発話リズムに適応する練習。
- **リアルタイムのオーディオ速度制御（0.5倍から2.5倍）**: ピッチを維持した再生速度スライダーで、早口のネイティブスピーカーに合わせます。
- **Ear-only Listening Mode（耳だけのリスニングモード）**: AIの会話の字幕を非表示にし、純粋にリスニングに頼ります。必要な場合は**[Reveal last line（最後の行を表示）]**を利用できます。
- **修復表現の奨励**: _"Sorry?"_、_"Could you say that again?"_ などの修復戦略を使用すると、減点ではなく**ボーナスポイント**が付与されます。
- **Listening Lab（リスニングラボ）**: 正確な詳細の理解（数字、薬の投与量、患者名、時間、方向、価格）をテストする演習で、項目ごとの正確さを採点します。

## 11. 講義ティーチバック（ファインマン・テクニック）

ファインマン・テクニック（医学の知識を他の人に教えるように声に出して説明する）を使用して、知識を確固たるものにします。

3. **対象者のペルソナの選択**:
   - **Oral Exam Professor（口頭試験の教授）**: 鋭く挑戦的な臨床的な「なぜ」「もし～だったらどうなるか」というフォローアップの質問をします。

   - **Friendly Tutor（フレンドリーな家庭教師）**: 支持的な励ましと表現のガイダンスを提供します。
4. **教える**: **Start**をタップし、マイクを通して説明します。AIの聞き手が明確化のための質問で応答します。

## 14. フィードバックレポートの分解（7つの主要セクション）

セッションを完了すると、7つのセクションからなるレポートが多次元のフィードバックを提供します：

1. **Scores（スコア）**: AIの領域スコア（0～10）とあなたの自己評価を並べて比較します。**2.0ポイント以上**の差があると、自己反省を促す黄色の**Reflection Prompt（反省プロンプト）**カードがトリガーされます。
2. **Fluency（流暢さ）**:
   - **WPM（1分間あたりの単語数）**: 推奨される目標（100～130 WPM）に対して話す速度を測定します。
   - **Filler Words（つなぎ言葉）**: つなぎ言葉の密度（`um`、`uh`、`like`）を測定し、ポーズの効果的な使用を促します。
3. **Checklist（チェックリスト）**: 臨床目標を評価し、トランスクリプトの正確な文を**Evidence（証拠）**として引用します。
4. **SOAP Note Comparison（SOAPノートの比較）**: あなたのセッションから自動生成されたSOAPノートと、モデルのリファレンスSOAPノートを比較します。
5. **Corrections（修正）**: 直訳、冠詞/複数形、不自然な表現、発音のカードベースの修正。**[Accept]**をタップすると、その項目が個人のSRSエラートラッカーに登録されます。
6. **Shadowing（シャドーイング）**: 弱い文章を、聞いて繰り返す音声トレーニング用に主治医レベルの臨床英語に書き換えます。
7. **Summary & Share Cards（概要と共有カード）**: 全体的なフィードバックを表示し、学習仲間とパフォーマンスの概要を共有するための**Share Card（共有カード）**画像ジェネレーターを提供します。

## 16. 間隔反復エラートラッカーとMistake Genome

**[Accept]** を介して受け入れられた修正は、エラーデータベース内の間隔反復（Spaced Repetition）アルゴリズムによって自動的に管理されます。

- **ファジーな重複の検出**: 類似した間違いが重複して記録されるのを自動的に防ぎます。
- **リーチ / 頑固なエラー（Leech / Stubborn Errors）**: レビュークイズで4回連続して間違えた項目は、集中的な管理のために**Stubborn / Leech**としてタグ付けされます。
- **科学的な間隔反復の間隔**:
  - レビュースケジュール：**1日 → 3日 → 7日 → 14日 → 30日**。3回連続でレビューに合格すると、その項目は**Mastered（マスター済み）**に卒業します。
  - **Practice My Mistakes** で音声クイズをクリアすると、項目がマスターに向けて進みます。
- **Mistake Genome パネル**:
  - 上位5つの弱いエラーカテゴリ（冠詞、複数形、時制、前置詞、使用域、直訳）を、平易な言葉のツールチップが付いたダッシュボードの棒グラフとして表示します。

## 17. 主治医への症例プレゼンテーション連鎖

Patient Encounter（患者との遭遇）の後に、スーパーバイザー（指導医/主治医）に症例をプレゼンテーションすることで、口頭での引き継ぎスキルをトレーニングします：

1. **Patient Encounter** セッションを完了します。
2. **History（履歴）** タブに移動し、セッションを選択して **`📋 Present Case`** をタップします。
3. AI Attending（AI主治医）が次のように開始します：_"Doctor, please present the case you just saw."_（先生、今診た症例について報告してください。）
4. SBARまたはSOAP形式を使用して口頭で症例プレゼンテーションを行い、鑑別診断と治療計画に関するフォローアップの質問に答えます。

## 22. よくある質問（FAQ）とスコアリングルブリック

### よくある質問（FAQ）

**Q: マイクが音声を拾わず、AIが応答しません。**

- Androidの **設定 → アプリ → Bedside English → 権限 → マイク** を確認し、[許可]に設定します。権限が拒否された場合、アプリは **Type instead（代わりにタイプする）** モードに切り替わり、キーボードから練習を続けることができます。

**Q: 高度な練習モード（Exam、Teach-back、Interview、Lounge、Custom）がありません。**

- 最初の練習セッションを完了すると、すべての高度なモードがお祝いのメッセージとともに自動的にロック解除されます。Practice画面からすべてのモードを展開して表示することもできます。

**Q: 発音分析の結果が、すぐにSRSレビューデータベースに反映されません。**

- 単発の音声認識エラーが学習者の負担になるのを防ぐため、受け入れられた発音項目は最初に **Observed（観察済み）** 状態に入ります。同じエラーパターンが将来のセッションで再発した場合にのみ、アクティブなSRSレビューカードに昇格します。

**Q: 採点のために外部の会話トランスクリプト（例：ChatGPT）をインポートできますか？**

- はい。Androidの共有機能を使用してテキストをBedside Englishに共有するか、`Import Transcript` 画面にテキストを貼り付けると、完全なフィードバック、SOAPノート、および修正カードを受け取ることができます。
