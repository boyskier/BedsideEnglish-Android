# دليل المستخدم لتطبيق Bedside English

**الجمهور المستهدف:** الخريجون الطبيون الدوليون (IMGs)، الأطباء المقيمون، طلاب الطب، والممارسون الصحيون الذين يستعدون للغة الإنجليزية السريرية، امتحانات OSCE، وOET Speaking، ومقابلات الإقامة الطبية في الولايات المتحدة، وجولات المرور على المرضى (Ward Rounds)، والتواصل السريري.

Bedside English هو تطبيق حصري لنظام Android يعتمد على الذكاء الاصطناعي التفاعلي (Google Gemini, OpenAI Realtime, Anthropic Claude) وتقنية الصوت في الوقت الفعلي. تم تصميمه لتدريب مهارات التواصل السريري، التفكير الطبي، النطق، ووضوح الكلام (Intelligibility) عبر أبعاد متعددة. يوضح هذا الدليل جميع الميزات وكيفية الاستخدام بالتفصيل.

## 1. إعداد وتكوين مفاتيح API

يدعم Bedside English بشكل مرن محركات Google Gemini وOpenAI وAnthropic Claude.

### 💡 الإعداد الموصى به (مفتاح Google Gemini الفردي)

**تسجيل مفتاح API واحد لـ Google Gemini يفعل جميع ميزات التطبيق — من المحادثات الصوتية المباشرة إلى تحليل الملاحظات التفصيلي — بأسرع طريقة وأكثرها توفيراً.**

| الخدمة                 | الغرض الرئيسي                                       | مطلوب / اختياري                  | الرابط                                                 |
| :--------------------- | :-------------------------------------------------- | :------------------------------- | :----------------------------------------------------- |
| **Google (Gemini)**    | محادثة صوتية مباشرة (Gemini Live) + تحليل الملاحظات | **مطلوب (مفتاح واحد يغطي الكل)** | [aistudio.google.com](https://aistudio.google.com)     |
| **OpenAI**             | صوت مباشر (OpenAI Realtime) + ملاحظات + TTS         | اختياري                          | [platform.openai.com](https://platform.openai.com)     |
| **Anthropic (Claude)** | تحليل الملاحظات (محرك اختياري)                      | اختياري (Gemini هو الافتراضي)    | [console-anthropic.com](https://console.anthropic.com) |

### إدخال مفتاح API والأمان

يتم إدخال مفاتيح API مباشرة داخل التطبيق:

- قم بالتكوين أثناء **معالج الإعداد الأولي (First-Run Onboarding Wizard)** أو عبر قائمة **الإعدادات (⚙️) ← Preferences ← API Keys** في الشريط العلوي.
- المفاتيح المدخلة **تُحفظ بأمان** في التخزين المشفر على الجهاز (`EncryptedSharedPreferences`) ولا يتم إرسالها أبداً إلى خوادم خارجية.
- يتضمن كل حقل مفتاح أيقونة عين على اليمين للتبديل بين إظهار المفتاح أو إخفائه.

### 🎈 وضع التجربة (Demo Mode) (تجربة مجانية بالكامل)

إذا كنت ترغب في تجربة التطبيق دون تسجيل مفتاح API أو منح أذونات الميكروفون، فحدد وضع **Demo** في شاشة الإعداد (onboarding) أو تحت **Preferences**.
سيتم تحميل محادثات تجريبية مكتوبة مسبقاً وبيانات ملاحظات، مما يتيح لك استكشاف واجهة المستخدم الكاملة، ومتتبع الأخطاء، وميزات المراجعة **مجاناً** دون استهلاك أي رموز (tokens). بعد الانتهاء من جلسة تجريبية، ستتيح لك رسالة إدخال مفتاح API أو الاستمرار في ممارسة المريض التجريبي التالي في أي وقت.

## 2. تثبيت التطبيق وإعداد الأذونات

يعمل التطبيق على أجهزة Android 8.0 (API Level 26) أو أحدث.

### تثبيت التطبيق

- افتح ملف التثبيت (`.apk`) على جهاز Android واتبع التعليمات على الشاشة.

### إذن الميكروفون ووضع الكتابة

- عند استخدام وضع التدريب الصوتي لأول مرة، انقر على **[سماح]**.
- إذا تعذر الحديث، يتحول التطبيق تلقائياً إلى وضع **الكتابة بدلاً من ذلك (Type instead)** للمتابعة عبر لوحة المفاتيح.

### إذن الإشعارات واختبار الصوت (Audio Preflight)

- يُطلب إذن الإشعارات لتنبيهك عند اكتمال تحليل التقرير في الخلفية.
- يظهر خيار **اختبار الصوت (Audio Preflight)** قبل أول جلسة للتأكد من مستوى الميكروفون والسماعات ومنع الصدى.

## 3. الإعداد الأولي وتخصيص متعلمي اللغة الأم L1 (First-Run Onboarding & L1 Learner Customization)

عند تشغيل التطبيق لأول مرة، يعمل معالج إعداد من 4 خطوات لبناء بيئة تعليمية مخصصة:

1. **شاشة الترحيب (Welcome Screen)**: تعرض الميزات الأساسية وتوفر زر **Try Demo Mode** للاستكشاف دون مفاتيح API.
2. **منتقي لغة واجهة المستخدم (UI Language Picker)**: حدد لغة الواجهة المفضلة لديك (8 لغات مدعومة: الإنجليزية، الكورية، الإسبانية، الصينية، العربية، الهندية، البرتغالية، التاغالوغية).
3. **إعداد مفاتيح API (API Keys Setup)**: قم بتسجيل مفتاح Google Gemini الخاص بك أو مفاتيح API الأخرى للذكاء الاصطناعي.
4. **اللغة الأم والخصوصية (Native Language & Privacy)**: حدد لغتك الأم (مثل **الكورية**، الصينية، الإسبانية، العربية، الهندية، التاغالوغية، البرتغالية). يؤدي هذا إلى تفعيل تحليل دقيق للقواعد والنطق مصمم خصيصاً لأنماط التداخل الخاصة بلغتك الأم.

### 🌐 أبرز ميزات تخصيص اللغة الأم L1 (على سبيل المثال، متعلمو اللغة الأم الكورية - Korean L1 Learners)

- **تصحيحات القواعد والصياغة (Grammar & Phrasing Corrections)**:
  - أدوات التعريف والتنكير المفقودة (حذف _a/an/the_ قبل الأسماء).
  - حرف الـ _-s_ المفقود في صيغ الجمع (_two patient_ → _two patients_).
  - أخطاء الأزمنة (استخدام زمن المضارع عند مناقشة التاريخ المرضي السابق).
  - إساءة استخدام حروف الجر (_in hospital_، وحذف حروف الجر في _explain to patient_).
  - الترجمات المباشرة الحرفية / Konglish (الترجمة الكورية-الإنجليزية) (_skin scale_، وهي ترجمة مباشرة ركيكة لـ _side effect_).
- **تصحيحات النطق ووضوح الكلام (Pronunciation & Intelligibility Corrections)**:
  - التمييز بين زوج الأصوات _r / l_ (_liver_ مقابل _river_).
  - التمييز بين الأصوات _f / p_ (_fever_ مقابل _peter_).
  - نطق الصوت الاحتكاكي الأسناني _th_ (_think_ مقابل _tink_).
  - السواكن النهائية المحذوفة والإدراج غير الضروري لحروف العلة (_cardiac_ → _cardi-ack-eu_).
  - وضع نبر الكلمات الطبية في غير محله (_angina_, _arrhythmia_).

### 💡 الجولة التفاعلية للتشغيل الأول (Interactive First-Run Tour)

بعد إكمال الإعداد (onboarding) والدخول إلى لوحة التحكم لأول مرة، يرشدك برنامج تعليمي تفاعلي تلقائياً عبر مواقع ووظائف الأزرار الرئيسية (Dashboard، Practice Hub، Pron Lab، SRS Reviews، History، Help، 1:1 Voice Coach).

## 4. نظرة عامة على الواجهة (5 علامات تبويب والمساعدة)

### شريط التنقل السفلي (5 علامات تبويب)

يتكون التنقل الرئيسي من 5 علامات تبويب سفلية:

```
┌───────────┬──────────────┬───────────────────────┬───────────────┬─────────────┐
│  🏠 Home  │  ▶ Practice  │  🎙️ Pronunciation Lab │  ⚠️ SRS Reviews│  🕘 History │
└───────────┴──────────────┴───────────────────────┴───────────────┴─────────────┘
```

1. **الرئيسية (Home / Dashboard)**: تتابع التدريب (`🔥`)، المهمة السريرية لمدة 5 دقائق، مخططات اتجاهات الأداء، جينوم الأخطاء (Mistake Genome)، خريطة الطريق، و **مدرب الصوت المباشر 1:1 (Always-on 1:1 Voice Coach)**.
2. **التدريب (Practice / Practice Hub)**: المركز الرئيسي لجميع أوضاع التحدث في الوقت الفعلي: مقابلة المريض (Patient Encounters)، والاختبار والتشخيص (Exam & Diagnostic)، واللغة الإنجليزية في المواقف الحساسة (Survival English)، والشرح العكسي (Teach-back)، والمقابلات (Interviews)، والصالون (Lounge)، والسيناريوهات المخصصة (Custom Scenarios).
3. **مختبر النطق (Pronunciation Lab / Pron Lab)**: علامة تبويب تدريب مخصصة لوضوح الكلام وتصحيح النطق (تصفية نمط الخطأ، إدارة حالة الملاحظة).
4. **مراجعة الأخطاء (SRS Reviews / Weakness Review)**: اختبارات المراجعة الصوتية بناءً على خوارزميات التكرار المتباعد لجمل التصحيح المقبولة.
5. **السجل (History / Session History)**: عرض النتائج والملاحظات من الجلسات السابقة، وتتبع تكاليف الرموز، والتصدير إلى Anki/Word، وبدء **تقديم الحالة للطبيب الاستشاري (Present Case)**.

### شريط التطبيق العلوي

- **شعار Bedside English**: العنوان الرئيسي.
- **ويكي المساعدة (أيقونة `?`)**: يؤدي النقر فوق أيقونة `?` إلى فتح دليل المستخدم هذا في عارض ملء الشاشة مع التنقل في جدول المحتويات والبحث بالكلمات الرئيسية في النص الكامل.
- **زر الإعدادات (⚙️ التفضيلات)**: مفاتيح API، والمحركات الصوتية، وسرعة التحدث، ومنع الصدى، واللغة، وإدارة البيانات.

## 5. إتقان لوحة التحكم الرئيسية (Dashboard)

تعرض اللوحة الرئيسية تقدمك السريري:

- **تتابع التدريب السريري (`🔥`)**: يعرض عدد أيام الدراسة المتواصلة لبناء عادة يومية.
- **بطاقات المؤشرات الرئيسية**:
  - **Sessions done**: الجلسات المكتملة والمحللة بالكامل.
  - **Errors tracked**: الأخطاء المكتشفة والمسجلة في قاعدة بياناتك.
  - **Mastered**: الأخطاء التي تم إتقانها وتجاوزها بعد المراجعات.
  - **Due now**: بطاقات المراجعة الصوتية المستحقة اليوم.
  - **Stubborn**: الأخطاء المستعصية (_Leech_) التي تكرر الخطأ فيها 4 مرات أو أكثر.
- **مهمة الـ 5 دقائق اليومية**: توصي بتدريب سريع وموجه بناءً على نقاط ضعفك.
- **تغطية المفردات المبسطة OET**:
  - تتبع استبدال المصطلحات المعقدة (_syncope_) بمصطلحات يفهمها المريض (_fainting_).
  - تظهر المفردات المستخدمة تحت **Recently Unlocked (مفتوحة)** والغير مستخدمة تحت **Next Goals (Locked) (مغلقة)**.
- **لوحة جينوم الأخطاء (Mistake Genome)**: رسم بياني لأكثر 5 فئات أخطاء تكراراً (أدوات التعريف، الجمع، الأزمنة، حروف الجر، الترجمة الحرفية).
- **اتجاهات النمو ورسم التداخل اللغوي**:
  - رسم بياني لمستواك في 5 مجالات عبر آخر 20 جلسة.
  - إظهار أنماط الأخطاء القواعدية المتكررة.
- **خطة التعلم المخصصة**: عرض 4 بطاقات تدريب أولوية بناءً على نقاط ضعفك.
- **زر مدرب الصوت المباشر 1:1 (`🎙️ RecordVoiceOver`)**: في أسفل اليمين لبدء محادثة صوتية موجهة مع الذكاء الاصطناعي في أي وقت.

## 6. مركز التدريب وفتح الميزات التدريجي (Practice Hub & Progressive Feature Unlocking)

### فتح الميزات التدريجي (Progressive Feature Unlocking)

لمنع شعور المستخدمين الجدد بالإرهاق، يبدأ المستخدمون لأول مرة بشاشة مقدمة هادئة تعرض الأوضاع الأساسية (**Dashboard**، **Patient Encounters**، **Survival English**، **History**).

- **إكمال جلسة التدريب الأولى** يؤدي تلقائياً إلى **فتح (unlocks)** الأوضاع المتقدمة (Exam، Teach-back، Interview، Lounge، Custom) مع رسالة احتفال.
- يمكنك أيضاً النقر لتوسيع جميع الأوضاع وإظهارها فوراً من شاشة التدريب (Practice).

### فئات الوضع الرئيسي لمركز التدريب (Practice Hub Main Mode Categories)

1. **Patient Encounters (مقابلة المريض)**: أخذ التاريخ المرضي، المتابعة، وضع الأساسيات (Foundations) للمبتدئين، تمارين المهارات (Skill Drills)، تدريب أخطائي (Practice My Mistakes).
2. **Exam & Diagnostic (الاختبار والتشخيص)**: التشخيص الأساسي لمدة 10 دقائق (10-minute Baseline Diagnostic)، وامتحانات تجريبية لـ OSCE، وOET، وResidency، وWard Round.
3. **Survival English & Listening Lab**: المواقف غير المتوقعة في المستشفى، المحادثات القصيرة السريعة، 15 ملفاً لغوياً بنبرات أصلية، تدريبات التفاصيل في مختبر الاستماع (Listening Lab).
4. **Lecture Teach-back**: تدريب تقنية فاينمان (Feynman technique) بناءً على ملخصات YouTube/النصوص.
5. **Residency Interviews**: مقابلات تجريبية سلوكية (Behavioral)، سريرية (Clinical)، وخاصة بالأطباء الدوليين (IMG-specific).
6. **Free English Lounge**: مناقشات طبية، مناقشات حول ترجمات الأخبار، حل النزاعات في مكان العمل.
7. **Custom Scenarios**: تأليف توجيهات ذكاء اصطناعي (AI prompts) مخصصة ومقاييس تقييم (scoring rubrics).

## 7. مقابلة المريض ومتابع التغطية السريرية

يحاكي أخذ التاريخ المرضي وتقديم المشورة للمرضى بجانب السرير—وهو جوهر التواصل السريري.

### 7-1. الأوضاع الفرعية التشغيلية

- **وضع الأساسيات (Foundations Mode)**: يزيل أعباء الاستدلال السريري للمتعلمين في المراحل المبكرة، مع التركيز بصرامة على **القواعد، والمفردات السريرية، وبناء الألفة (rapport)، والطلاقة**.
- **تمارين المهارات (Skill Drills)**: تمارين مستهدفة للكفاءات الدقيقة (أسلوب NURSE للتعاطف، تفسيرات بلغة مبسطة، تسليم الوردية الليلية، **والترجمة الطبية التتابعية من اللغة الأم ← الإنجليزية**).
- **تدريب أخطائي (Practice My Mistakes)**: يركب اختباراً حوارياً صوتياً فورياً من الأخطاء المعلقة في قاعدة بياناتك.
- **المهمة اليومية (Daily Mission)**: تحدٍ يومي تكيفي مدته 5 دقائق يستهدف فجوات مهاراتك الحالية.

### 7-2. متابع التغطية السريرية في الوقت الفعلي

لوحة قابلة للطي تحدد عناصر أخذ التاريخ المرضي في الوقت الفعلي أثناء حديثك:

- يتتبع العناصر تلقائياً بناءً على سياق محادثة الذكاء الاصطناعي.
- يراقب البداية/المدة، وطبيعة الألم، والانتشار (radiation)، والعوامل المفاقمة/المخففة، والأعراض المصاحبة، وICE (الأفكار، المخاوف، التوقعات)، والتاريخ المرضي السابق، والأدوية، والحساسية، وتاريخ الكحول/التدخين، والتاريخ العائلي، إلخ.
- يتم التعرف على أسئلة التأكيد المنفية مثل _"أنت لا تدخن، أليس كذلك؟"_ وتتبعها بشكل صحيح.

### 7-3. مساعدة الاستمرار المدركة للسياق (`💡 Help me continue`)

إذا توقفت أو نفدت منك الأسئلة في منتصف الجلسة، فانقر على **💡 Help me continue** أسفل الشاشة.

- يحلل أحدث استجابة للمريض لاقتراح هدف السؤال المنطقي التالي مع **جملة نموذجية إنجليزية جاهزة للاستخدام**.
- يعرض متتبع مرحلة المقابلة العلوي التقدم باستخدام رموز الحالة:
  - `✓`: تم اكتشاف أدلة كافية
  - `•`: تم اكتشاف ذكر جزئي
  - `?`: تم الوصول إلى مرحلة لاحقة دون التحقق من المرحلة السابقة

## 8. وضع الاختبار والتشخيص (10 دقائق وتحديد CEFR)

يقيس كفاءة التواصل في ظل ظروف امتحان غامرة ومحددة بوقت:

### التشخيص السريري للغة الإنجليزية لمدة 10 دقائق

- يبدأ بمقدمة للممتحِن، تليها 4 مهام قصيرة (شرح التشخيص، التعامل مع أسئلة المتابعة، تقديم تسليم SBAR لمدة 45 ثانية، والإجابة على سؤال مقابلة الإقامة الطبية).
- يربط أدائك تلقائياً بدرجات **CEFR** الدولية:
  - **النتيجة >= 8.5**: **C1** (تواصل سريري آمن وطلِق على مستوى طبيب استشاري)
  - **النتيجة >= 7.2**: **B2+** (مؤهل للتدريب السريري والممارسة في المستشفيات)
  - **النتيجة >= 6.0**: **B1-B2** (قدرة تواصل أساسية؛ يُوصى بالدراسة المنهجية)
  - **النتيجة < 6.0**: **A2-B1** (مطلوب تدريب تأسيسي على التواصل السريري)

### سيناريوهات الاختبارات التجريبية

- **OSCE**: أخذ التاريخ المرضي لألم الصدر (Mr. Hayes) (قياس ICE، واكتشاف العلامات الحمراء، والتعاطف).
- **OET Speaking**: لعب دور لتقديم المشورة لمريض ارتفاع ضغط الدم.
- **Residency**: مقابلة تجريبية لمدير برنامج الطب الباطني بالولايات المتحدة.
- **Ward Round**: عرض شفهي لحالة التهاب رئوي مكتسب من المجتمع لمدة 5 دقائق والتعامل مع الأسئلة الشفوية.

### شارة موثوقية النتيجة (Score Reliability Badge)

تشير إلى ثقة الذكاء الاصطناعي في التقييم كـ **High** (عالية)، أو **Medium** (متوسطة)، أو **Low** (منخفضة):

- **High**: عدد كلمات المتعلم >= 180 كلمة ومعدل أدلة قائمة التحقق >= 75%.
- **Medium**: عدد كلمات المتعلم >= 80 كلمة ومعدل أدلة قائمة التحقق >= 50%.
- **Low**: عدد الكلمات < 80 كلمة (إشارة Short Transcript) أو معدل الأدلة < 50%.

## 9. مختبر النطق ووضوح الكلام (Pron Lab)

يقع في علامة التبويب السفلية الثالثة المخصصة (`🎙️ Pron Lab`)، وهو مركز التدريب المتخصص الخاص بك لوضوح الكلام.

### 💡 التوجيه القائم على وضوح الكلام

الهدف ليس تقليد اللهجة الأصلية، بل **"هل يستطيع الزملاء والمرضى الدوليون فهم كلامي بوضوح دون سوء فهم؟"**

- يوفر التحليل الصوتي توجيهاً دقيقاً فقط حول عناصر النطق التي تسبب سوء فهم لدى المستمع.

### فئات أنماط الأخطاء وتصفية الشرائح (Filter Chips)

يتم تنظيم أخطاء النطق المكتشفة عبر جلساتك حسب الفئة في شرائح تصفية:

- `r · l`: _liver / river_، _clinical / critical_
- `f · p`: _fever / peter_، _palpation / falcation_
- `th`: _think / tink_، _throat / troat_
- `final`: السواكن النهائية المحذوفة (_chest / ches_)
- `cluster`: معالجة مجموعات السواكن وإدراج حروف العلة غير الضرورية (_cardiac_ → _cardi-ack-eu_)
- `stress`: وضع نبر الكلمات الطبية في غير محله (_angina_, _arrhythmia_)
- `vowel`: الخلط بين حروف العلة القصيرة والطويلة (_ship / sheep_، _fit / feet_)

### قاعدة ترقية حالة الملاحظة (Observed State Promotion Rule)

عندما يتم تسجيل بطاقة نطق مقبولة لأول مرة، فإنها تدخل في حالة **Observed** (تحت الملاحظة) بدلاً من أن تصبح بطاقة واجب منزلي يومية على الفور. يتم ترقيتها إلى بطاقة خطأ مراجعة SRS نشطة فقط عندما يتكرر نفس نمط الخطأ في جلسة منفصلة، مما يضمن أن الأخطاء المؤقتة للتعرف على الصوت التي تحدث لمرة واحدة لا تخلق واجباً منزلياً مفرطاً.

## 10. إنجليزية المواقف الحساسة ومختبر الاستماع (Survival English & Listening Lab)

يُعد الخريجين الطبيين الدوليين (IMGs) للتفاعلات غير السريرية في المستشفيات على أرض الواقع خارج غرفة الفحص.

- **الوضع العشوائي / المفاجئ (Random / Surprise Mode)**: التعامل العفوي مع المواقف غير المتوقعة (الأسئلة السريعة في الردهة (hallway curbside questions)، مكالمات الصيدلية، أحاديث الممرضات القصيرة) مع إخفاء سياق السيناريو حتى يبدأ الذكاء الاصطناعي في التحدث.
- **المحادثات القصيرة السريعة (Rapid-fire Small Talk)**: ردود سريعة على التغييرات المفاجئة في الموضوع.
- **15 ملفاً شخصياً للنبرات الأصلية (15 Native Accent Profiles)**: تدرب على التكيف مع النبرات الأصلية الدولية وإيقاعات الكلام.
- **التحكم في سرعة الصوت في الوقت الفعلي (0.5× إلى 2.5×) (Real-time Audio Speed Control)**: شريط تمرير لسرعة التشغيل مع الحفاظ على طبقة الصوت (Pitch-preserving) للتكيف مع المتحدثين الأصليين السريعين.
- **وضع الاستماع للأذن فقط (Ear-only Listening Mode)**: يخفي ترجمات محادثات الذكاء الاصطناعي بحيث تعتمد فقط على الاستماع، مع توفر خيار **[Reveal last line]** عند الحاجة.
- **تشجيع عبارات الإصلاح والاستدراك (Repair Expression Encouragement)**: يمنحك استخدام استراتيجيات الإصلاح مثل _"Sorry?", "Could you say that again?"_ **نقاطاً إضافية (bonus points)** بدلاً من خصم النقاط.
- **مختبر الاستماع (Listening Lab)**: تمارين تختبر الفهم الدقيق للتفاصيل (الأرقام، جرعات الأدوية، أسماء المرضى، الأوقات، الاتجاهات، الأسعار) مع تقييم دقة مفصل.

## 11. الشرح العكسي للمحاضرات (Lecture Teach-back) (تقنية فاينمان)

يستخدم تقنية فاينمان (Feynman technique) - وهي شرح المفاهيم بصوت عالٍ كما لو كنت تُدرس شخصاً آخر - لترسيخ المعرفة الطبية.

1. **إعداد مواد المحاضرة (Prepare Lecture Material)**: الصق الملاحظات الملخصة أو أدخل رابط فيديو لمحاضرة طبية على YouTube وانقر على **`🎬 Fetch YT transcript`**.
2. **تكثيف الذكاء الاصطناعي (AI Condensation)**: للمواد الطويلة، انقر على **`✨ Condense`** لضغط النص إلى مخطط منظم مكون من 500 كلمة.
3. **تحديد شخصية الجمهور (Select Audience Persona)**:
   - **أستاذ الامتحان الشفوي (Oral Exam Professor)**: يطرح أسئلة متابعة سريرية حادة ومليئة بالتحديات مثل "لماذا" (Why) و"ماذا لو" (What-if).
   - **زميل صف مرتبك (Confused Classmate)**: يطلب شروحات بلغة مبسطة دون مصطلحات معقدة.
   - **معلم ودود (Friendly Tutor)**: يقدم تشجيعاً داعماً وتوجيهاً للصياغة.
4. **التدريس (Teach)**: انقر على **Start** (بدء) واشرح عبر الميكروفون بينما يستجيب المستمع الذي يعمل بالذكاء الاصطناعي بأسئلة توضيحية.

## 12. مقابلات الإقامة الطبية التجريبية

محاكاة واقعية لمقابلات الإقامة الطبية والعمل بالمستشفيات في الخارج (US Residency Match):

- **Behavioral (السلوكية)**: وصف التجارب والخبرات باستخدام طريقة STAR (الوضع، المهمة، الإجراء، النتيجة).
- **Clinical (السريرية)**: تقديم الحالات الشفهية، الأخلاقيات الطبية، ومنطق التعامل مع الطوارئ.
- **IMG-Specific (خاصة بالأطباء الدوليين)**: التركيز على أسئلة رعاية التأشيرة (Visa sponsorship)، تفسير فترات الانقطاع (Gap years)، واستعراض النقاط القوية للأطباء الدوليين.
- يقوم مدير البرنامج (Program Director) بطرح أسئلة متتابعة ودقيقة.

## 13. صالون الإنجليزية الحر والسيناريوهات المخصصة

### صالون الإنجليزية الحر (Free English Lounge)

- ناقش المواضيع الطبية الحالية، أو لخص مقالات المجلات الطبية، أو قم بحل النزاعات في مكان العمل/مع الممرضين، أو تدرب على المحادثات القصيرة في أوقات الاستراحة.
- قم بجلب ترجمات الأخبار الطبية من YouTube للمناقشة بحرية مع الذكاء الاصطناعي.

### السيناريوهات المخصصة (Custom Scenarios)

قم بإنشاء سيناريوهات تدريب مخصصة ومصممة حسب احتياجاتك:

- **Scenario Name**: مُعرف مخصص.
- **Persona / Context**: توجيه النظام (System prompt) الذي يحدد دور الذكاء الاصطناعي والموقف.
- **Eval Template**: حدد معايير التقييم (على سبيل المثال، بروتوكول SPIKES لنقل الأخبار السيئة).
- **Custom Eval Criteria**: حدد نقاط تقييم رئيسية معينة لكي يتحقق منها الذكاء الاصطناعي.

## 14. تفكيك تقرير الملاحظات (7 أقسام رئيسية) (Deconstructing the Feedback Report)

بعد الانتهاء من الجلسة، يوفر تقرير مكون من 7 أقسام ملاحظات متعددة الأبعاد:

1. **النتائج (Scores)**: يقارن درجات نطاق الذكاء الاصطناعي (0–10) جنباً إلى جنب مع تقييمك الذاتي. تؤدي الفجوة البالغة **2.0+ نقطة** إلى تشغيل بطاقة صفراء **Reflection Prompt** (موجه تأمل) لتوجيه التأمل الذاتي.
2. **الطلاقة (Fluency)**:
   - **WPM (كلمة في الدقيقة)**: يقيس سرعة التحدث مقابل الأهداف الموصى بها (100–130 WPM).
   - **كلمات الحشو (Filler Words)**: يقيس كثافة كلمات الحشو (`um`، `uh`، `like`)، مما يشجع على الاستخدام الفعال للوقفات (pauses).
3. **قائمة التحقق (Checklist)**: يقيّم الأهداف السريرية، ويقتبس جمل المحادثة الدقيقة كـ **Evidence** (أدلة).
4. **مقارنة ملاحظات SOAP (SOAP Note Comparison)**: يقارن ملاحظة SOAP التي تم إنشاؤها تلقائياً من جلستك مع ملاحظة SOAP مرجعية نموذجية.
5. **التصحيحات (Corrections)**: تصحيحات قائمة على البطاقات للترجمات الحرفية المباشرة، والأدوات/الجمع، والتعبيرات غير الطبيعية، والنطق. يؤدي النقر على **[Accept]** إلى تسجيل العنصر في متتبع أخطاء SRS الشخصي الخاص بك.
6. **التظليل (Shadowing)**: يعيد كتابة الجمل الضعيفة إلى لغة إنجليزية سريرية بمستوى طبيب استشاري (attending-level) للتدريب الصوتي على الاستماع والتكرار.
7. **الملخص وبطاقات المشاركة (Summary & Share Cards)**: يعرض الملاحظات العامة ويوفر منشئ صور **Share Card** لمشاركة ملخصات الأداء مع زملاء الدراسة.

## 16. متتبع الأخطاء بالتكرار المتباعد وجينوم الأخطاء

تُدار التصحيحات المقبولة عبر النقر على **[Accept]** تلقائياً بواسطة خوارزميات التكرار المتباعد في قاعدة بيانات الأخطاء الخاصة بك.

- **منع التكرار (Fuzzy Duplicate Detection)**: يمنع التسجيل المزدوج للأخطاء المتشابهة تلقائياً.
- **الأخطاء المستعصية (Stubborn / Leech)**: تُصنف العناصر التي يتم الخطأ فيها 4 مرات متتالية أو أكثر في اختبارات المراجعة كـ **Stubborn / Leech** من أجل الإدارة المركزة.
- **فترات التكرار المتباعد العلمية**:
  - جدول المراجعة: **1 يوم ← 3 أيام ← 7 أيام ← 14 يوماً ← 30 يوماً**. اجتياز 3 مراجعات متتالية ينقل العنصر إلى حالة **Mastered** (مُتقن).
  - اجتياز الاختبارات الصوتية في **Practice My Mistakes** يطور العناصر نحو الإتقان (Mastery).
- **لوحة جينوم الأخطاء (Mistake Genome Panel)**:
  - تعرض أعلى 5 فئات أخطاء لديك (الأدوات (Articles)، صيغ الجمع (Plurals)، الأزمنة (Tense)، حروف الجر (Prepositions)، مستوى اللغة (Register)، الترجمات الحرفية (Direct Translations)) كمخطط شريطي في لوحة التحكم (Dashboard) مع تلميحات توضيحية بلغة مبسطة.

## 17. تقديم الحالة للطبيب الاستشاري (Present Case)

تقديم عرض شفهي للحالة بعد مقابلة المريض:

1. إكمال جلسة **Patient Encounter**.
2. الانتقال لعلامة التبويب **السجل (History)** واختيار الجلسة والنقر على **`📋 Present Case`**.
3. يبدأ الطبيب الاستشاري (Attending): _"دكتور، يرجى تقديم حالة المريض الذي عاينته للتو"_.
4. تقديم العرض الشفهي بصيغة SBAR أو SOAP والإجابة على الأسئلة التتبعية.

## 18. استيراد سجل المحادثات الخارجية (Import Transcript)

استورد نص المحادثة من ChatGPT أو Gemini أو الملاحظات السريرية إلى التطبيق لتلقي ملاحظات كاملة:

1. **تكامل مشاركة Android (Android Share Integration)**: قم بتحديد نص المحادثة في التطبيقات الخارجية وحدد **[Share] ← [Bedside English]** لفتح شاشة **Import Transcript** تلقائياً.
2. **الإدخال المباشر / اللصق (Direct Entry / Paste)**: افتح شاشة `Import Transcript` مباشرة من التفضيلات (Preferences) أو القائمة الرئيسية والصق النص.
3. **الملاحظات التلقائية والتكرار المتباعد (Automated Feedback & SRS)**: يُنشئ درجات النطاق، وملاحظات SOAP، وبطاقات تصحيح متاحة للقبول في نظام SRS.

## 19. تصدير بطاقات Anki ومستندات Word

- **تصدير بطاقة Anki (ملف `.txt` مفصول بعلامات جدولة)**:
  - يحول التصحيحات المقبولة إلى ملف استيراد نص عادي لبرنامج Anki (ملف ← استيراد في Anki / AnkiDroid). يتم نقل فئة كل خطأ كعلامة (tag). متاح على حد سواء في شاشة ملاحظات ما بعد الجلسة ومن **My Mistakes** (أخطائي)، والذي يصدر قائمة المراجعة بأكملها دفعة واحدة.
- **تصدير تقرير Word (`.docx`)**:
  - ينشئ تقارير طبية منظمة تحتوي على الدرجات، وأدلة قائمة التحقق، وملاحظات SOAP، وتصحيحات الجمل. يتيح خيار التفضيلات الحفظ التلقائي.

## 20. ويكي المساعدة المدمج في التطبيق (In-App Help Wiki)

يؤدي النقر فوق **أيقونة المساعدة `?`** في شريط التطبيق العلوي إلى فتح عارض ويكي المساعدة المدمج في وضع ملء الشاشة.

- **التكامل متعدد اللغات (Multilingual Integration)**: يحمّل تلقائياً ملف دليل المستخدم المطابق لإعداد لغة واجهة المستخدم الخاصة بالتطبيق.
- **شريط الشريط الجانبي لجدول المحتويات (TOC)**: يتيح التنقل السريع للقفز عبر جميع أقسام الدليل.
- **البحث في النص الكامل (Full-Text Search)**: أدخل كلمات رئيسية في شريط البحث لتمييز التطابقات والتنقل باستخدام زري السابق/التالي.
- **الروابط التشعبية الخارجية (External Hyperlinks)**: يؤدي النقر فوق روابط الويب في الدليل إلى فتح متصفح النظام الافتراضي الخاص بك.

## 21. إعدادات لغة واجهة المستخدم وتتبع تكاليف API والتفضيلات (UI Language Settings, API Cost Tracking & Preferences)

قم بالوصول إلى **ترس الإعدادات (⚙️ Settings)** في الشريط العلوي لتخصيص التطبيق ليناسب جهازك وميزانيتك:

- **الصوت والملاحظات (Voice & Feedback)**:
  - حدد نماذج الذكاء الاصطناعي للصوت والملاحظات (Demo، Gemini، OpenAI، Claude).
  - **منع الصدى (Echo Prevention)**: يكتم الميكروفون تلقائياً أثناء حديث الذكاء الاصطناعي لمنع حلقات ردود الفعل الصوتية (ضروري عند عدم استخدام سماعات الرأس).
  - **سرعة تحدث الذكاء الاصطناعي (AI Speaking Pace)**: تحكم متدرج في السرعة (Slow، Normal، Fast، Challenge).
- **تحليلات تكلفة API (API Cost Analytics)**: يتتبع بشفافية استخدام الرموز والتكلفة المقدرة بالدولار لكل جلسة مع تصورات للمخططات.
- **الصوت (Audio)**: مؤشر مستوى الميكروفون في الوقت الفعلي ونغمة اختبار مكبر الصوت.
- **مفاتيح API (API Keys)**: مدير مفاتيح التخزين المشفر المحلي.
- **التصدير والتعلم (Export & Learning)**: خيارات الحفظ التلقائي لملفات Docx، والإدخال الإلزامي لملاحظات SOAP، وإعدادات اللغة الأم (Native Language)، ولغة واجهة المستخدم (UI Language).
- **البيانات (Data)**: التبديل بين تشغيل وإيقاف تحليل النطق، وتكوين المحركات، واختيار محركات التظليل TTS.
- **الخصوصية (Privacy)**: التبديل بين تشغيل وإيقاف القياس عن بُعد للاستخدام المجهول (anonymous usage telemetry).

## 22. الأسئلة الشائعة (FAQ) ومعايير التقييم (Scoring Rubric)

### الأسئلة الشائعة (FAQ)

**س: الميكروفون لا يلتقط الصوت والذكاء الاصطناعي لا يستجيب.**

- تحقق من إعدادات Android (**Settings → Apps → Bedside English → Permissions → Microphone**) وقم بتعيينه على [Allow] (السماح). إذا تم رفض الإذن، يتحول التطبيق إلى وضع **Type instead** (الكتابة بدلاً من ذلك) حتى تتمكن من مواصلة التدريب عبر لوحة المفاتيح.

**س: أوضاع التدريب المتقدمة (Exam، Teach-back، Interview، Lounge، Custom) مفقودة.**

- أكمل جلسة التدريب الأولى وسيتم إلغاء قفل جميع الأوضاع المتقدمة تلقائياً مع رسالة احتفال. يمكنك أيضاً التوسيع والكشف عن جميع الأوضاع من شاشة التدريب (Practice).

**س: لا تنتقل نتائج تحليل النطق إلى قاعدة بيانات مراجعة SRS الخاصة بي على الفور.**

- لمنع أخطاء التعرف على الكلام التي تحدث لمرة واحدة من إثقال كاهل المتعلمين، تدخل عناصر النطق المقبولة حالة **Observed** (تحت الملاحظة) أولاً. يتم ترقيتها إلى بطاقات مراجعة SRS نشطة فقط عندما يتكرر نفس نمط الخطأ في جلسة مستقبلية.

**س: هل يمكنني استيراد نصوص المحادثات الخارجية (مثل ChatGPT) للتقييم؟**

- نعم. استخدم ميزة المشاركة في Android لمشاركة النص مع Bedside English أو الصق النص في شاشة `Import Transcript` لتلقي ملاحظات كاملة وملاحظات SOAP وبطاقات تصحيح.
