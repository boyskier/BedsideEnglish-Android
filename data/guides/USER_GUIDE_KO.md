# Bedside English 사용자 설명서

**대상:** 임상 의학 영어, OSCE, OET Speaking, 미국 레지던시(US Residency) 면접, 회진(Ward Round) 발표, 임상 의사소통(Clinical Communication)을 준비하는 해외의대 졸업자(IMG), 전공의, 의대생 및 의료진.

Bedside English는 대화형 AI(Google Gemini, OpenAI Realtime, Anthropic Claude)와 실시간 음성 기술을 활용하여 임상 의사소통(Clinical Communication) 능력, 의학적 추론, 발음 및 전달 명료도(Intelligibility)를 다각도로 훈련하는 안드로이드 전용 앱입니다. 본 설명서는 최신 앱 버전의 전체 기능과 활용법을 사용자 눈높이에 맞춰 상세히 안내합니다.

## 1. API 키 발급 및 설정

Bedside English는 구글 제미나이(Google Gemini), 오픈AI(OpenAI), 앤트로픽 클로드(Anthropic Claude) 백엔드를 유연하게 지원합니다.

### 💡 권장 설정 (Google Gemini 단일 키 모드)
**Google Gemini API 키 하나만 등록하면 실시간 음성 대화부터 세션 피드백 분석까지 앱의 모든 기능을 가장 빠르고 경제적으로 사용**할 수 있습니다.

| 서비스 | 주요 용도 | 권장/필수 | 발급 링크 |
| :--- | :--- | :--- | :--- |
| **Google (Gemini)** | 실시간 음성 대화 (Gemini Live) + 피드백 정밀 분석 | **필수 (단일 키로 전 기능 작동)** | [aistudio.google.com](https://aistudio.google.com) |
| **OpenAI** | 실시간 음성 대화 (OpenAI Realtime) + 피드백 + 고품질 TTS | 선택 사항 | [platform.openai.com](https://platform.openai.com) |
| **Anthropic (Claude)** | 세션 피드백 분석 (선택 변경 가능) | 선택 사항 (기본값은 Gemini) | [console.anthropic.com](https://console.anthropic.com) |

### API 키 입력 및 보안
API 키는 앱 내부에서 직접 입력합니다:
* **첫 실행 온보딩 위저드** 또는 상단 바의 **설정 톱니바퀴(⚙️) → Preferences → API Keys** 메뉴에서 설정할 수 있습니다.
* 입력된 API 키는 기기 내부 전용 보안 암호화 저장소에 **안전하게 보관**되며 외부 서버로 전송되지 않습니다.
* 각 키 입력란 우측의 눈 모양 아이콘으로 키 숨기기/보기를 자유롭게 전환할 수 있습니다.

### 🎈 데모 모드 (Demo Mode — 완전 무료 체험)
API 키나 마이크 권한 없이 앱을 체험하고 싶다면 온보딩 화면이나 **Preferences**에서 **Demo** 모드를 선택하세요.
미리 준비된 스크립트 모의 대화와 피드백 데이터가 로드되어 전체 UI, 오답 노트, 약점 복습 기능을 토큰 소비 없이 **무료**로 탐색할 수 있으며, 데모 세션 완료 후에는 안내 창을 통해 언제든 API 키를 등록하거나 다음 데모 환자 연습을 계속할 수 있습니다.

## 2. 앱 설치 및 권한 설정

Bedside English는 안드로이드 8.0 (API 레벨 26) 이상의 스마트폰 및 태블릿에서 사용할 수 있습니다.

### 앱 설치
* 제공된 설치 파일(`.apk`)을 안드로이드 기기에서 실행하여 안내에 따라 설치합니다.

### 마이크 권한 및 텍스트 전환 모드
* 실전 음성 연습 모드를 시작할 때 안드로이드 OS의 마이크 접근 권한 요청 창이 표시됩니다. **[허용]**을 선택해야 음성 인식이 정상 작동합니다.
* 만약 마이크 사용이 어려운 환경이거나 권한을 거부하더라도 앱이 중단되지 않으며, **텍스트 입력 모드(Type instead)**로 자동 전환되어 키보드 타이핑으로 대화 연습을 진행할 수 있습니다.

### 알림 권한 및 음성 사전 점검 (Audio Preflight)
* 백그라운드 피드백 분석이 완료되었을 때 알림을 받기 위해 알림 권한을 요청합니다.
* 첫 실전 음성 세션 시작 직전 **음성 사전 점검 (Audio Preflight)** 안내 창이 표시되어 이어폰 착용 안내 및 마이크 입력 상태를 미리 점검하여 스피커 하울링(소리 울림)을 예방합니다.

## 3. 첫 실행 온보딩 & 한국어 사용자 맞춤 설정

앱을 처음 설치하고 실행하면 4단계 설정 위저드가 진행되어 맞춤 학습 환경을 구축합니다:

1. **환영 화면 (Welcome)**: 핵심 기능 안내 및 API 키 없이 둘러볼 수 있는 **Try Demo Mode** 버튼을 제공합니다.
2. **UI 언어 선택 (Language Picker)**: 화면 표시 언어(한국어, 영어, 스페인어, 중국어, 아랍어, 힌디어, 포르투갈어, 타갈로그어 등 8개 국어)를 선택합니다.
3. **API 키 설정 (API Keys)**: 보유하신 Google Gemini 등 API 키를 등록합니다.
4. **모국어 설정 & 개인정보 보호 (Native Language & Privacy)**: 모국어로 **Korean (한국어)**을 선택하면 한국인 학습자 특화 L1 문법 간섭 및 발음 특성에 대한 정밀 맞춤 분석을 받게 됩니다.

### 🇰🇷 한국어 모국어 사용자 특화 맞춤 분석 항목
* **문법 및 표현 교정**:
  * 관사 누락 (*a/an/the* 명사 앞 누락)
  * 복수형 *-s* 누락 (*two patient* → *two patients*)
  * 시제 오류 (과거력 언급 시 현재시제 혼용)
  * 전치사 오용 (*in hospital*, *explain to patient* 전치사 누락/오류)
  * 콩글리시 1:1 직번역 (*skin scale*, *side effect* 어색한 직역)
* **발음 및 전달 명료도 교정**:
  * *r / l* 최소 대립쌍 구분 (*liver* vs *river*)
  * *f / p* 구분 (*fever* vs *peter*)
  * *th* 치음 발음 (*think* vs *tink*)
  * 받침 자음 처리 및 모음 으/이 불필요 삽입 (*cardiac* → *cardi-ack-eu*)
  * 의학 용어 단어 강세(Word Stress) 오인식 (*angina*, *arrhythmia*)

### 💡 첫 실행 안내 튜토리얼 (First-Run Tour)
온보딩 완료 후 대시보드에 처음 진입하면 주요 기능 버튼(대시보드, 연습 허브, 발음 랩, 약점 복습, 세션 기록, 도움말, 1:1 영어 코치)의 위치와 역할을 안내하는 대화형 튜토리얼이 자동으로 진행됩니다.

## 4. 화면 구성 한눈에 보기 (하단 5개 탭 & 도움말)

### 하단 내비게이션 바 (5개 탭)
앱의 핵심 기능은 하단 5개 탭으로 구성되어 있습니다:

```
┌───────────┬──────────────┬───────────────────────┬───────────────┬─────────────┐
│  🏠 Home  │  ▶ Practice  │  🎙️ Pronunciation Lab │  ⚠️ SRS Reviews│  🕘 History │
└───────────┴──────────────┴───────────────────────┴───────────────┴─────────────┘
```

1. **Home (대시보드)**: 연속 학습 불꽃(`🔥`), 5분 임상 미션, 성과 추세 차트, Mistake Genome, 로드맵 및 **상시 1:1 영어 코치**.
2. **Practice (연습 허브)**: 환자 진료, 임상 진단 테스트, 생존 영어, 티치백, 면접, 라운지 등 모든 실시간 말하기 연습 모드의 집결지.
3. **Pronunciation Lab (발음 랩)**: 발음 및 전달 명료도(Intelligibility) 교정 전용 훈련 탭 (오류 패턴 필터링, 복습 상태 관리).
4. **SRS Reviews (약점 복습)**: 수락한 교정 문장을 망각 곡선 알고리즘에 맞춰 입으로 소리 내어 복습하는 오답 노트 퀴즈.
5. **History (세션 히스토리)**: 지난 연습 세션의 점수와 피드백 조회, 토큰 비용 추적, Anki/Word 내보내기 및 **주치의 케이스 발표(Present Case)** 연속 실행.

### 상단 앱 바 (Top App Bar)
* **Bedside English 로고**: 브랜드 타이틀.
* **도움말 위키 (`?` 아이콘)**: 상단 바 `?` 아이콘을 누르면 본 사용자 설명서가 풀스크린 뷰어로 열립니다. (목차 이동 및 키워드 검색 지원).
* **설정 톱니바퀴 (⚙️ Preferences)**: API 키, 백엔드 선택, 음성 속도, 하울링 방지, 언어 및 데이터 관리.

## 5. 대시보드 (Home) 완벽 활용법

메인 대시보드는 임상 영어 소통 능력의 성장을 다각도로 시각화해 줍니다.

* **연속 학습 일수 (Practice Streak)**: 매일 꾸준한 연습 습관을 형성하도록 연속 학습 일수를 불꽃 기호(`🔥`)로 표시합니다.
* **핵심 지표 카드**:
  * **Sessions done**: 완료 후 피드백 분석까지 끝마친 총 세션 횟수.
  * **Errors tracked**: 확인되어 개인 약점 데이터베이스에 등록된 교정 항목 수.
  * **Mastered**: 반복 복습 퀴즈를 통과하여 완벽히 교정된 실수 개수.
  * **Due now**: 오늘 복습해야 하는 SRS 오답 퀴즈 개수.
  * **Stubborn**: 4회 이상 반복 틀려 집중 관리가 필요한 '고질적 실수(Leech)'.
* **오늘의 5분 임상 미션 (Today's 5-Minute Clinical Mission)**: 당일 복습할 오답이 있거나 진단 테스트가 필요할 때, 또는 가장 저조한 영역을 타겟팅하여 최적의 5분 연습 코스를 자동 추천합니다.
* **OET Layman 어휘 커버리지**:
  * 환자가 이해하기 어려운 의학 전문 용어(Jargon, 예: *syncope*) 대신 일상 용어(Layman terms, 예: *fainting*)를 잘 구사하는지 추적합니다.
  * 사용한 표현은 **Recently Unlocked(해금)**로 표시되고, 미사용 표현은 **Next Goals(잠금)**에 나열됩니다.
* **Mistake Genome 패널**: 내가 자주 범하는 오류 카테고리(관사, 복수형, 시제, 전치사, 레지스터, 콩글리시 등)를 분석하여 상위 5개 약점 비중을 바 차트로 보여줍니다.
* **성장 추세 그래프 & 한국어 간섭 차트**:
  * 최근 20개 세션의 5대 영역 점수(Grammar, Accuracy, Reasoning, Professionalism, Fluency) 추이를 그래프로 보여줍니다.
  * 자주 실수하는 문법 패턴을 시각화합니다.
* **맞춤형 추천 로드맵**: 취약 지표와 오답 항목을 분석하여 나에게 가장 필요한 4가지 중점 학습 카드를 우선순위별로 제시합니다.
* **상시 1:1 영어 코치 버튼 (`🎙️ RecordVoiceOver`)**:
  * 대시보드 우측 하단의 음성 코치 버튼을 누르면 세션 시작 절차 없이 언제든 AI 영어 튜터와 자유롭게 1:1 소리 내어 말하기 대화를 나눌 수 있습니다. 내 개인 약점 프로필을 기반으로 맞춤 코칭이 제공됩니다.

## 6. 연습 허브 (Practice Hub) & 기능 해금

### 단계적 기능 해금 (기능 순차 열림)
처음 설치한 사용자가 복잡함에 압도되지 않도록, 첫 실행 시에는 핵심 모드(**대시보드**, **환자 진료 연습**, **생존 영어**, **세션 히스토리**)로 구성된 차분한 첫 화면을 제공합니다.
* **첫 번째 연습 세션을 완료**하면 Exam, Teach-back, Interview, Lounge, Custom 등 심화 모드들이 축하 메시지와 함께 **자동으로 해금**됩니다.
* Practice 화면에서 즉시 전체 모드를 펼쳐볼 수도 있습니다.

### 연습 허브 주요 모드 카테고리
1. **Patient Encounters (환자 진료 연습)**: 병력 청취, follow-up, Foundations 초급 모드, Skill Drills, Practice My Mistakes.
2. **Exam & Diagnostic (평가 및 진단)**: 10분 Baseline Diagnostic 및 OSCE, OET, Residency, Ward Round 모의고사.
3. **Survival English & Listening Lab (생존 영어 & 리스닝 랩)**: 병원 현장 돌발 상황, 스몰토크, 15개 억양, 리스닝 정밀 청취.
4. **Lecture Teach-back (강의 티치백)**: 파인만 학습법 기반 YouTube/텍스트 요약 발표 훈련.
5. **Residency Interviews (레지던시 면접)**: Behavioral, Clinical, IMG 특화 면접.
6. **Free English Lounge (라운지 & 토론)**: 의학 이슈 토론, 뉴스 자막 토론, 직장 내 갈등 조율.
7. **Custom Scenarios (자유 시나리오)**: 사용자 정의 AI 프롬프트 및 채점 루브릭.

## 7. 환자 진료 연습 (Patient Encounters) & 문진 트래커

의료 커뮤니케이션의 핵심인 병력 청취(History Taking) 및 환자 상담을 시뮬레이션합니다.

### 7-1. 연습 모드 분과
* **Foundations 모드**: 의학적 추론 부담을 줄이고 **문법, 임상 어휘, 라포 형성, 유창성**에만 집중하는 초·중급자용 모드입니다.
* **Skill Drills**: 미세 역량 훈련 모드 (NURSE 공감 기법, 쉬운 용어 설명, 야간 인계, **한국어→영어 메디컬 순차 통역 드릴**).
* **Practice My Mistakes**: 약점 데이터베이스에 저장된 내 과거 실수들을 바탕으로 음성 대화형 오답 퀴즈를 즉석 생성합니다.
* **Daily Mission**: 당일 취약 영역을 보완하도록 자동 생성되는 5분 미션.

### 7-2. 실시간 문진 커버리지 트래커
대화 중 실시간으로 병력 청취 항목의 수집 여부를 체크하는 열림/닫힘 접이식 패널입니다.
* AI 대화 내용을 바탕으로 실시간으로 항목을 체크합니다.
* 통증 발병/유기간, 통증 양상, 방사통, 악화/완화 요인, 동반 증상, ICE(Ideas, Concerns, Expectations), 과거력, 복용 약물, 알레르기, 음주/흡연력, 가족력 등을 추적합니다.
* *"담배 안 피우시죠?"*와 같은 부정 확인 질문도 항목 작성으로 정확히 인정됩니다.

### 7-3. 상황 맞춤형 대화 힌트 (`💡 Help me continue` / 💡 다음 말 도와주세요)
대화 중 다음 질문이 떠오르지 않거나 막힐 때 하단의 **💡 다음 말 도와주세요** 버튼을 누르세요.
* 환자의 직전 답변 문맥을 분석하여 자연스럽게 이어질 질문 목적과 **바로 사용할 수 있는 영어 예문 문장**을 즉시 추천해 줍니다.
* 상단 인터뷰 단계 트래커에 수행 현황이 기호로 표시됩니다:
  * `✓`: 충분한 발화 근거 확인 완료
  * `•`: 부분적 언급 확인
  * `?`: 이전 필수 단계를 건너뛰고 다음 단계로 진입함

## 8. 평가 및 진단 모드 (Exam & Diagnostic)

실전 시험과 동일한 몰입감과 제한 시간 속에서 소통 실력을 정밀 측정합니다:

### 10분 임상 영어 진단 테스트 (10-minute Baseline Diagnostic)
* 감독관 인사를 시작으로 4가지 단기 태스크(환자 진단 설명, 추가 질문 대처, 45초 SBAR 인계 보고, 레지던시 면접 질문 답변)를 연속 수행합니다.
* 평가 결과를 국제 표준 **CEFR 등급**으로 자동 매핑합니다:
  * **평점 >= 8.5**: **C1** (전문 의사 수준의 원활하고 안전한 임상 소통)
  * **평점 >= 7.2**: **B2+** (해외 병원 실습 및 임상 수행 통과 가능 수준)
  * **평점 >= 6.0**: **B1-B2** (기본 소통 가능하나 보완 학습 필요)
  * **평점 < 6.0**: **A2-B1** (기초 임상 소통 훈련 필요)

### 실전 모의고사 유형
* **OSCE**: 흉통 환자(Mr. Hayes) 병력 청취 (ICE, 위험 신호 탐지, 공감 라포 형성 측정).
* **OET Speaking**: 고혈압 환자 상담 역할극.
* **Residency**: 미국 내과 레지던시 프로그램 디렉터 모의 면접.
* **Ward Round**: 5분 간 지역사회획득 폐렴 증례 발표 및 구술 질문 대처.

### 점수 신뢰도 표시 (Score Reliability)
AI 평가 결과의 신뢰성을 **High**, **Medium**, **Low** 3단계로 명확히 표시합니다:
* **High**: 학습자 발화 단어 수 180단어 이상 & 평가 항목 근거율 75% 이상.
* **Medium**: 단어 수 80단어 이상 & 평가 항목 근거율 50% 이상.
* **Low**: 단어 수 80단어 미만(Short Transcript) 또는 근거율 50% 미만.

## 9. 발음 및 전달 명료도 랩 (Pronunciation Lab)

하단 3번째 전용 탭(`🎙️ Pron Lab`)에 위치한 발음 및 전달 명료도 전용 훈련 센터입니다.

### 💡 Intelligibility(전달 명료도) 중심 코칭
목적은 원어민 억양 흉내가 아닌 **"해외 동료나 환자가 내 말을 오해 없이 명확히 알아들을 수 있는가?"**입니다.
* 음성 분석을 통해 오해가 발생한 발음 항목에 대해서만 핀포인트 교정을 제공합니다.

### 오발음 패턴 카테고리 & 필터 칩
내 세션들에서 포착된 발음 오류가 카테고리별로 정돈되어 필터 칩으로 제공됩니다:
* `r · l`: *liver / river*, *clinical / critical*
* `f · p`: *fever / peter*, *palpation / falcation*
* `th`: *think / tink*, *throat / troat*
* `final`: 종성 자음 생략 및 받침 처리 (*chest / ches*)
* `cluster`: 자음군 처리 및 모음 으/이 불필요 삽입 (*cardiac* → *card-i-ack-eu*)
* `stress`: 의학 단어 강세 오인식 (*angina*, *arrhythmia*)
* `vowel`: 단모음/장모음 오인식 (*ship / sheep*, *fit / feet*)

### 관찰(Observed) 상태 승격 규칙
발음 교정 카드는 최초 1회 수락 시 즉시 오답 숙제로 등록되지 않고 **관찰(Observed)** 상태로 기록됩니다. 타 세션에서 동일한 오발음 패턴이 재발될 때 비로소 오답 노트로 승격되어 대시보드 복습 루프에 반영되므로, 사소한 1회성 발음 인식을 과도한 숙제로 부여하지 않습니다.

## 10. 생존 영어 & 리스닝 랩 (Survival English & Listening Lab)

해외 병원에서 근무하는 IMG가 진료실 밖에서 실제로 부딪히는 돌발 상황을 대비하는 핵심 연습 모드입니다.

* **돌발 상황 모드 (Random / Surprise)**: 복도 기습 질문, 약국의 전화 처방 확인, 간호사 스몰토크 등 AI의 첫 마디를 들을 때까지 상황을 숨긴 채 기습 대처 연습을 진행합니다.
* **Rapid-fire small talk**: 예고 없이 주제가 바뀌는 빠른 스몰토크에 순발력 있게 대답합니다.
* **15가지 원어민 억양 프로필**: 세션마다 다양한 국가/지역의 원어민 억양 및 리듬에 적응하도록 지원합니다.
* **실시간 음성 속도 조절 (0.5배 ~ 2.5배)**: 원어민의 말하기 속도에 적응하도록 음정 변형 없는 속도 조절 슬라이더를 제공합니다.
* **귀 전용 듣기 모드 (Ear-only Mode)**: AI 대화 자막을 숨기고 순수하게 귀로만 청취하며 필요한 경우 **[Reveal last line]**으로 직전 자막을 확인합니다.
* **대화 수복 복구 표현 장려 (Repair is a skill)**: 못 알아들었을 때 *"Sorry?", "Could you say that again?"* 등으로 확인하는 복구 표현은 감점이 아닌 **포상 점수**로 반영됩니다.
* **리스닝 랩 (Listening Lab)**: 숫자, 약물 용량, 환자 이름, 시각, 약국지시사항, 가격, 방향 등 정밀한 디테일 청취를 테스트하고 정답률을 측정합니다.

## 11. 강의 티치백 (Lecture Teach-back — 파인만 학습법)

의학 지식을 내 머릿속에 완전히 각인시키기 위해 누군가에게 설명하듯 공부하는 Feynman 학습법 모드입니다.

1. **강의 자료 준비**: 요약 노트 텍스트를 직접 붙여넣거나, YouTube 의학 강의 URL을 입력한 후 **`🎬 Fetch YT transcript`**를 눌러 자막을 추출합니다.
2. **AI 요약 (Condensation)**: 긴 강의 자료는 **`✨ Condense`** 버튼을 눌러 핵심 500단어 구조화 요약본으로 축소할 수 있습니다.
3. **청중 페르소나 선택**:
   * **Oral Exam Professor**: 깐깐하고 날카로운 임상 "Why" & "What-if" 꼬리 질문을 던집니다.
   * **Confused Classmate**: 전문 용어를 쉬운 일상 용어로 풀어서 설명해주길 요청합니다.
   * **Friendly Tutor**: 말문이 막힐 때 용기를 주며 차근차근 표현을 가이드해 줍니다.
4. **티칭 진행**: **[시작]**을 누르고 마이크로 강의를 진행하면 청중 AI가 흥미를 보이며 질문을 던집니다.

## 14. 피드백 리포트 세부 분석 (7대 섹션)

세션이 끝나면 내 발화를 다각도로 정밀 분석한 결과 리포트가 7개 섹션으로 제공됩니다:

1. **Scores (점수)**: AI의 영역별 점수(0~10점)와 내가 입력한 자기 평가 점수를 나란히 비교합니다. 점수 차이가 **2.0점 이상** 크게 나면 원인을 돌아보는 노란색 **Reflection Prompt** 카드가 제시됩니다.
2. **Fluency (유창성)**:
   * **WPM (Words Per Minute)**: 분당 말하기 단어 수를 측정하여 권장 속도(100~130 WPM)와 비교합니다.
   * **Filler Words**: `um`, `uh`, `like` 등 불필요한 추임새 비중을 측정하여 침묵(Pause) 활용을 권장합니다.
3. **Checklist (체크리스트)**: 임상 목표 수행 여부를 판단하며, 내 실제 발화 문장이 **Evidence(근거)**로 인용됩니다.
4. **SOAP Note 비교**: 내 대화 내용을 토대로 자동 작성된 SOAP Note와 모범 답안 SOAP Note를 나란히 비교 분석합니다.
5. **Corrections (문장 교정)**: 콩글리시, 관사/복수형 오용, 부자연스러운 표현, 발음 오인식 항목의 교정안이 카드로 제시됩니다. 각 카드의 **[Accept]** 버튼을 누른 항목만 개인 오답 노트에 등록됩니다.
6. **Shadowing (섀도잉 훈련)**: 어색했던 문장을 원어민 문장으로 재구성하여 음성을 들으며 따라 말하는 훈련이 가능합니다.
7. **Summary & Share Cards**: 종합 총평 및 성적 요약 이미지를 생성하여 스터디 동료들과 공유할 수 있는 **Share Card** 기능을 제공합니다.

## 16. 망각 곡선 오답 노트 & Mistake Genome

피드백에서 **Accept(수락)**한 교정 문장들은 망각 곡선 알고리즘에 따라 오답 노트에서 자동 관리됩니다.

* **유사 오답 자동 감지**:
  * 표현이 유사한 오답이 중복 등록되지 않도록 자동으로 감지하여 정돈합니다.
* **Leech / Stubborn (고질적 실수)**:
  * 4회 이상 연속으로 복습 퀴즈를 틀린 항목은 **Stubborn / Leech** 태그가 지정되어 집중 관리됩니다.
* **망각 곡선 과학적 복습 주기 (Spaced Repetition)**:
  * 복습 주기: **1일 → 3일 → 7일 → 14일 → 30일**. 3회 연속 통과 시 **Mastered(완전 습득)** 상태가 됩니다.
  * **Practice My Mistakes** 음성 퀴즈를 통해 맞히면 단계가 올라가며 완치(Mastery)로 이동합니다.
* **Mistake Genome 패널**:
  * 대시보드에서 상위 5개 약점 카테고리(Articles, Plurals, Tense, Prepositions, Register, Konglish 등)를 바 차트로 확인하고 툴팁으로 쉬운 설명을 볼 수 있습니다.

## 17. 주치의 케이스 발표 연속 학습 (Attending Case Presentation Chaining)

환자 문진(Patient Encounter) 후 supervisor에게 보고하는 구두 인계 발표 능력을 연속 훈련합니다:

1. **Patient Encounter** 세션을 완료합니다.
2. **History** 탭으로 이동하여 해당 세션을 선택하고 **`📋 Present Case`** 버튼을 누릅니다.
3. 세션이 시작되면 AI 주치의(Attending)가 *"의사 선생님, 방금 본 환자 케이스 발표해 보세요."*라고 지시합니다.
4. SBAR 또는 SOAP 형식에 맞춰 입으로 구두 발표를 진행하면, 주치의가 감별 진단 및 치료 계획에 대해 추가 꼬리 질문을 던집니다.

## 18. 외부 대화 히스토리 가져오기 (Import Transcript)

ChatGPT, Gemini, 메모장에 기록된 외부 음성 대화 텍스트나 인계받은 문진 대화 텍스트를 앱으로 가져와 정밀 피드백을 받을 수 있습니다.

1. **Android 앱 공유 기능 활용**: 타 앱에서 대화 텍스트를 드래그하여 [공유] → [Bedside English]를 선택하면 자동으로 **Import Transcript** 화면이 열립니다.
2. **직접 입력/붙여넣기**: 상단 ⚙️ Preferences 또는 메뉴에서 `Import Transcript` 화면을 직접 열어 텍스트를 붙여넣을 수 있습니다.
3. **자동 분석 & 오답 등록**: 입력된 텍스트를 바탕으로 앱 내 세션과 동일한 영역별 점수, SOAP Note, 문장 교정안이 즉시 생성되며 오답 노트로 수락 등록할 수 있습니다.

## 19. Anki 단어장 & Word 보고서 내보내기

* **Anki 카드 내보내기 (탭 구분 `.txt`)**:
  * 세션에서 수락한 교정 문장들이 Anki 텍스트 가져오기 파일로 변환됩니다. Anki / AnkiDroid에서 [파일] → [가져오기]로 불러오면 각 오답의 카테고리가 태그로 함께 들어갑니다. 세션 종료 후 피드백 화면과 **오답 노트(My Mistakes)** 화면 양쪽에서 내보낼 수 있으며, 후자는 전체 오답 목록을 한 번에 내보냅니다.
* **Word 보고서 (`.docx`) 내보내기**:
  * 세션 점수, 체크리스트 달성 근거, SOAP Note, 문장 교정안이 정돈된 의학 보고서를 `.docx` 파일로 저장합니다. Preferences에서 자동 저장 옵션을 제공합니다.

## 20. 앱 내 도움말 위키 (In-App Help Wiki)

상단 앱 바의 **`?` 도움말 아이콘**을 누르면 본 내장 도움말 위키 뷰어가 풀스크린으로 열립니다.

* **다국어 연동**: 앱의 UI 표시 언어 설정에 맞춰 해당 언어의 설명서를 자동으로 로드합니다.
* **목차(TOC) 사이드바**: 원하는 섹션으로 빠르게 이동할 수 있는 목차 뷰를 제공합니다.
* **전문 검색 (Full-Text Search)**: 상단 검색창에 키워드를 입력하면 본문 내 검색어가 하이라이트 표시되며 이전/다음 버튼으로 즉시 이동합니다.
* **외부 하이퍼링크**: 가이드 내 웹 링크를 터치하면 시스템 브라우저로 연결됩니다.

## 21. UI 언어 설정, API 비용 추적 & 환경설정

상단 바의 **설정 톱니바퀴(⚙️)**를 눌러 내 기기와 예산에 맞게 앱을 조율할 수 있습니다:

* **Voice & Feedback**:
  - 음성 및 피드백 AI 모델 선택 (Demo, Gemini, OpenAI, Claude).
  - **Echo Prevention (하울링 예방)**: AI가 말하는 동안 마이크를 자동 차단하여 소리 울림을 방지합니다 (이어폰 미착용 시 필수).
  - **AI Speaking Pace (음성 속도 조절)**: Slow, Normal, Fast, Challenge 단계별 조절.
* **API Cost Analytics (API 비용 및 토큰 추적)**:
  - 세션별 소비 토큰 수 및 예상 달러 비용을 투명하게 집계하고 차트로 시각화합니다.
* **Audio**: 마이크 입력 레벨 게이지 및 스피커 테스트 음으로 사전 점검 수행.
* **API Keys**: 보안 저장소 기반 API 키 관리.
* **Export & Learning**: Docx 자동 저장, SOAP Note 입력 필수 여부, 모국어 및 UI 언어 설정.
* **Data**: 발음 분석 켜기/끄기, 발음 엔진 설정, 섀도잉 TTS 엔진 선택.
* **Privacy**: 익명 텔레메트리 켜기/끄기 설정.

## 22. 자주 묻는 질문 (FAQ) & 평가 루브릭

### 자주 묻는 질문 (FAQ)

**Q: 마이크 인식이 안 되고 대답이 없습니다.**
* 안드로이드 **설정 → 앱 → Bedside English → 권한 → 마이크**가 [허용]으로 되어 있는지 확인하세요. 만약 권한 거부 시에도 텍스트 입력 모드(Type instead)로 전환하여 키보드로 계속 연습할 수 있습니다.

**Q: 고급 연습 모드(Exam, Teach-back, Interview, Lounge, Custom)가 보이지 않습니다.**
* 첫 번째 연습 세션을 완료하면 축하 안내와 함께 모든 심화 모드가 자동으로 해금됩니다. Practice 화면에서 즉시 펼쳐볼 수도 있습니다.

**Q: 발음 분석 결과가 바로 오답 노트로 들어가지 않습니다.**
* 1회성 오발음을 과도한 숙제로 만들지 않기 위해, 발음 오인식 항목은 수락 시 먼저 **관찰(Observed)** 상태로 저장됩니다. 타 세션에서 동일한 발음 패턴이 재발될 때 비로소 오답 노트로 승격됩니다.

**Q: 외부 대화(ChatGPT 등)를 가져와 채점받을 수 있나요?**
* 네, Android 앱 공유 기능을 통해 텍스트를 공유하거나 `Import Transcript` 화면에 붙여넣으면 즉시 앱 내 정밀 피드백과 SOAP Note, 오답 카드가 자동 생성됩니다.
