# Bedside English 用户指南

**目标受众：** 国际医学毕业生 (IMG)、住院医师、医学生以及准备临床英语、OSCE、OET Speaking、美国住院医师面试、查房汇报 (Ward Round) 和临床沟通的医疗专业人员。

Bedside English 是一款由对话式人工智能（Google Gemini、OpenAI Realtime、Anthropic Claude）和实时语音技术驱动的 Android 专属应用。旨在全方位训练临床沟通技巧、医学推理、发音和语音清晰度 (Intelligibility)。本指南详细介绍了最新版本应用的所有功能和使用方法。

## 1. API 密钥设置与配置

Bedside English 灵活支持 Google Gemini、OpenAI 和 Anthropic Claude 后端。

### 💡 推荐设置（Google Gemini 单密钥模式）
**只需注册并输入一个 Google Gemini API 密钥，即可解锁应用内的所有功能——从实时语音对话到课后深度反馈分析，这是最快速且最具性价比 Choice。**

| 服务 | 主要用途 | 必填 / 选填 | 链接 |
| :--- | :--- | :--- | :--- |
| **Google (Gemini)** | 实时语音对话 (Gemini Live) + 深度反馈分析 | **必填（单密钥覆盖所有功能）** | [aistudio.google.com](https://aistudio.google.com) |
| **OpenAI** | 实时语音 (OpenAI Realtime) + 反馈 + 高级 TTS | 选填 | [platform.openai.com](https://platform.openai.com) |
| **Anthropic (Claude)** | 课程反馈分析（可选后端） | 选填（默认为 Gemini） | [console.anthropic.com](https://console.anthropic.com) |

### API 密钥输入与安全
API 密钥直接在应用内输入：
* 可在 **首次运行引导向导** 或通过主界面右上角 **设置 (⚙️) → 偏好设置 → API 密钥** 进行配置。
* 输入的 API 密钥安全存储在设备本地加密存储区 (`EncryptedSharedPreferences`) 中，绝不会上传至外部服务器。
* 每个密钥输入框右侧均带有眼睛图标，可自由切换显示或隐藏密钥。

### 🎈 Demo 演示模式（完全免费体验）
若希望在不输入 API 密钥或不授权麦克风的情况下体验应用，请在引导界面或 **偏好设置** 中选择 **Demo** 模式。
系统将加载预设的模拟对话与反馈数据，允许您在不消耗任何 Token 的情况下 **免费** 探索完整 UI、错题本与复习功能。完成 Demo 会话后，提示框允许您随时注册 API 密钥或继续进行下一个 Demo 患者练习。

## 2. 应用安装与权限设置

Bedside English 支持运行 Android 8.0 (API Level 26) 或更高版本的智能手机和平板电脑。

### 应用安装
* 在 Android 设备上打开提供的安装包文件 (`.apk`)，并按屏幕提示完成安装。

### 麦克风权限与打字模式
* 首次启动实时语音练习模式时，系统将请求麦克风访问权限。请点击 **[允许]** 以确保语音识别正常工作。
* 若处于不便说话的环境或拒绝了权限，应用不会崩溃，而是会自动切换为 **打字模式 (Type instead)**，允许您通过键盘输入完成对话练习。

### 通知权限与音频预检 (Audio Preflight)
* 请求通知权限以便在后台反馈分析完成时接收提醒通知。
* 在首次实时语音会话开始前，系统将弹出 **音频预检 (Audio Preflight)** 提示框，指导佩戴耳机并测试麦克风输入电平，防止扬声器产生回声啸叫。

## 3. 首次运行引导与母语定制

首次启动应用时，4 步设置向导将帮助您构建定制化学习环境：

1. **欢迎界面 (Welcome)**：介绍核心功能并提供 **体验 Demo 模式 (Try Demo Mode)** 按钮。
2. **UI 语言选择 (Language Picker)**：选择界面显示语言（支持中文、英文、韩文、西班牙文、阿拉伯文、印地文、葡萄牙文、他加禄语等 8 种语言）。
3. **API 密钥设置 (API Keys)**：注册您的 Google Gemini 或其他 AI API 密钥。
4. **母语与隐私 (Native Language & Privacy)**：选择您的母语（如 **中文**）。这将激活针对中文母语者发音与语法干涉模式的精准纠错。

### 🌐 中文母语者 (L1 Chinese) 专属定制亮点
* **语法与表达纠错**：
  * 冠词漏用（名词前遗漏 *a/an/the*）
  * 复数尾音 *-s* 漏用（如 *two patient* → *two patients*）
  * 时态混用（讲述既往病史时误用一般现在时）
  * 介词误用与遗漏（如 *in hospital*，*explain to patient* 中漏用介词）
  * 中式英语/直译表达 (Chinglish / Direct Translation，如 *skin scale*，*side effect* 的生硬直译)
* **发音与清晰度纠错**：
  * *v / w* 最小对立对区分（如 *very* vs *wery*）
  * *n / ng* 鼻音词尾区分（如 *pin* vs *ping*）
  * *th / s / z* 齿擦音区分（如 *think* vs *sink*）
  * 词尾辅音脱落及不必要的元音附加（如 *cardiac* 读成 *cardi-ack-eu*）
  * 医学专业词汇重音误置（如 *angina*, *arrhythmia*）

### 💡 首次运行互动导览 (First-Run Tour)
完成引导进入主页面板后，互动教程将自动指引核心按钮（主页面板、练习中心、发音实验室、SRS 复习、历史记录、帮助、1:1 语音教练）的位置与功能。

## 4. UI 界面概述（底部 5 个标签页与帮助）

### 底部导航栏 (5 个标签页)
应用的核心功能由底部 5 个标签页组成：

```
┌───────────┬──────────────┬───────────────────────┬───────────────┬─────────────┐
│  🏠 Home  │  ▶ Practice  │  🎙️ Pronunciation Lab │  ⚠️ SRS Reviews│  🕘 History │
└───────────┴──────────────┴───────────────────────┴───────────────┴─────────────┘
```

1. **Home (主页)**：连续练习天数 (`🔥`)、5 分钟临床任务、业绩趋势图表、错误基因组、路线图及 **随时随地 1:1 语音教练**。
2. **Practice (练习中心)**：问诊练习、临床诊断测试、生存英语、费曼输出、面试、自由交流角等所有实时口语练习模式的集中地。
3. **Pronunciation Lab (发音实验室)**：专注于语音清晰度 (Intelligibility) 与发音纠正的独立训练标签页（错误模式筛选、观察状态管理）。
4. **SRS Reviews (弱点复习)**：基于间隔重复算法对已接受的纠错句子进行朗读复习的错题测试。
5. **History (会话历史)**：查看历史会话得分与反馈、Token 成本追踪、导出至 Anki/Word 及触发 **上级医师病例汇报 (Present Case)**。

### 顶部应用栏 (Top App Bar)
* **Bedside English Logo**：主标题。
* **帮助维基 (`?` 图标)**：点击顶部栏 `?` 图标可在全屏查看器中打开本用户指南（支持目录跳转与全文本关键字搜索）。
* **设置齿轮 (⚙️ 偏好设置)**：API 密钥、后端选择、语速、回音消除、语言及数据管理。

## 5. 掌握主页面板（Dashboard）

主页面板从多个维度直观展示您的临床英语沟通能力成长：

* **连续练习天数 (Practice Streak)**：显示连续练习天数 (`🔥`)，培养每日坚持练习的习惯。
* **核心指标卡片**：
  * **Sessions done**：已完成分析的会话总数。
  * **Errors tracked**：个人错题数据库中已注册的纠错项。
  * **Mastered**：经反复复习已完全掌握并毕业的错题数。
  * **Due now**：今日待复习的 SRS 口语卡片数。
  * **Stubborn**：连续 4 次以上复习失败的顽固错题 (*Leech*)。
* **每日 5 分钟临床任务 (Today's 5-Minute Clinical Mission)**：根据今日待复习错题或薄弱环节，自动推荐最佳的 5 分钟练习课程。
* **OET 患者通俗词汇覆盖率 (OET Layman Vocabulary)**：
  * 评估用通俗词汇（如 *fainting*）替代复杂医学术语（如 *syncope*）的能力。
  * 已使用的表达显示在 **Recently Unlocked (解密)**，未使用的表达排列在 **Next Goals (Locked) (锁定)**。
* **错误基因组面板 (Mistake Genome)**：分析最常犯的错误分类（冠词、复数、时态、介词、语体、直译等），柱状图展示前 5 大弱点分布。
* **成长趋势与 L1 干涉图谱**：
  * 展示最近 20 次会话在 5 大维度（语法、准确性、推理、专业度、流畅度）上的得分趋势。
  * 视觉化呈现反复出现的语法错误模式。
* **个性化路线图**：基于薄弱指标推荐 4 项优先练习。
* **随时随地 1:1 语音教练 (`🎙️ RecordVoiceOver`)**：
  * 点击主页右下角悬浮按钮，无需开始完整场景即可基于个人弱点库与 AI 导师展开 1:1 语音对话。

## 6. 练习中心与功能渐进式解锁

### 渐进式解锁
为了防止新用户感到应接不暇，初次启动时仅展示核心模式（**主页**、**问诊练习**、**生存英语**、**历史记录**）。
* **完成首次练习会话后**，系统将伴随祝贺消息 **自动解锁** 高阶模式（考试、费曼输出、面试、自由交流角、自定义场景）。
* 您也可以在练习界面随时点击展开全部模式。

### 练习中心核心分类
1. **Patient Encounters (问诊练习)**：病史采集、随访、Foundations 基础模式、Skill Drills 专项微技能、Practice My Mistakes 错题强化。
2. **Exam & Diagnostic (考试与诊断)**：10 分钟基线诊断、OSCE、OET、住院医师面试及查房汇报模拟考试。
3. **Survival English & Listening Lab (生存英语与听力实验室)**：医院突发状况、快速闲聊、15 种国际口音及听力精听训练。
4. **Lecture Teach-back (医学讲座费曼输出法)**：基于文本或 YouTube 视频摘要的费曼输出训练。
5. **Residency Interviews (住院医师面试)**：行为面试 (STAR)、临床面试及 IMG 专属面试。
6. **Free English Lounge (自由交流角)**：医学新闻辩论、工作场所冲突调解。
7. **Custom Scenarios (自定义场景)**：自定义 Prompt 与评分标准。

## 7. 问诊练习与实时病史覆盖率追踪

模拟病房病史采集 (History Taking) 与患者沟通——临床沟通的核心。

### 7-1. 子模式
* **Foundations 基础模式**：降低临床推理负担，专注于 **语法、临床词汇、建立共情 (Rapport) 与流畅度**。
* **Skill Drills 专项微技能**：包含 NURSE 共情技巧、通俗解释、夜班交接及 **中文→英文医学同声传译训练**。
* **Practice My Mistakes 错题强化**：基于错题库生成即时口语测试。
* **Daily Mission 每日任务**：5 分钟自适应每日挑战。

### 7-2. 实时病史覆盖率追踪 (Live History Coverage Tracker)
可折叠面板，在对话中实时勾选已采集的病史要点：
* 根据 AI 对话上下文实时追踪发病时间、痛点性质、放射痛、加重/缓解因素、伴随症状、ICE (Ideas, Concerns, Expectations)、既往史、用药史、过敏史、饮酒/吸烟史、家族史等。
* 否定确认问题（如 *"您不抽烟，对吧？"*) 也将被正确识别并记录。

### 7-3. 上下文感知启发 (`💡 Help me continue`)
卡壳时点击底部 **💡 Help me continue**：
* 系统分析患者上一句回答，提示下一个逻辑问诊目标及 **即拿即用的英文例句**。
* 顶部阶段追踪器显示进度符号：
  * `✓`：充分证据已确认
  * `•`：部分提及
  * `?`：跳过前期阶段

## 8. 考试与诊断模式（10 分钟基线与 CEFR 对照）

在限时、沉浸式考试环境下精准测量沟通能力：

### 10 分钟临床英语基线诊断 (10-minute Baseline Diagnostic)
* 考官致辞后连续执行 4 项短任务（解释诊断、回答追问、45 秒 SBAR 汇报、回答面试问题）。
* 自动映射至国际 **CEFR 等级**：
  * **得分 ≥ 8.5**：**C1**（主治医师水平的流利、安全的临床沟通）
  * **得分 ≥ 7.2**：**B2+**（胜任海外医院实习与临床实践）
  * **得分 ≥ 6.0**：**B1-B2**（具备基础沟通能力，建议结构化进修）
  * **得分 < 6.0**：**A2-B1**（需基础临床沟通训练）

### 模拟考试场景
* **OSCE**：胸痛患者 (Mr. Hayes) 病史采集（测量 ICE、危险信号识别、共情建立）。
* **OET Speaking**：高血压患者咨询角色扮演。
* **Residency**：美国内科住院医师项目主任模拟面试。
* **Ward Round**：5 分钟社区获得性肺炎病例汇报与口试应对。

### 分数可信度 (Score Reliability)
标示 AI 评分可信度为 **High**、**Medium** 或 **Low**：
* **High**：发音词数 ≥ 180 词且检查单证据率 ≥ 75%。
* **Medium**：词数 ≥ 80 词且证据率 ≥ 50%。
* **Low**：词数 < 80 词（Short Transcript 标记）或证据率 < 50%。

## 9. 发音与清晰度实验室 (Pron Lab)

位于第 3 个标签页 (`🎙️ Pron Lab`)，专注于 **临床语音清晰度 (Intelligibility)**：

### 💡 以清晰度为核心的指导
目标不是模仿纯正美音，而是 **“海外同事和患者能否清晰无误地听懂我的话？”**
* 仅针对导致听者误解的发音项提供精准纠正。

### 错误模式分类与筛选 Chip
* `r · l`：*liver / river*，*clinical / critical*
* `f · p`：*fever / peter*，*palpation / falcation*
* `th`：*think / tink*，*throat / troat*
* `final`：词尾辅音脱落 (*chest / ches*)
* `cluster`：辅音连缀及元音附加 (*cardiac* → *cardi-ack-eu*)
* `stress`：医学词汇重音误置 (*angina*, *arrhythmia*)
* `vowel`：长短元音混淆 (*ship / sheep*, *fit / feet*)

### 观察状态 (Observed) 升级规则
首次接受的发音错误存为 **观察状态 (Observed)**，仅在后续练习中再次复现时才会转为 active SRS 复习卡片，防止偶然的识别失误造成额外负担。

## 10. 生存英语与听力实验室

准备应对诊室外的真实医院突发状况：

* **突发模式 (Surprise Mode)**：在事先不知情的情况下应对护士走廊提问、药房电话确认等突发沟通。
* **快速闲聊 (Rapid-fire small talk)**：快速应对话题切换。
* **15 种国际口音**：适应不同国家/地区的发音与节奏。
* **实时语速调节 (0.5× 至 2.5×)**：无变调语速调节滑块。
* **纯听力模式 (Ear-only Mode)**：隐藏字幕进行纯听力训练（配备 **[Reveal last line]** 按钮）。
* **修复表达奖励 (Repair is a skill)**：使用 *"Sorry?"* 或 *"Could you say that again?"* 等澄清表达将获得 **加分奖励**。
* **听力实验室 (Listening Lab)**：精细测试药物剂量、化验值、患者姓名、时间及价格听辨。

## 11. 医学讲座费曼输出法 (Teach-back)

使用费曼学习法向 AI 听众口头讲解医学概念：

1. **准备材料**：粘贴文本或输入 YouTube URL，点击 **`🎬 Fetch YT transcript`**。
2. **AI 精简 (`✨ Condense`)**：将长文本压缩为 500 词结构化提纲。
3. **选择听众角色**：

## 14. 解构反馈报告（7 大核心板块）

会话结束后提供 7 板块深度分析：

5. **Corrections (纠错)**：显示直译、语法、发音卡片，点击 **[Accept]** 存入 SRS 错题库。
6. **Shadowing (影子跟读)**：改写复杂句子为主治医师水平进行听读训练。
7. **Summary & Share Cards**：生成可分享的学习成果卡片。

## 16. 间隔重复错题追踪与错误基因组

通过科学的间隔重复算法管理已接受的错题：

* **模糊去重 (Fuzzy Duplicate Detection)**：自动防止重复录入。
* **顽固错题 (Stubborn / Leech)**：连续失败 4 次以上的错题标记重点关注。
* **间隔重复周期**：**1 天 → 3 天 → 7 天 → 14 天 → 30 天**。连续 3 次通过即可升至 **Mastered (已掌握)**。
* **错题强化练习 (Practice My Mistakes)**：通过语音测试提高掌握度。
* **错误基因组面板**：主页柱状图展示 5 大语法错误类型及Tooltip解释。

## 22. 常见问题解答 (FAQ) 与评分标准

### 常见问题解答 (FAQ)

**问：麦克风无法识别且 AI 无应答。**
* 请检查 Android 设置 → 应用 → Bedside English → 权限 → 麦克风。若被拒绝，应用将切换为 **打字模式 (Type instead)**。

**问：高阶练习模式未显示。**
* 完成首次练习后，所有高阶模式将自动解锁。

**问：发音错误为何没有直接存入复习卡片？**
* 首次接受的发音错误会先存为 **观察状态 (Observed)**，仅在后续练习中再次复现时才会转为复习卡片。

**问：可以导入 ChatGPT 等外部对话记录吗？**
* 可以，通过 Android 分享功能或粘贴至 `Import Transcript` 界面即可生成完整反馈。

### 📝 详细评估评分标准（0 至 10 分）

| 分数 | 评估等级 | 评估标准 |
| :--- | :--- | :--- |
| **9 ~ 10** | **主治医师 / 专家 (Attending / Expert)** | 语法与表达完美无瑕；临床词汇精准且医学推理系统化；语气专业自然。 |
| **7 ~ 8** | **胜任 / 合格 (Competent / Pass)** | 轻微语法瑕疵但沟通极其清晰；能准确识别关键风险因素并安全完成鉴别诊断。 |
| **5 ~ 6** | **成长中 (Developing)** | 频繁出现结构性语法错误，需倾听者费力理解；临床推理欠系统化。 |
| **1 ~ 4** | **危急 / 不合格 (Critical / Fail)** | 严重医学错误或遗漏风险因素；表达局限于单个词汇或长时间停顿。 |
